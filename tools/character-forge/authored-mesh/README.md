# Authored mesh study — P0.4 A3

This directory is an optional authoring tool, **not** the production clothing generator. An independent agent can create arbitrary geometry elsewhere and submit version 1 JSON: a rig table with exact joint ids, names, parents, rest positions and local translations; an array of Forge-compatible authored parts with positions, normals, indices, material/color and four/eight skin channels. No closed style or garment list. This importer makes an isolated, explicitly unqualified study model; it cannot grant admission. No Blender dependency for authoring or importing, no new dependency in Core.

First author recipe: Artisan Base, northern European working clothing, c. 1330–1380. Bocksten outfit (Hallands Kulturhistoriska Museum), comparative tunic construction (https://doi.org/10.59500/ADXG6035), and occupational apron imagery (https://www.larsdatter.com/aprons.htm). The new surface uses an implicit union and rounded underarms, not the old welded ring topology; it has a narrowed neckline, flared hem, and a stitched 2.5 mm lining. This is original geometry inspired by historical garments, not an archaeological reconstruction or a sewn pattern with literal gusset seams. Material/art finish remains incomplete. Only Base has been tested, not other morphotypes.

With Python 3.13.5 and the pinned optional author dependencies: install requirements.txt, invoke python author-artisan.py SOURCE.json OUTPUT.json twice, compare outputs, then node export-study.mjs BASE_WITH_CYCLIC49.json OUTPUT.json STUDY.glb. The original Forge exporter is used; do not feed this study to production admission as a complete character. Source and motion are the original P0.3 archives (run 46138654367). The independent local offline analysis of A3 gives 3178 vertices/6364 triangles, 163 inherited joints, zero strict crossings in rest and nine Idle phases; 67-state max self 74/body 1663, max stretch 1.294947/P95 1.122433, no collapsed edges. Matched old 18 states: self 259->61, body 2355->1561, max stretch 1.247882->1.288554; differing triangle counts and local-vs-Blender methods are not interchangeable. All gates remain unchanged. Body crossings in Walk block admission; preserve P0.3 controls. Full outfit, attachments, Merchant and other morphotypes not built. Native export CI and independent playback/staging still required.

The first study CI 46142579791 passed import tests and artifact downloads, then failed in Trimesh plane slicing because Shapely was not installed. Pin Shapely 2.1.2 (locally verified) and Numba 0.65.1 for the optional independent binary audit. `audit-export.py GLB SOURCE.json PART OUTER_VERTEX_COUNT REPORT.json` reads exact exported skin/animation channels and performs 67-state triangle audit with preserved pair IDs and matched 18-state summaries. It compares the isolated A3 tunic with the archived P0.3 control using the same method. It does not qualify a full outfit, browser, Blender or Art Forge staging. The workflow publishes evidence even if its isolated gate rejects the study.

### P0.5 pose-aware full composition study
The pinned A3 native GLB (run 46143701216, artifact 15262823644) remains unchanged. Optional pose_tailor.py uses the existing binary decoder, validated tetrahedron distance control, signed nearest triangle distance plus enclosed parity, centroid-sampled affected outer area, thickness and discrete control phases. Its seven-state diagnosis and single bounded geometry correction do not constitute continuous collision or full qualification. Run with GLB SOURCE PART OUTER_COUNT OUTPUT_DIR, then compose-artisan.py BASE A3_DOCUMENT OUTPUT_DIR/candidate.npy OUTPUT_DIR/composed-document.json, then compose-fit-audit.py with the same five pose-tailor arguments plus the composed document. The optional negative-studies.py reproduces B/C on the same inputs, after A; do not run routinely. No new mandatory Core dependencies. The authored mesh import and existing exporter remain unchanged. The complete composition uses a new belt and apron, locally refitted inherited hose, relocated inherited rigid hardware, inherited face/hair/boots with material revisions. It has separate fixed and free zones; neither the attachment-chain study nor the isolated tunic audit is a full layered production gate. The isolated study workflow publishes native GLB, images and videos on rejection. Blender/browser/Art Forge/Studio qualification still required; no admission granted.
