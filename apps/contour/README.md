# КОНТУР

Quick Pocket Works puzzle, version 1.0.0. Rotate tiles by 90° to connect the generator to every lamp without leaving open ends. Choose one of five generated schemas, shuffle the current puzzle, or continue to the next. The app stores progress locally and declares its own manifest, icon, service worker and cache namespace.

## Run

Open `/apps/contour/` from the Pocket Works launcher or serve the repository through the normal Pocket Works development/build workflow. Touch and mouse both rotate tiles.

## Validation

Use the repository's existing registry, health and browser checks. The app's isolated files live in this directory; launcher metadata is declared in `app.config.json`. This documentation-only change does not modify game rules, storage, runtime or deployment.
