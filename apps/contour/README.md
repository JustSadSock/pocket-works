# КОНТУР · v1.0.0

Офлайн-головоломка Pocket Works. Пять детерминированных схем 5×5: вращайте проводники касанием, пока все лампы не получат питание и не останется открытых контактов. Переключение уровня, сброс и переход после решения находятся рядом с полем.

- `core.mjs` — генерация схем, поворот масок и проверка связности.
- `app.js` — интерактивное поле и локальное сохранение уровня, масок и количества ходов.
- `manifest.webmanifest`, `sw.js` — автономная PWA.
- Хранилище: `pocket-works:contour:state`.

В корне Pocket Works запустите `npm run prepare:site` и откройте `/apps/contour/` через сервер проекта. Для проверки пройдите уровень, перезагрузите страницу и проверьте восстановление состояния.

Автоматические тесты: `node --test apps/contour/core.test.mjs`.
