# НОМОС

Мобильная офлайн-лаборатория возникновения государств для Pocket Works.

- Canvas 2D, без зависимостей и сетевых запросов.
- Процедурный рельеф, ресурсы, экспансия, войны, торговля, бунты и расколы.
- Кисти прямого вмешательства и четыре глобальных общественных закона.
- Политический, экономический, культурный и кризисный режимы карты.
- Автосохранение, снимки эпох каждые 50 лет и восстановление прошлого.
- Touch-first интерфейс, safe-area, PWA, звук и виброотдача.
