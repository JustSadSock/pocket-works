# Звуковая палитра «Чёрных знамён»

Материалы: деревянные ножны, тянущаяся кожа ремней, железный обод шлема, влажный камень.

События: марш — приглушённый деревянный удар и шелест; удар — короткий металлический акцент с низким резонансом; оборона — сухой деревянный щелчок; смена хода — глухой стук; невозможное действие — мягкий беззвучный визуальный сигнал (без резкого звука).

Характер: низкий, сухой, приглушённый, тяжёлый.

Реализация: Web Audio шум с полосовым фильтром и огибающей; при ударах дополнен коротким треугольным осциллятором, случайная модуляция шума. Короткие хвосты без музыкальной последовательности. Звук выключен изначально, включается только через меню, используется малый уровень громкости.

Не используется: одиночный «UI beep», звонкая синусоида, автостарт, сэмплы из чужих игр.

Если Web Audio недоступен, игра остаётся полностью работоспособной. Все действия подтверждаются видимыми изменениями сцены и статуса.
