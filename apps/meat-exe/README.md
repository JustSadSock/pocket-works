# MEAT.EXE / Pocket Works

Порт исходного [JustSadSock/Meat.exe](https://github.com/JustSadSock/Meat.exe) — процедурного мясного FPS с Three.js. Исходный репозиторий остаётся нетронутым.

## Реализация

- Единственная авторитетная 3D-симуляция и игровой кадр: app.js ↔ scene.js. Старые самостоятельные 2D WebGL-карта и gameplay loop намеренно не перенесены.
- organGen.js: сохранённый исходный детерминированный генератор связанных секций, открытых межчанковых коридоров; геометрия стен и проверки доступных клеток унифицированы в scene.js.
- three.module.js: локальная копия библиотеки Three.js из исходного репозитория (оригинальное уведомление о MIT-лицензии в коде); внешних CDN нет.
- Пять волн, несколько типов врагов, простейшая BFS-навигация, два оружия с попаданием по направлению камеры, кровь, полевые улучшения, Hash-Heart и окончание игры.
- Управление ПК: WASD / стрелки, мышь, ЛКМ (удержание), Space (рывок), Shift (ускорение), Q/E (переключение оружия), Esc (пауза).
- Управление телефоном: левый виртуальный стик, правое перетаскивание обзора, ОГОНЬ (удержание), РЫВОК, СМЕНА. Поддерживаются горизонтальный и вертикальный экран.
- Пауза по Esc, скрытию страницы или уходу из приложения; восстановление сохранённого забега, рекордов и полученных мутаций; отключаемый процедурный Web Audio.
- Service Worker кэширует собственные файлы и требуемый мобильный runtime.

## v1.1.0 — Железный скелет

- Стартовая камера направляется вдоль самого открытого коридора: телефон не должен начинать забег лицом к стене.
- Фиксированный симуляционный шаг 60 Гц с ограничением догоняющих шагов; меню/пауза рисуются только один раз за переход (не греют GPU в фоне), скрытая вкладка не рисуется.
- Коллизия с sweep-сегментацией: быстрый рывок больше не перепрыгивает через препятствия.
- Проверка сохранений v1/v2, перенос предыдущих забегов, проверка позиции и восстановление валидных врагов/предметов.
- Мышь захватывается после клика по 3D-арене; до этого кнопка паузы доступна, при захваченном курсоре пауза — Esc.
- Геймпад: стики, RT — выстрел, A — рывок, B — оружие, Start — пауза, A — продолжение; экран настроек не требуется.
- Графика АВТО / СКОРОСТЬ / ДЕТАЛИ в меню и на паузе. Авто-режим динамически меняет разрешение рендера.
- Подтверждение замены сохранённого забега, обработка потери WebGL-контекста, read-only QA-состояние `window.__MEAT_QA__()`.

## v1.2.0 — Оружие чувствуется

- `combat.js`: отдельный 3D ray hit resolver для оружия; стены, потолок и пол блокируют выстрелы, а не только движение. Центр дробового рисунка всегда соответствует прицелу.
- КОСТОЛОМ и МЯСОРУБКА получили различные 3D-модели: длинная затворная игла против двух костяных стволов с зубчатой челюстью. На телефоне модель уменьшена и приподнята, чтобы оставаться видимой без перекрытия прицела. На ПК первый клик одновременно начинает стрельбу и захватывает курсор.
- Выстрелы запускают короткие трассеры, вспышки и инерционную пружину оружия. Попадание вызывает всплеск в точке контакта, краткий светлый след на теле, микрозадержку движения врага; удар по стене оставляет ограниченное по количеству кровяное пятно. Убийства отражаются на прицеле и полу.
- `sound-forge.js`: оригинальный многослойный Web Audio со звуками кости, железа и влажной плоти, ограничением голосов и защищенными повторами; см. `AUDIO.md`.
- Эффекты ограничены по количеству, режим «Скорость» уменьшает плотность частиц. Рендер ограничен по физическим пикселям и в режиме «Детали» не монополизирует главный поток. Поддерживается `prefers-reduced-motion`. Звуки отключаемы.
- Добавлены Node-тесты точности траекторий и Playwright-проверка реальной стрельбы мышью/касанием.

## v1.3.0 — Внутри живого

- `organGen.js`: три варианта детерминированных комнат (`atrium`, `rib-vault`, `artery`), периферический сосудистый кольцевой маршрут, проходы к четырём согласованным порталам. Ткани блокируют только необязательные обходные клетки: перед размещением каждая кандидатура проходит BFS-проверку связности.
- На карте появляются объёмные пульсирующие мембраны. В них можно стрелять: у затвора 100 здоровья; после разрыва геометрия скрывается, физическая клетка открывается, навигация ИИ пересчитывается, игрок получает очки и фрагмент.
- Организм отвечает на нарушение стенок краткой волной иммунных врагов спустя предупреждение; масштаб реакции ограничен, здоровье врагов не растёт искусственно. Пульс среды обозначает событие.
- Повреждения и открытые затворы сохраняются в забеге v3 (старые v1/v2 данные проходят миграцию). Старые позиционные данные вне нового лабиринта безопасно возвращаются к старту.
- `qa/anatomy.test.mjs`: тысяча процедурных секций, многосекторная связность и сохранение прохода при целой мембране; `qa/anatomy.spec.js`: браузерный сценарий старта, огня, паузы и возврата.

## Ограничения

Классический оригинальный GLSL-редактор перенесён как игровая концепция фрагментов-улучшений, не как произвольная компиляция пользовательского кода: небезопасные/битые шейдеры были одним из источников поломок.
Модели монстров и оружия — специально собранная параметрическая геометрия; Blender недоступен в исполнительной среде портирования.
Финальное визуальное подтверждение требует реального запуска в Chromium и WebKit; тест с одной лишь проверкой исходного кода не доказывает качество рендера.
