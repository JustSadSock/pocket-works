# Звуковая палитра MEAT.EXE

**Материал:** мокрая плоть, кость, стальной ствол, пульсирующие органы; никаких стандартных UI-бипов.

**Выстрел:** короткий рваный низкий пилоподобный импульс со слоем bandpass-шума; дробовик ниже и длиннее болтера. **Попадание:** высокий сухой хруст поверх краткого шумового среза. **Убийство:** низкое ломкое поглощение. **Урон игроку:** утробный спад + влажный шорох. **Фрагмент:** короткий дрожащий резонанс. **Сердце:** низкочастотный мощный удар без длительного шума. **Меню/рывок:** короткое физическое клацанье.

Только Web Audio API после жеста. Есть выключатель, амплитудные огибающие сглажены, длительности от 70 до 520 мс, вариация тона до 4%. Ни один звук не обязателен для понимания игры.
