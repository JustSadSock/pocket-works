# Print Sheet

Загрузите фото, задайте ширину и высоту в см, выберите обрезку или вписывание, количество копий, поля и ориентацию. Предпросмотр отражает реальную раскладку. PDF содержит A4 MediaBox и растровые листы 300 dpi. Печатайте при 100% без подгонки. Фото и настройки сохраняются локально в IndexedDB. Не поддерживаемые браузером файлы, включая некоторые HEIC, следует преобразовать в JPEG. Тесты: `node --test apps/print-sheet/core.test.mjs`.
