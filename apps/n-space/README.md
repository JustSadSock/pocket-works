# N·SPACE

Интерактивная лаборатория многомерной геометрии для Pocket Works.

## Что умеет

- симулирует координаты и рёбра фигур в 1D, 2D, 3D, 4D и 5D;
- строит гиперкубы, регулярные симплексы и кросс-политопы;
- вращает фигуру в любой координатной плоскости: XY, XZ, XW, XV, YZ, YW, YV, ZW, ZV, WV;
- проецирует исходное пространство в 4D, 3D, 2D или 1D перспективно либо ортографически;
- показывает параллельную цепочку 4D/3D/2D/1D проекций;
- позволяет касанием выбрать вершину и прочитать её текущие N-мерные координаты;
- сохраняет размерность, фигуру, проекцию, ориентацию, масштаб и режим автоворота локально;
- работает офлайн после первого успешного запуска.

## Управление

На основной сцене горизонтальное движение вращает выбранную плоскость. Вертикальное движение вращает связанную плоскость, когда она существует. Щипок меняет масштаб. Касание вершины открывает её координаты. С клавиатуры работают стрелки и `+`/`-`.

## Реализация

Приложение использует собственное N-мерное математическое ядро на JavaScript и Canvas 2D. Это осознанно точнее и легче для задачи, чем полноценный 3D-движок: 4D/5D координаты и повороты хранятся без потерь, а визуализация выполняется только на последнем шаге через последовательную проекцию.
