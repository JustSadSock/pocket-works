# Miniature Lab

Miniature Lab — отдельное Pocket Works приложение для превращения фото и видео в убедительный miniature / tilt-shift эффект.

## Что умеет

- принимает фото и видео любого соотношения сторон;
- работает полностью локально на устройстве;
- даёт три режима фокуса: **Авто**, **Сцена**, **Объект**;
- `Авто` анализирует кадр по локальной детализации, контрасту, насыщенности и пространственной концентрации и выбирает подходящую геометрию фокуса;
- использует несколько уровней blur вместо одного равномерного размытого слоя;
- дополнительно усиливает локальный контраст и насыщенность внутри резкой области;
- позволяет двигать фокусную полосу или объектный эллипс прямо по кадру;
- показывает оригинал удержанием одной кнопки;
- экспортирует фото в JPEG/PNG;
- экспортирует видео через `MediaRecorder` в лучший формат, поддерживаемый браузером;
- пытается сохранить исходный звук через Web Audio;
- сохраняет настройки локально;
- после первого успешного запуска оболочка доступна офлайн;
- использует WebGL fallback для `CanvasRenderingContext2D.filter`, чтобы Safari/WebKit не превращали эффект в пустышку.

## Когда какой режим использовать

- **Авто** — быстрый старт; после анализа его можно вручную подправить.
- **Сцена** — улицы, комнаты, дороги, города, железные дороги, пейзажи и другие кадры с перспективой.
- **Объект** — еда, вещи, люди, техника, раковины, столы, предметы и кадры сверху.

## Ограничение авто-анализа

В этой версии нет многомегабайтной нейросетевой monocular depth-модели. Авто-режим строит лёгкую локальную оценку визуальной структуры кадра, чтобы оставаться быстрым, офлайн-дружелюбным и стабильным на iPhone. Это не настоящая 3D-реконструкция сцены, поэтому сложные перекрытия всё ещё лучше корректировать вручную.

## Форматы и экспорт

Декодирование входного файла выполняет сам браузер. JPEG/PNG/WebP/AVIF, MP4/MOV/WebM и другие обычные форматы работают там, где их поддерживает установленный Safari/Chrome/Edge/Firefox. HEIC/HEIF обычно доступен на Apple-устройствах.

- **Авто:** до 4096 px по длинной стороне для фото, до 1920 px для видео.
- **1080p:** до 1920 px.
- **4K:** до 3840 px.
- **Оригинал:** без апскейла, с защитным лимитом 8192 px.
