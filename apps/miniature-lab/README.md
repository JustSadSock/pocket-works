# Miniature Lab

Miniature Lab — отдельное Pocket Works приложение для превращения фото и видео в убедительный miniature / tilt-shift эффект.

## Что умеет

- принимает фото и видео любого соотношения сторон;
- работает полностью локально на устройстве;
- даёт три режима фокуса: **Авто**, **Сцена**, **Объект**;
- `Авто` анализирует кадр по локальной детализации, контрасту, насыщенности, пространственной концентрации и ориентации деталей и выбирает подходящую геометрию фокуса;
- основной эффект считается одним WebGL-шейдером: для каждого пикселя вычисляется непрерывная условная глубина и соответствующий радиус размытия;
- резкая область дополнительно получает локальное усиление контраста и насыщенности, чтобы кадр воспринимался как макет, а не как простое замыливание;
- позволяет двигать фокусную полосу или объектный эллипс прямо по кадру; у эллипса можно менять размер перетаскиванием края;
- показывает оригинал удержанием одной кнопки;
- экспортирует фото в JPEG/PNG;
- экспортирует видео через `MediaRecorder` в лучший формат, поддерживаемый браузером;
- пытается сохранить исходный звук через Web Audio;
- сохраняет настройки локально;
- после первого успешного запуска оболочка доступна офлайн;
- если основной WebGL-рендерер недоступен, есть Canvas fallback; для Safari/WebKit его фильтры подстрахованы отдельным WebGL polyfill.

## Когда какой режим использовать

- **Авто** — быстрый старт; после анализа результат можно вручную подправить.
- **Сцена** — улицы, комнаты, дороги, города, железные дороги, пейзажи и другие кадры с перспективой.
- **Объект** — еда, вещи, люди, техника, раковины, столы, предметы и кадры сверху.

## Авто-анализ и «глубина»

Miniature Lab не притворяется полноценной нейросетевой 3D-реконструкцией. В этой версии нет многомегабайтной monocular-depth модели: авто-режим строит лёгкую локальную оценку структуры кадра, чтобы оставаться быстрым, офлайн-дружелюбным и устойчивым на iPhone. После выбора геометрии WebGL-шейдер создаёт непрерывное поле глубины относительно полосы или эллипса.

Это гораздо осмысленнее обычного tilt-shift blur, но сложные перекрытия объектов и настоящая семантическая глубина всё ещё могут потребовать ручной корректировки.

## Производительность

- один основной WebGL-pass вместо нескольких полноразмерных blur-композиций;
- видеопревью намеренно рендерится во внутреннем уменьшенном разрешении;
- UI не запускает больше одного нового рендера за animation frame;
- дорогие циклы останавливаются, когда видео стоит или приложение скрыто.

## Форматы и экспорт

Декодирование входного файла выполняет сам браузер. JPEG/PNG/WebP/AVIF, MP4/MOV/WebM и другие обычные форматы работают там, где их поддерживает установленный Safari/Chrome/Edge/Firefox. HEIC/HEIF обычно доступен на Apple-устройствах.

- **Авто:** до 4096 px по длинной стороне для фото, до 1920 px для видео.
- **1080p:** до 1920 px.
- **4K:** до 3840 px.
- **Оригинал:** без апскейла, с защитным лимитом 8192 px.
