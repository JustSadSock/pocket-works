# Ограничения Blockies (обновлено 19.10.2026)

Реализация в Pocket Works остаётся экспериментальной. Развитие, критерии приёмки и порядок работ — в [ROADMAP.md](./ROADMAP.md).

## Устранено кодовым изменением v0.1.1 (нужен браузерный приёмочный прогон)
- Повторный RAF после перезапуска/выхода и невидимая пауза после ухода вкладки в фон.
- Мобильный touch и геймпад могли обращаться к чужому слоту в PocketNet.
- Онлайн-перезапуск создавал локальную партию без серверного рестарта; теперь игрок явно возвращается к комнатам.
- Сетевой nickname/room-name вставлялся в `innerHTML`; теперь через `textContent`.
- Ready в лобби мог отображаться без подтверждения сервера.

## Открыто
- Выход / обрыв связи одного игрока сбрасывает сетевую партию всех в лобби. Нужна фиксированная нумерация слотов, reconnect + server-side rematch; не решать локальными хаками.
- Не поддерживается продолжение локальной игры после reload (хранятся настройки).
- По онлайн-режиму нужны двухбраузерные / долгие прогоны, WebKit и режим плохой связи. Обязательные проверки не завершены.
- Клиент и PocketNet сервер используют две копии Player; возможен регрессионный дрейф правил.
- Touch кнопки ещё не поддерживают удержание по DAS/ARR, gamepad не повторяет удержание.
- Нет version/sequence в сетевом снапшоте, честного сервера тиков, server-side сохранённых реплеев.
- Профилирование FPS и глубокий визуальный аудит не проведены.

## Обязательные ограничения
- Не менять чужие игры и Pocket Works shell.
- PocketNet server modules immutable: при изменении `server/module.ts` запускать `node scripts/build-pocketnet-modules.mjs --snapshot`, не перезаписывать опубликованные v1/v2.
- Прежде чем выпускать новую сборку — `health`, `deploy:site`, Playwright Chromium/WebKit и запуск двух клиентов одновременно.
