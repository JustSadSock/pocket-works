# Blockies 0.2 — состояние реализации и ограничения

## Реализовано
- Сетевая партия на общем серверном поле PocketNet (до 4 игроков), последовательные авторитетные действия и полные состояния.
- При выходе одного участника его фигура снимается, остальные продолжают свою партию; управление комнатой переходит следующему игроку.
- Общая пауза и перезапуск завершённой партии по команде ведущего; повторный раунд остаётся в той же комнате.
- Возврат после временного обрыва PocketNet восстанавливает текущую комнату и раунд (если сохранена сессия браузера).
- Управление касаниями: одиночные шаги, удержание движения и soft drop, отмена при прерывании; поддержка планшетов и поворота.
- Приглашения по ссылке и ручному коду комнаты.
- Regression suite: `node --test apps/blockies/tests/board.test.mjs`; проверка неизменяемых server snapshots: `npm run pocketnet:check`.

## Оставшиеся ограничения
- Сохранение и продолжение **локальной** одиночной партии после полной перезагрузки пока отсутствует. Настройки сохраняются.
- WebKit/iOS и длительная настоящая многопользовательская сессия по Wi-Fi/мобильной сети требуют отдельной проверки на устройствах: серверные и синтаксические тесты не подтверждают отсутствие проблем рендеринга на реальном устройстве.
- Если все подключённые участники закрыли вкладки, партия не имеет активного источника команд `pulse`, её течение на сервере возобновится с ограниченным шагом после подключения.
- Изменения в серверной логике выпущены в immutable версии `v2`; комнаты на `v1` продолжают использовать `v1` до завершения. Никогда не редактировать уже опубликованные версии.
