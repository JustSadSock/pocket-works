# Blockies 0.4 — Stack Club

Совместный тетрис с одной общей доской, тремя режимами: одиночный, локальный на 2–4 игроков и онлайн на 2–4 игроков.

## Интерфейс

- Светлая, контрастная оболочка и просторное поле без декоративных мини-карточек; цельные экраны входа, выбора режима, комнаты, настроек и результатов.
- На телефоне: узкая панель следующей фигуры и большое поле; в онлайне широкое поле (14–22 столбца) использует всю доступную ширину.
- В альбомной ориентации: игровое поле в центре, тач-контролы слева, счёт и следующие фигуры справа.
- Два блока сенсорных кнопок: движение (удержание работает), поворот и моментальный сброс. На поле можно касаться для поворота и свайпать горизонтально/вниз для точных шагов.
- На ПК остаются клавиши, настройки раскладки и геймпады.
- Видимые предупреждения о пропаже соединения, пауза и готовность комнаты.
- Автосохранение соло (включая точное состояние RNG) и восстановление после закрытия вкладки.

## Проверки

`node --test apps/blockies/tests/board.test.mjs`; `npm run pocketnet:check`. Server module `v2` immutable. Физические Android/iOS + длительный мультиплеер требуют дополнительного испытания.

## 0.4.1 — серверные достижения Blockies

Девять испытаний распределены по четырём уровням сложности. Достижения
проверяются по авторитетным снимкам движка PocketNet (прогресс линий,
мультиочистки, цепочка комбо, командные очки). Выдача производится только
через защищённый канал PocketNet → Pocket Social; повторные события и пульсы
не дублируют награды. Все активные участники общего поля получают
командные достижения за совместный матч.

В игре доступна кнопка «Награды» со списком условий и статусом проверки.
Профиль получает 4 титула, 2 авторских SVG-головных убора, фон
«Блочная сетка», рамку «Тетрамино», аксессуар на плече. Косметика
защищена серверной проверкой владения, доступны только открытые предметы.

Для честности одиночные/локальные результаты пока **не** выдают профильные
награды: клиентский счёт сам по себе не является доказательством.
Для доступа к наградам требуется вход в Pocket Works и сетевая партия.
Проверка: `npm run test:blockies:awards`.

## 0.4.2 — PocketNet и приглашения друзей

- Приглашения Pocket Social открывают комнаты с полным UUID, а восьмизначные коды продолжают работать.
- Ссылка-приглашение имеет приоритет над сохранённой комнатой при восстановлении соединения.
- В лобби есть «Позвать друзей» через Pocket ID и отдельная ссылка для гостей.
- При переходе в другую комнату клиент корректно освобождает прежнее место.
- Сетевые тесты: `node --test apps/blockies/tests/network.test.mjs`.

## 0.5.0 — Персональные шахты фигур

В кооперативе на 2–4 человек над общим полем расположен отдельный вход у каждого игрока: ширина **4 клетки**, глубина **2 клетки**, цвет владельца, ник и предпросмотр следующей фигуры. Входы распределены детерминированно, всегда отделены друг от друга хотя бы одной колонкой и совпадают для локальной и сетевой симуляции.

Каждая новая фигура возникает строго по центру своего входа. Если её начальные клетки заняты, владелец выбывает, но остальные участники продолжают играть; сервер больше не ищет запасную позицию на поле. Одиночный режим использует прежние правила. Серверная версия **v3** закреплена отдельно, предыдущие комнаты продолжают работать на своих версиях.

В локальном кооперативе разрешено задавать имена игроков; они сохраняются для следующих сессий. В сетевой комнате отображаются имена PocketNet.

Отладчик открывается клавишей **Backquote** (та же клавиша, что «Ё», слева от «1») и позволяет открыть все основные экраны, паузу, результаты и список наград, а также проверить состояние игроков, входов и подключения.

Проверка: `node --test apps/blockies/tests/*.test.mjs` и `npm run pocketnet:check`.
