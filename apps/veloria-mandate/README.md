# VELORIA // MANDATE

Полноценная мобильная стратегия внутри Pocket Works о губернаторе вымышленной островной колонии Велория в 1887–1890 годах.

## Центральная механика

Игра хранит две реальности: фактическое состояние колонии и официальную картину, которую губернатор отправляет Аурелианской империи в квартальных депешах. Приукрашивание отчётов повышает благосклонность метрополии, тревожные доклады могут выбить помощь, честность уменьшает расхождение и риск аудита. Долгая ложь становится самостоятельным стратегическим долгом.

## Симуляция

- 6 районов с населением, производством, инфраструктурой, богатством, беспорядками, болезнями и контролем;
- 6 фракций, которые имеют собственные силу и лояльность;
- 6 процедурных персонажей с характерами, интересами, коррупцией, влиянием и памятью;
- экономика, торговля, еда, цены, долг, коррупция, неравенство, армейское жалование и внешнее давление;
- меняющийся курс и стабильность метрополии;
- события появляются из текущего состояния систем, а решения могут создавать отложенные последствия.

## Партия

Мандат длится 36 месяцев. В месяц можно подписать один крупный указ, затем мир делает собственный ход. Каждый третий месяц требуется депеша метрополии. Возможны автономная хартия, имперская карьера, торговая республика, железный протекторат, нейтральное завершение срока, отзыв, банкротство или распад реальной власти.

## Mobile / PWA

- shared `mobile-runtime`;
- shared versioned storage capability;
- shared audio feedback capability;
- shared update manager + isolated service worker cache;
- landscape-first layout с portrait fallback, safe areas и touch targets;
- автосохранение при каждом значимом действии, `pagehide` и suspension;
- офлайн после первого успешного запуска.

## QA

`tests/sim.mjs` прогоняет 30 партий на разных seeds и стратегиях (`economy`, `reform`, `iron`, `balanced`, `reckless`), проверяя наличие нескольких финалов, возможность победы и возможность поражения.

Локально: `node apps/veloria-mandate/tests/sim.mjs`. Исполняемый runtime собирается из app-local текстовых частей загрузчиком `app.js`, чтобы приложение оставалось Quick runtime без корневых зависимостей.
