# KŌAN · Mahjong Dojo

Мобильный тренер закрытого японского риичи-маджонга для Pocket Works. Основная цель первой версии — не симулировать всё правилообразие сразу, а качественно научить фундаменту: структуре руки, сянтэну, укеирэ, ожиданиям, риичи и базовым яку.

## Режимы

- **Академия** — шесть интерактивных уроков с проверками и последовательным открытием.
- **Лаборатория** — бесконечные 14-косточные задачи. После сброса приложение считает сянтэн, укеирэ и показывает лучшие альтернативы.
- **Стол** — закрытая раздача против трёх ботов. Есть риичи, цумо, рон, три уровня силы и разбор собственных сбросов.
- **Кодекс** — компактная шпаргалка по костям, форме, яку и базовой стратегии.

## Ограничение учебного стола

Версия 0.1.0 намеренно тренирует **закрытую** игру: чи/пон/кан и полноценный расчёт фу/платежей пока не симулируются. Интерфейс прямо сообщает об этом, чтобы не выдавать упрощённую модель за полные правила.

## Технически

Приложение — Quick app без внешних зависимостей. `mahjong-core.js` содержит расчёт стандартного сянтэна, чиито:цу, кокуши, укеирэ, анализ сбросов и базовое распознавание закрытых яку. Прогресс хранится в `pocket-works:mahjong-dojo`, оболочка подключает общий mobile runtime, update manager и Workshop Mode. Service Worker кэширует весь shell для офлайна.

## Проверка

Из корня репозитория:

```bash
node --check apps/mahjong-dojo/app.js
node --check apps/mahjong-dojo/mahjong-core.js
node --check apps/mahjong-dojo/sw.js
npm run registry:check
npm run validate:all
npm run prepare:site
npm run validate:site
```
