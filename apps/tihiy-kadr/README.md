# Тихий кадр · 1.7.0

Локальная лаборатория удаления голосов (до 90 секунд видео) с двумя самостоятельными нейросетями.

* **Open-Unmix UMX-HQ** — быстрый режим по умолчанию (пользовательский замер ~5 с на 90-секундной сцене).
* **SCNet** — качественный режим (пользовательский замер ~150 с на такой же сцене).

## Полностью переключаемые DSP-эксперименты

После одного инференса выбранной модели отдельный браузерный Worker один раз рассчитывает три независимых слоя:

1. **Спектральная очистка** — мягкое частотное ослабление остаточной энергии там, где вокальный стем активен.
2. **Адаптивный центр стерео** — динамически подавляет центр только во время обнаруженного голосового сигнала; отключается для моно.
3. **Мягкая спектральная реконструкция** — дополнительное маскирование на основе энергии голоса и остатка.

Все три тумблера **включены по умолчанию** и переключаются после прогона без нового запуска нейросети и без повторной FFT-обработки. Элементы меняют лишь итоговое сведение заранее рассчитанных дорожек. Индивидуальные настройки сохраняются у каждого результата в текущем браузерном сеансе. Можно также одним нажатием выключить/включить всё для A/B и регулировать интенсивность вычитания до **150%** (105–150% экспериментально, может ухудшить музыку). Регулятор силы адаптивного центра по умолчанию 35%.

Важно: «Мягкая реконструкция» — **отдельный DSP-алгоритм**, а не изменение внутренних EM Wiener-итераций библиотеки Open-Unmix. Изменение самих итераций Wiener потребовало бы дополнительной обработки модели и нарушило бы мгновенный A/B. Поскольку слои спектральной очистки рассчитываются для базового 100%-го вычитания, изменение силы вокального вычитания масштабирует заранее рассчитанные поправки, а не запускает FFT заново.

Сохраняются оригинал, вариант без голоса, удалённая часть, сравнение Open-Unmix/SCNet, CSV, экспорт WAV и видео. Экспорт использует текущий набор эффектов. Время ONNX и дополнительной подготовки DSP отображаются раздельно. Никаких платных API, CUDA, серверной обработки пользовательских файлов или дополнительных нейросетей.
