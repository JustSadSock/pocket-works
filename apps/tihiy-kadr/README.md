# Тихий кадр · 1.6.0

Встроенная браузерная лаборатория удаления оригинальных голосов из видеосцены (до 90 секунд).

## Два независимых режима

- **Open-Unmix UMX-HQ**: быстрый вариант по умолчанию. Пользовательский тест на 90-секундном отрезке занял примерно 5 секунд.
- **SCNet**: более тщательная обработка; на том же ПК 90 секунд заняли около 150 секунд. Чуть лучше удаляются остаточные голоса, меньше теряются фоновые звуки.

Оба режима работают непосредственно на исходной дорожке. MRX, SCNet-large и цепочки из нескольких нейросетей не устанавливаются.

## Сценарий

Загрузить локальное видео → выбрать фрагмент → один из двух режимов → прослушать оригинал, очищенный звук либо удалённую часть → настроить интенсивность и дополнительное подавление центра (при необходимости) → скачать WAV или видео с очищенным звуком. Можно сохранить CSV с фактическими временами, RTF и оценкой времени для 90 секунд.

Результаты двух моделей сохраняются в пределах открытой вкладки на текущем фрагменте, повторный запуск модели переиспользует сохранённый вокальный стем. Видеофайл и PCM никуда не отправляются; только разрешённые ONNX-веса скачиваются через same-origin edge PocketWorks. Используется WASM, никаких CUDA или внешних API.

Реальные времена и точность могут отличаться на других сценах и устройствах. Обе модели предназначены для отделения вокала от музыки, поэтому нельзя гарантировать сохранение всех эффектов.
