# КАУЗА

Мобильная офлайн-first лаборатория причинных систем для Pocket Works.

## Основной сценарий

1. Открыть готовую систему или пустую модель.
2. Потянуть фактор вверх или вниз, чтобы применить внешний контрфактический шок.
3. Запустить модель и наблюдать, как последствия распространяются по положительным и отрицательным связям с задержками.
4. Редактировать исходные уровни, инерцию, шум и структуру связей.
5. Назначить главный результат, посмотреть его трассу, устойчивость и события.
6. Запустить скан рычагов и поиск усиливающих либо балансирующих петель.

Модель хранится локально в `pocket-works:causa:state`. Импорт и экспорт используют JSON-схему `causa-model` версии 1.
