# РАСКЛАД

Мобильный Pocket Works-инструмент для случайной компоновки изображений на один лист A4.

## Основной сценарий

1. Добавить сразу несколько изображений через системный picker или drag & drop.
2. Получить случайную плотную раскладку без каких-либо пересечений, с сохранением пропорций и разницы случайных размеров.
3. Настроить слайдером плотность 0–100%: меньше — больше воздуха, больше — меньше пустого места. При изменении плотности seed композиции сохраняется.
4. Нажать «Перерандомить» для новой композиции.
5. Экспортировать lossless PNG размером 2480×3508 px — печатный размер A4 при 300 DPI.

## Качество и память

- Экранное превью использует отдельные миниатюры до 560 px.
- Оригинальные File-объекты остаются нетронутыми.
- При экспорте оригиналы декодируются по одному и сразу рисуются в финальный холст, поэтому пачка больших фотографий не держится одновременно в распакованном виде.
- Автораскладка использует MaxRects-подобную упаковку: пересечения запрещены жёстко, а пустое место сокращается общим масштабированием всей случайно выбранной композиции.
- Относительная разница случайных размеров сохраняется: алгоритм не превращает лист в одинаковую сетку.
- Плотность управляет одновременно допустимым общим масштабом, внешними полями и межкарточными зазорами; пересечения при этом всегда запрещены.
- Настройка плотности сохраняется в `pocket-works:rasklad:density`; значение по умолчанию — 85%.
- Автораскладка не увеличивает изображение выше его нативного разрешения относительно 2480×3508.
- PNG кодируется без JPEG-пережатия. В файл добавляется pHYs-метадата 300 DPI (11811 px/m), поэтому печатные редакторы видят физический размер A4 корректно.

## Ограничения

- До 60 изображений на один лист.
- Форматы зависят от декодеров текущего браузера. PNG/JPEG/WebP поддерживаются широко; HEIC/HEIF зависит от платформы.

## Проверка

- node --check apps/rasklad/app.js
- node --test apps/rasklad/layout-core.test.mjs
- npm run registry:check
- npm run prepare:site
- проверить загрузку 1, 6, 20 и 60 изображений;
- проверить несколько перерандомиваний;
- проверить итоговый PNG: строго 2480×3508 px;
- проверить мобильный Chromium/WebKit и повторный офлайн-запуск.
