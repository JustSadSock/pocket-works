# Rivals / Свой стиль

Полный интерактивный доклад для JustSadSock (`1480038980`) и Hioydfts (`1689724361`). Срез данных: **21 октября 2026**. Самостоятельное приложение Pocket Works; хостинг и регистрация — штатный конвейер репозитория.

## Что внутри

10 глав: обзор, герои, прогресс по сезонам, команда, уровень, скрытый вклад, карты, развитие, лаборатория и источники. Фильтры аккаунта, режима и размера выборки; сезонные графики; реальные восстановленные дуэты; механическая совместимость, тактические сценарии, план следующих игр, локальные отметки, экспорт JSON и печать главы.

Последние выводы добавлены в «Развитие»: Гамбит — основной приоритет пользователя, Локи — второй опорный герой, Адам — перспективная проверка переноса QP в ranked. Пени и Стрэндж сопоставлены по одному сезону с оговоркой о малой выборке. Предпочтения Яси учитывают зависимость от точности и хедшотов, а не только класс героя.

## Запуск

Сервер из корня репозитория: `python -m http.server 8765`, затем `/apps/rivals-field-notes/`. Не открывать через file://. Установка доступна через браузер; оболочка, данные и графики кэшируются после первого успешного посещения. Портреты героев — необязательные внешние изображения RivalsMeta; офлайн анализ работает без них. Внешние источники требуют интернета.

Локальные отметки используют только `pocket-works:rivals-field-notes:`. Worker и manifest ограничены каталогом приложения; обновления — через общий update manager. Другие приложения и их данные не затрагиваются.

## Данные и ограничения

`data.js` — карьерные таблицы; `maps.js` — карты и ранги; `research.js` — 228 сезонных строк, история двух аккаунтов и 1250 стандартных совпадений дуо (342 ranked, 908 QP). `content.js`, `update-content.js`, `extended.js`, `verdict.js` — выводы, механика, методика и рекомендации. Данные не обновляются автоматически.

Публичные профили: https://rivalsmeta.com/player/1480038980 и https://rivalsmeta.com/player/1689724361. Полные ссылки на гайды и источники приведены в главе «Источники». Авторские права на героев Marvel принадлежат их правообладателям; портреты загружаются с исходного ресурса, здесь не распространяются.

Совпадение карточек не гарантирует сертифицированный журнал одной команды: общего постоянного ID нет, смены героев не раскрыты. Карьерные и сезонные суммы иногда расходятся. QP и ranked не смешиваются для выбора победителя. Среднее по внешней выборке не объявляется медианой. Скрытый вклад описан качественно: точного общего балла импакта без реплеев нет.

## Проверка

`node scripts/build-registry.mjs --check`; `node scripts/validate-visual-direction.mjs --app=rivals-field-notes`; app-owned browser flow: `node apps/rivals-field-notes/qa/journey.mjs` при работающем сервере. Автоматическая smoke-проверка описана в `qa.plan.json`.
