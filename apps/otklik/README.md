# ОТКЛИК

ОТКЛИК — автономная мобильная лаборатория для сравнительного анализа акустики помещения. Пользователь ставит точки на плане комнаты, запускает короткий логарифмический свип через динамик телефона и получает карту разборчивости речи, низкочастотного избытка и времени затухания.

## Основной сценарий

1. Указать размеры прямоугольной комнаты.
2. Коснуться плана и положить телефон в выбранную точку.
3. Запустить четырёхсекундный замер без наушников.
4. Повторить в других местах.
5. Переключать карты, открывать частотные отпечатки и сравнивать две точки.

## Что измеряется

- относительный фон в dBFS до запуска сигнала;
- восьмиполосный спектральный отпечаток от 63 Гц до 8 кГц;
- низкочастотный избыток относительно среднего диапазона;
- отношение ранней энергии к поздней;
- приближённое время затухания по спаду остаточной энергии;
- доверие к измерению на основе отношения сигнал/шум и клиппинга.

Оценки предназначены для сравнения точек на одном устройстве. Они не заменяют калиброванный SPL-метр, измерительный микрофон или профессиональный RT60-анализ.

## Технология

Quick PWA без внешних зависимостей. Используются Web Audio API, `getUserMedia`, `ScriptProcessorNode` как совместимый мобильный канал сбора PCM, собственный radix-2 FFT, Canvas 2D, localStorage, JSON-импорт/экспорт и изолированный Service Worker.

## Приватность

Запись микрофона анализируется в памяти устройства и не отправляется по сети. Сырые аудиоданные не сохраняются.
