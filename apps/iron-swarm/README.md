# ЖЕЛЕЗНЫЙ РОЙ

Landscape-first Enhanced Pocket Works survivor на Babylon.js.

Главная механика — видимый вращаемый риг вокруг ремонтного меха. Левый палец ведёт мех, правый разворачивает весь билд. Оружие, щиты и служебные модули занимают реальные позиции на риге, поэтому сборка влияет не только на цифры, но и на то, какой стороной игрок встречает толпу.

## Цикл

- двигаться по компактной индустриальной пустоши;
- поворачивать риг и использовать геометрию модулей против роя;
- собирать лом/опыт;
- выбирать один из трёх реальных модулей или улучшений;
- пережить нарастающий директор угрозы;
- уничтожить Crusher и завершить забег.

## Техника

- Babylon.js, фиксированная 3D-камера и логика движения в плоскости XZ;
- собственная лёгкая толпа с uniform spatial grid, импульсами и без rigid body на каждом враге;
- pooled Babylon instances для врагов, снарядов и лома;
- процедурные spring/recoil-анимации рига и модулей;
- процедурный Web Audio без внешних ассетов;
- сохранение мета-прогресса и незавершённого забега в namespaced localStorage;
- `window.__AI_TEST_STATE__` для gameplay QA.

Сборка и PWA-выход генерируются стандартным Enhanced pipeline Pocket Works.
