# Vertical slice refinement — QA and owner review

Prior 2797c22: native 6/6, browser 7/9, both mobile failures at camera pan while the full inspector obscured the touch point (artifact 15024401810). Compact selected coverage Chromium portrait 70.22%, landscape 75.27%, tablet 86.75%, desktop 85.22%; WebKit 69.87%, 74.39%, 86.27%, 84.67%. Previous transparent-canvas FPS is not comparable to visible compositor timing. Original field was too dominated by trees, heraldic markers and low-contrast soldiers.

Refinement collapses inspector on explicit camera mode, provides visible camera toggle, preserves exact pan assertion and adds no-order-mutation assertion. Chromium CDP uses native simultaneous touch contacts. WebKit public Playwright touchscreen supports native tap but not native multi-touch; the two-pointer path is tested through DOM PointerEvents and must not be described as hardware/native WebKit pinch. Real device approval is outstanding.

Batched silhouettes at medium scale; two-dimensional evenly distributed visual samples, smaller trees, stronger soldier silhouettes, larger and more separated touch handles. No changes to physical data or combat rules. Visible field benchmark uses actual engine frames and normal HUD with replay, moving camera and zoom samples; programmatic camera paths are not human input. Input latency measured separately with actual test input to completion of next draw. JS heap where supported; not total process RAM. Seven Laboratory projects preserve base troop specs, demonstrate contacts, shots, actual disorder/rout, three-unit withdrawal, real reserve arrival and a ford. They are QA fixtures, not new player scenarios.

Owner review (10–15 min): open standalone.html locally, start Greyford, move a regiment and try an overlapping deployment; set a four-regiment front, undo and redo; change zoom, switch camera mode, use two fingers on a phone; select infantry, tap a destination, drag center and rotate/spread/depth handles, use the expanded tools and conditional stage; give cavalry a separate route; submit two or more turns, scrub a replay, inspect result/events. Evaluate legibility, touch precision, accidental orders, battlefield atmosphere, and whether the map rather than UI feels dominant. Standalone uses exact engine; session is in memory, no persistence in this isolated route. No owner approval, deployment, new mechanics or changes to other modes asserted.
