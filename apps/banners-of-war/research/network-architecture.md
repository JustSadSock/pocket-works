# War Against Men — candidate network architecture
Pocket ID verification at existing same-origin Worker; no new credentials. Each match has its own SQLite-backed Durable Object, with an account index instance of the same class. Shared PocketNet has a 256 KiB state budget and global mutation queue. Match requests serialize per room, not globally.
Two acceptances of a SHA-256 scenario digest precede deployment/planning. All orders are validated. Durable readiness lock precedes alarm execution. State and history commit in one SQLite transaction. Clients never supply results. Pinned engine v1 contains exact 0.7.0 dependencies; new versions must not overwrite it.
Pre-finish projections contain observations and dated friendly reports, no enemy draft or HQ. Full recorded state and orders are released only after finish if allowed. Separate replay/planning deadlines and persistent account journal. Initial provisional caps: 60 regiments including guards, 1880×1300 m, 1 MB request, 24 indexed rooms/account, 8 creations/day. Polling stops in hidden tabs. No production capacity or deployment confirmed.
