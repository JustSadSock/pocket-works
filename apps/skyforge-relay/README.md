# Skyforge Relay

Original co-op raid with reactor, three terminals, energy orbs, three enemy archetypes, command-drone boss, pulse/dash/shoot/interact and shared win/loss conditions. Authored sprite and texture assets are retained. PocketNet runs the original authoritative simulation with serialized Map state and stable entity IDs; inactive input expires. A separate offline practice mode runs the same module locally and saves its state. Touch controls mirror the original actions.
