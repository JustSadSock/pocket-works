# ШЕВЕЛЬ

Самостоятельное Pocket Works-приложение для рисованной 2D-анимации. Один редактор совмещает рисованные экспозиции (cels), интерполированные ключи трансформаций, произвольные суставы/деформации и неразрушающее squash/stretch.

## Управление

- **Рисовать:** штрихи на выбранном объекте. Для отдельной фигуры кнопка «+ Объект».
- **Двигать:** выбрать рисунок касанием и перетащить на нужном кадре; положение превращается в ключ. «→ Действие» создаёт конечный ключ через указанное число кадров.
- **Суставы:** касание рисунка создаёт управляющий узел; перетаскивание узла задаёт ключевой изгиб. Деформация рассчитывается по близости контрольных точек к штрихам, поэтому не требует распознавания анатомии.
- **Кадры:** кнопки «Чистый кадр» и «Копия» создают отдельные экспозиции на текущем кадре.
- **Клавиатура:** пробел — воспроизведение, стрелки — кадры, D/V/J — инструменты, Cmd/Ctrl+Z/Y — отмена/повтор, Delete — удалить объект.

## Данные

Сохраняются локально в `localStorage`, пространство `pocket-works:shevel`; JSON импорт/экспорт позволяет резервировать и переносить проекты. PNG и GIF генерируются локально без сети. 12 FPS по умолчанию, до 240 кадров.

## QA

Основной поток: запуск готовой анимации → выбрать объект → добавить действие → перетащить в конце → покадрово дорисовать → создать и переместить сустав → экспортировать GIF → обновить страницу и увидеть проект. Проверять мобильный Safari, Chrome, desktop, отсутствие вертикальной прокрутки и ориентации.
