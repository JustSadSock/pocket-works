# ОСИ: Склад
Отдельное приложение Pocket Works, перенос идей [Axis-Pals-Warehouse](https://github.com/JustSadSock/Axis-Pals-Warehouse).
Один игрок управляет вертикалью (W/S), второй — горизонталью (←/→). Каждая команда двигает обоих грузчиков на одну клетку, но стены блокируют каждого независимо. Победа — поставить бирюзовый и терракотовый блоки на соответствующие цели.
- Локально: на одной клавиатуре или одном смартфоне доступны обе панели осей. Есть отмена хода, подсказка и перезапуск.
- PocketNet: комната строго на 2 игрока, сервер контролирует роли, состояние, лимит ходов и победу; вход по коду или ссылке, реконнект и выход в меню.
- Генерация: детерминированный seeded random, гарантированно достижимые цели путем стартового walk, затем BFS для кратчайшего маршрута; три лимита сложности. 12 уровней кампании и бесконечные смены.
- Сохранение: рекорд кампании, текущая бесконечная смена, звук и сложность через localStorage. Сеть и роль через PocketNet.
- Проверка: node --test apps/axis-pals/engine.test.mjs.
- Публикация: обязательно запинить серверный файл в pocketnet/module-versions/axis-pals/v1.ts и добавить в modules.lock.json; основной Worker подключит модуль при деплое main.
