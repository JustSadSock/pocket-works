# ОСИ: Склад — звуковой почерк
Мир: матовый листовой металл, пластиковые скользящие салазки, фанерные грузовые блоки, тугие направляющие.
Действия: сухое шуршание и приглушённый металлический удар при перемещении; низкий глухой отказ у стены; лёгкая верхняя обертональная волна при завершении маршрута.
Характер: сухой, короткий, физический, тактильный, тихий. Не использовать универсальный одинаковый sine-beep для каждого события.
Реализация: короткий управляемый шумовой импульс через bandpass и отдельный слегка расстроенный резонанс через triangle/sine oscillator, с независимыми огибающими. Звук отключается в заголовке, контекст запускается только после жеста пользователя, а события дублируются геометрической анимацией, текстом и тактильной обратной связью.

## v1.3 — контактная механика
- `sound.js`: локальный Web Audio, созданный по событию действия, без загрузок и внешних аудиофайлов; `createSoundPlayer` создаёт AudioContext лениво.
- `press`: короткий щелчок кнопки (45 мс).
- `move`: негромкий треугольный спуск механического привода (115 мс) с фильтрованным шумом колёс.
- `collision`: более низкий удар с шелестом проскальзывания (125 мс).
- `blocked`: короткий приглушённый отбойный контакт (145 мс), без длинного проигрывания.
- `win`: небольшой светлый интервал/подъём (230 мс), без торжественного джингла.
- Один псевдослучайный, но воспроизводимый шумовой буфер на контекст; небольшая варьируемость высоты тона у повторяющихся команд.
- Звук никогда не нужен для решения: направление видно по кнопке и импульсу, удар — по деформации и локальной отметине.
- Выключенный в заголовке звук не инициализирует граф; пульсация и частицы отключаются при `prefers-reduced-motion`; тактильная вибрация остаётся опциональной способностью устройства.
