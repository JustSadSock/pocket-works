# RIVALS DNA — Pocket Works

Самостоятельное приложение — тест игрового почерка в **Marvel Rivals**. Не является официальным продуктом Marvel / NetEase.

## Прохождение
- Полный режим: 18 основных вопросов (8 выборов, 6 шкал, 4 тактических сценария) + 2 адаптивных уточнения.
- Быстрый режим: 10 основных вопросов + 2 адаптивных.
- Система анализирует **предпочтения**, **механическую доступность** и **боевые решения** отдельно.
- Для всех 54 персонажей рассчитываются индексы интереса и удобства освоения; доступны объяснения и топ-10.
- До 20 независимых локальных профилей игроков, экспорт и импорт JSON.
- Оценка героя (-2 … +2) и 3-матчевый чек-лист влияют на последующий рейтинг; есть сравнение дуэтов двух завершённых профилей.

## Данные и оговорки
Базовая таблица героев адаптирована из приложения RIVALS FIT LAB в том же репозитории. Обновлена до 54 героев / сезона 10.5; добавлен Gorr the God Butcher. Профили — экспертные эвристики, не статистический инструмент, не оценка текущей меты и не подтверждённая вероятность понравиться. Модель не собирает личные игровые аккаунты и не требует сети.

## Сборка
Quick runtime без сторонних зависимостей. Для тестов:
\`\`\`bash
node --test apps/rivals-dna/tests/engine.test.mjs
\`\`\`

## Хранение
\`pocket-works:rivals-dna:state:v1\` — локальное состояние. Синхронизация между устройствами не заявлена: пока её заменяет безопасный экспорт/импорт JSON. PWA offline cache: \`rivals-dna-v1.0.0\`.
