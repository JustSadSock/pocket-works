# ПЛАСТ

Оригинальная мобильная voxel-песочница для Pocket Works. Проект не использует код, текстуры, модели, звуки или товарные знаки Minecraft/Mojang; сходство ограничено жанровыми принципами voxel sandbox и привычной схемой мобильного управления.

## Основной сценарий

1. Создать процедурный мир с рельефом, пещерами, водой, лесом и живыми существами.
2. Исследовать его в горизонтальной ориентации телефона: ходить, бегать, красться, прыгать и плавать.
3. Ломать блоки, удерживать установку для быстрого строительства и вести пальцем по девятислотовому хотбару.
4. Следить за здоровьем, сытостью и воздухом; находить яблоки и получать провиант.
5. Переживать день и ночь, строить и продолжать с сохранённого состояния.

## Технологии

- WebGL 2 fragment ray casting по 3D integer texture.
- Процедурные текстуры, освещение, звёзды, вода и трещины блоков.
- CPU-проекция составных cuboid-моделей животных поверх voxel-сцены.
- Собственная мобильная физика, survival-показатели и multi-touch controls.
- Локальное RLE-сохранение мира, позиции, времени, еды и настроек.
- Процедурный Web Audio, частицы, анимации и виброотклик.
- Изолированная offline-first PWA с mobile runtime и Workshop Mode.

## Архитектура запуска

`app-core.js`, `app-living-*`, `app-world-*` и `app-ui-*` загружают игровые подсистемы. `app.js` устанавливает mobile runtime Pocket Works и затем запускает классический игровой цикл из `app-main.js`, сохраняя общий lexical scope модулей игры. `polish.js` добавляет удержание для серийной установки, выбор слота ведением пальца, полноэкранный landscape-вход и короткую визуальную подсказку. `workshop.js` подключает диагностику и безопасный сброс данных.
