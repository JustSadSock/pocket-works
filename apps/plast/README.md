# ПЛАСТ

Оригинальная мобильная voxel-песочница для Pocket Works. Проект не использует код, текстуры, модели, звуки или товарные знаки Minecraft/Mojang; сходство ограничено базовыми жанровыми принципами voxel sandbox и привычной схемой мобильного управления.

## Основной сценарий

1. Создать процедурный мир.
2. Исследовать его в горизонтальной ориентации телефона.
3. Ломать и устанавливать блоки, выбирать материалы в хотбаре или инвентаре.
4. Плавать, прыгать и строить.
5. Закрыть приложение и продолжить с сохранённого состояния.

## Технологии

- WebGL 2 fragment ray casting по 3D integer texture.
- Процедурная генерация рельефа, пещер, воды и деревьев.
- Собственная мобильная физика и touch controls без внешних зависимостей.
- Локальное RLE-сохранение мира.
- Процедурный Web Audio и виброотклик.
- Изолированная offline-first PWA.
