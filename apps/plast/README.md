# ПЛАСТ

Мобильная voxel-песочница для Pocket Works, спроектированная вокруг горизонтального сенсорного экрана.

## Основной сценарий

1. Создать процедурный мир или продолжить сохранённый.
2. Перемещаться плавающим стиком и осматриваться жестом по правой части экрана.
3. Удерживать кнопку разрушения, чтобы сломать выбранный блок.
4. Выбрать материал в хотбаре или творческом инвентаре и поставить его на соседнюю грань.
5. Мир, позиция, хотбар и изменения блоков сохраняются автоматически.

## Технология

Рендерер написан на WebGL2 без внешних библиотек. Мир хранится в `R8UI` 3D-текстуре, а фрагментный шейдер выполняет voxel DDA-raycast. Это уменьшает число объектов и draw calls на мобильном устройстве. Физика, генерация, взаимодействия, звук и сохранение работают в `app.js`.

## Управление

- Левый стик: ходьба, при полном отклонении — бег.
- Жест по миру: обзор.
- Стрелка: прыжок или всплытие.
- Кирка: удерживать для разрушения.
- Куб: поставить выбранный блок.
- Нижняя панель: выбор блока; кнопка слева открывает весь инвентарь.
- Клавиатура: WASD, пробел, мышь, ЛКМ ломает, ПКМ ставит, E открывает инвентарь, Esc ставит на паузу.

## Данные

Хранилище: `pocket-works:plast`. Сохраняются seed, изменения относительно процедурной базы, позиция игрока, направление камеры, хотбар и настройки. Сервис-воркер кеширует только файлы приложения и общие файлы Pocket Works, необходимые для запуска.
