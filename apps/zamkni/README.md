# ЗАМКНИ

Небольшая пошаговая логическая игра, созданная как первый полноценный потребитель общего PocketLAN runtime.

## Правила

Поле состоит из 5×5 квадратов. Игроки по очереди проводят одну свободную линию между соседними точками. Если линия замыкает одну или две клетки, игрок получает эти клетки и сразу делает ещё один ход. Когда все 60 линий заняты, выигрывает игрок или команда с наибольшим количеством клеток.

## Режимы

- **Против ИИ** — локальная партия с эвристическим соперником, умеющим забирать готовые клетки и избегать очевидной отдачи цепочек.
- **1v1** — два устройства через PocketLAN.
- **2v2** — четыре устройства, команды A/B ходят в порядке A → B → A → B; очки партнёров складываются.
- **Трое** — каждый сам за себя.
- **Четверо** — каждый сам за себя.

## PocketLAN

Игра импортирует `../../shared/capabilities/lan.js` и не знает конкретный сетевой транспорт.

- При наличии native provider используется `discoverRooms()` / `joinRoom()` с автоматическим локальным обнаружением.
- В обычном PWA используется zero-server WebRTC fallback: хост создаёт `PWL1...` приглашение, клиент возвращает ответ, после чего игровой трафик идёт напрямую между устройствами.
- STUN, TURN, cloud signaling и глобальный интернет для матча не используются.
- Хост является авторитетным: клиенты отправляют только `move-request`, хост валидирует ход и рассылает полное детерминированное состояние.
- Для 3–4 игроков браузерный fallback0строит звезду: каждый клиент имеет прямое DataChannel-соединение с хостом.

## Файлы

- `game.js` — чистые правила, подсчёт клеток, командный счёт и валидация состояния.
- `ai.js` — эвристический ИИ без рандома.
- `app.js` — UI, сохранение одиночной партии и интеграция PocketLAN.
- `game.test.mjs` — smoke/unit проверки правил и ИИ.

## Проверка

```bash
node apps/zamkni/game.test.mjs
node --check apps/zamkni/game.js
node --check apps/zamkni/ai.js
node --check apps/zamkni/app.js
node --check apps/zamkni/sw.js
npm run registry:check
npm run validate:all
```

Для browser multiplayer дополнительно проверить два реальных устройства в одной Wi-Fi/hotspot сети: полный offer → answer → complete flow, 1v1 и хотя бы один матч на 3–4 устройствах.
