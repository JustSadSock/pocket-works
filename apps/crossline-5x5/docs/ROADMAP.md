# 5×5 Arena — дорожная карта после аудита

Версия-источник: 1.2.0 · аудит: 18.10.2026. Цель — законченная дуэль без потери правил оригинала, с честным одиночным режимом, надёжным PocketNet и выразительным исполнением пяти команд.

## Приоритеты

### Этап 1 · Надёжность · v1.3.0 — реализован

- [x] **ИИ:** убрана информация о скрытых действиях игрока при выборе ответа; введена оценка нескольких предполагаемых планов соперника, уровни сложности отличаются шириной поиска, шумом и устойчивостью к риску.
- [x] **Серверная сдача:** сообщение `forfeit`, запись победителя в счёт, сохранение завершённого матча и причины окончания в снимке комнаты.
- [x] **Уход игрока:** при осознанном выходе из активной комнаты победа оставшемуся игроку, удержание стороны A/B и счёта, возможность заселения освободившегося места и реванша.
- [x] **Протокол:** неизменяемая версия PocketNet `v2`; существующие комнаты `v1` остаются доступными в клиенте. Для v1 ограничение фиксирования сдачи явно обозначено.
- [x] **Восстановление:** сессионные токены и идентификатор комнаты мигрируют из `sessionStorage` в приложение-локальный `localStorage`; при входе повторно применяется авторитетное состояние и подтверждённый план только своего игрока.
- [x] **Разрыв соединения:** отдельный постоянный статус отсутствия собственного соединения или соперника. Сам разрыв соединения не считается сдачей.
- [x] **Локальная приватность:** отправленный план A не показывается игроку B при передаче устройства; экран передачи восстанавливается при повторном запуске. Черновые команды одиночной и локальной игры сохраняются.
- [x] **Регрессии:** серверная сдача, приватность, переподключение по состоянию/замена игрока, существующий v1 и корректность планов ИИ.
- [ ] **Ручной E2E на реальном PocketNet** с двумя браузерами, длительным отсутствием второго игрока и сценариями браузерного закрытия — до подтверждения в эксплуатации.

Критерии приёмки: не допускается утечка неподтверждённого плана второго игрока, потеря счёта при добровольном выходе, ошибочный перевод обрыва WebSocket в сдачу и переходы в игру с невалидным планом. Процедура: запустить два браузера, завершить/сдать несколько партий, отключить сеть с уже отправленным планом, восстановить сеанс и начать реванш.

## Ограничения обратной совместимости

- Имя продукта `5×5 Arena`, URL и технический slug `crossline-5x5` сохраняются.
- `pocketnet/module-versions/crossline-5x5/v1.ts` не менять: старые комнаты зависят от хеша этой версии.
- Серверное поведение `forfeit` и сохранение итогов после выхода поддерживаются начиная с `v2`, не могут добавляться задним числом в существующую v1.
- Исторические локальные сохранения `saved` читаются и без поля `draft`; партионные данные сервера не мигрируют в несуществующие матчи.

## Известные риски

- При недоступном сервере нельзя подтвердить сдачу. UI предлагает дождаться соединения или осознанно выйти без подтверждения; это не должно отображаться как засчитанная победа.
- PocketNet сохраняет место при потере WebSocket, поэтому пока нет честного механизма автоматически присуждать победу по неподтверждённому отсутствию игрока. Нужен авторитетный статус отключения/правило тайм-аута в серверной версии.
- Баланс ИИ требует дополнительных длинных серий против людей: снижение числа поражений на раунд не эквивалентно уровню человеческой игры.
