# Trafficity · дорожная карта 1.1–1.5

Источник: JustSadSock/traffic. Архитектура: PocketWorks Quick PWA + PocketNet Durable Objects. Завершённые пункты означают наличие кода; проверки выпуска фиксируются отдельно.

## v1.1 — Тактическое ядро
- [x] Пересечения маршрутов, приоритет с ротацией, не более одной активной машины на перекрёстке.
- [x] Встречный разъезд по широким улицам, блокировка по узким переулкам.
- [x] Остановка с парковкой вне полосы движения; заторы сохраняют очередной сегмент маршрута.
- [x] Два общих заказа с одноразовым вознаграждением, сроком и заменой.
- [x] Счёт оригинала: максимальная награда за быстрые персональные доставки.
- [x] Регрессии на collisions, одноразовую награду и смежность перемещений.
Чекпойнт: ни телепортаций, ни двух начислений за общий заказ, ни скрытого перемещения.

## v1.2 — Живой город
- [x] Seed меняет дорожную топологию, а не только положение геометрии.
- [x] Три разных района, река с двумя мостами, широкие улицы и переулки.
- [x] Разные крыши, трубы, парки и деревья; собственная миниатюрная иллюстрация.
- [x] Значки конкурирующих заказов и визуальные сигналы пробок.
- [x] Статическая карта кэшируется отдельно от подвижных автомобилей.
Чекпойнт: город узнаваем без текста, хотя тактический граф остаётся полностью читаемым.

## v1.3 — PocketNet и удобство
- [x] Зум 1–2,6×, кнопки, колесо мыши, двухпальцевые жесты, сброс.
- [x] Прямые маршруты к общим заказам, отмена, остановки и клавиатура.
- [x] PocketNet v2: приватные снимки своих маршрутов, повторный вход с тем же seat.
- [x] Возобновление сетевого матча после reload и защита от бесконечного ожидания.
- [x] Пин immutable v2 без изменения комнат v1.
Чекпойнт: маршруты другого игрока не раскрываются ни по событию, ни при входе.

## v1.4 — Стратегия
- [x] Срочные, грузовые и стандартные публичные заказы с разными сроками и наградами.
- [x] Три сложности: кратчайший путь, анализ заторов, перехват заказов.
- [x] Выбор между объездом, личной доставкой и общим контрактом.
- [x] Регрессионные симуляции с фиксированными seed.
Чекпойнт: кратчайший путь перестаёт быть гарантированно лучшим.

## v1.5 — Качество
- [x] Анимация передвижения, звуковая обратная связь с выключателем.
- [x] Локальная векторная графика без внешних шрифтов, изображений и серверов графики.
- [x] Ограничение DPR, кэширование фона, мобильная ориентация, safe-area.
- [x] Node-тесты процедурных миров, ИИ, столкновений и приватности PocketNet.
- [x] Актуальные визуальные скриншоты Chromium/WebKit на ПК и телефоне. GitHub Actions Universal QA, 4 конфигурации.
- [x] Два браузерных клиента, приватные маршруты, переподключение, тайм-аут и полный 30-ходовый матч. 9/9 Playwright, 16/16 движок/сервер.
- [x] Сборка PocketNet Edge, серверных модулей, visual QA и production packaging прошла.
- [ ] Проверить успешное развёртывание на Cloudflare после слияния с main. Общий health репозитория имеет старые проблемы других приложений.
Чекпойнт: матч можно закончить, восстановить, начать заново и выйти в оболочку.

## Идеи после 1.5
- Пешеходы и погода, только если они не мешают читаемости дорог.
- Расширенная карта и больше игроков лишь после проверки длительности матчей.
- Долгие асинхронные партии и уведомления — отдельная схема серверных дедлайнов.

## v1.6 · Дорожная геометрия, адаптивный ИИ и анимация (18.10.2026)

- [x] Магистрали сохраняют непрерывную топологию, а мосты продолжают широкие улицы.
- [x] Узкие дороги и широкие дороги выглядят по-разному в соответствии с фактическими правилами проезда.
- [x] Мосты имеют отдельные перила, опоры и соединяются с набережной, а не перекрывают граф асфальтовыми полосами.
- [x] Тактический и экспертный ИИ перестраивают маршрут при угрозе затора и сохраняют цель до доставки.
- [x] Умная маршрутизация работает и для игрока, но никогда не заменяет вручную нарисованный путь.
- [x] Неразрешимый встречный затор переходит в замедленный совместный разъезд после двух ходов.
- [x] Плавное движение за 920 мс, смещение корпуса, пыль, стоп-сигналы, водные блики и дым.
- [x] PocketNet v3 с приватной целью навигации и сохранением v1/v2.
- [x] Регрессионные проверки мостов, 120 генераций, манёвра разъезда, стабильных целей ИИ и приватности.
- [x] Актуальные визуальные скриншоты Chromium и WebKit, полная 30-ходовая партия и двухклиентская игра. Universal QA: 12/12 браузерных сценариев и игровой движок — успешно.
- [ ] Производственный билд Cloudflare после слияния.
