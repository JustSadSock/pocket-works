# ПЕРЕКОС — v0.1.0

Отдельная игра PocketWorks: магическая дуэль против ИИ, короткие раунды до 4 побед и первые 12 рун. Без обязательного входа и сети; настройки и текущая серия сохраняются локально.

## Управление

- Мобильный: левый стик; справа держать «Шар», нажать «Щит» или «Рывок». Коснуться арены — указать направление выстрела.
- ПК: WASD/стрелки — идти, Space или левая кнопка мыши — «Шар», Q/E — «Щит», Shift/F — «Рывок», мышь — прицел.
- Пауза и возврат в PocketWorks доступны из боя; из меню и финала есть явная ссылка в библиотеку.

## Архитектура

- `core.mjs`: фиксированный STEP=1/60 и seed-based случайность. Состояние полностью JSON-сериализуемое, управление ИИ и 12 рун. Не обращаться к DOM.
- `app.js`: input, доступный Canvas renderer, HUD, переходы матч → руны → матч → результат, сохранения, аудио.
- `styles.css`: полный рост экрана без прокрутки, безопасные зоны, мобильные цели касания.
- `sw.js`: независимый офлайн-кэш; при недоступности Pocket ID разрешён гостевой режим.
- `tests/core.test.mjs`: детерминизм, здоровье, раунды, события, завершение матчей, bounded projectile effects.

## Границы версии

Доступен **локальный тренировочный режим против ИИ**, не онлайн PvP. В v0.1 две базовые магии («Шар» и «Щит») плюс «Рывок». Проект не притворяется, что 36 рун, серверный PocketNet или редактор гримуара уже готовы. Используется предварительная палитра по Pocket ID preset; полноценная привязка рисованных аватаров запланирована в v0.3.

План: [docs/PEREKOS-ROADMAP.md](../../docs/PEREKOS-ROADMAP.md).

## Проверка

```bash
node --test apps/perekos/tests/core.test.mjs
node --check apps/perekos/app.js
node --check apps/perekos/sw.js
npm run registry:check
npm run validate:all
```

Реальный телефон + Chromium/WebKit: начать игру, двигаться, кастовать, выиграть/проиграть раунд, взять руну, завершить серию, начать реванш, уйти в библиотеку, проверить кэш офлайн и перезапуск страницы.

Не считать снимки экрана, созданные без запуска приложения, визуальной проверкой.
