# Третья клятва

Мобильная top-down narrative action-RPG для PocketWorks, основанная на старой текстовой кампании про Клятвенного рыцаря.

## Vertical slice 0.1

Первая глава строится вокруг цепочки:

**капелла → скрытый проход → крипта → Зал Клятв → два камня → след босого человека → дверь в башню**

Цель — не демо механик, а короткий законченный фрагмент с полноценной подачей.

## Принципы

- портретный mobile-first интерфейс;
- Phaser/WebGL внутри canvas;
- без внешних CDN и сетевых зависимостей;
- визуал собирается из детального процедурного 2D, слоёв света, частиц, теней и постэффектов, а не из примитивных debug-форм;
- текст короткий и предметный, без generic fantasy prose;
- скрытые проверки характеристик;
- бой на 1–3 противников;
- состояние и прогресс сохраняются локально;
- обязательный офлайн-режим после первого запуска.

## Art direction

Холодный камень, почти чёрное дерево, тусклое железо и янтарный бытовой свет. Холодный синий зарезервирован для сверхъестественного, чтобы каждое его появление оставалось событием.

## QA contract

Игра публикует `window.__PW_TEST_STATE__` и сохраняет ключевые фазовые значения: сцена, здоровье, режим, инвентарь и сюжетные флаги.
