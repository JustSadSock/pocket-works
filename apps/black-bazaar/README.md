# Чёрная барахолка — механический прототип

Отдельное приложение PocketWorks для 2–6 игроков. 2D без свободного передвижения. Визуальный дизайн **намеренно не утверждён** и будет выбран позже по референсам автора.

## Уже работает на уровне игрового ядра

- Комната PocketNet, ход игрока, девять раундов и серверный финальный рейтинг.
- Золото, кристаллы, детали, секретные квоты, персонажи и связи.
- Два стартовых предмета, 12 названий и по 2 варианта свойств.
- Дополнительные свойства отдельных разновидностей: неизбежные
  отложенные проклятия, одноразовая защита срочного задания,
  бонус за перепродажу и скидка на экспертизу.
- Ставки, частичная проверка лота, ломбард, подработка.
- Прямые сделки между любыми двумя игроками (ресурсы, артефакты, подарки) с адресным раскрытием условий.
- Три волны срочных заказов с одинаковой стоимостью в единицах подработки и штрафная система.
- Полноценные контрпредложения с изменяемыми условиями и лимитом пересмотров.
- Запечатанный артефакт брокера один раз за ход (75 золота), раскрытие свойств после покупки.
- Разбор предмета на 2 детали с уничтожением артефакта.
- Первая успешная публичная продажа за свой ход приносит продавцу +1 деталь.
- Полноценный анонимный рынок: раунды 2/5/8, скрытые ставки, посредник, 10% комиссия, сохранение непроданных предметов.
- Перепаковка с сохранением ID и свойств; платная экспертиза исходного названия и минуса.
- Серверный дедлайн хода с автоматической проверкой через сигнал любого подключённого клиента. Если отключились все, таймер проверится при возобновлении связи.
- Восстановление игровой комнаты после перезагрузки или повторного открытия браузера с отдельным пространством хранения сессии.
- Шесть несимметричных по составу, но сопоставимых по трудозатратам личных квот.
- Регрессионные и экономические smoke-тесты 120 партий; игровые показатели требуют живой проверки.
- Персональный сетевой снимок без чужих секретных свойств.
- Три публичные волны торговых событий на раундах 4, 6 и 8.
- Послематчевые метрики успешных действий и тест полного матча с четырьмя независимыми клиентскими представлениями.

## Ограничения текущей версии

Это **механическая альфа**, а не законченный дизайн. Нельзя пока делать долговые расписки и произвольные модификации эффектов. Анонимный рынок, перепаковка и проверки уже работают. Достоверные метрики баланса и живые сетевые плейтесты ещё не завершены. Онлайн-партии требуют опубликованного PocketNet-модуля; офлайн-загрузка оболочки не означает офлайн-мультиплеер.

## Проверка

\`\`\`sh
node --experimental-strip-types --test apps/black-bazaar/mechanics.test.mjs
node --check apps/black-bazaar/app.js
node --check apps/black-bazaar/sw.js
npm run pocketnet:check
npm run registry:check
\`\`\`

Для ручной проверки: запустить два приватных браузера, создать комнату, подключиться по коду, начать партию, выставить лот, сделать ставку, принять её, предложить и подтвердить частный бартер, завершить все девять раундов, убедиться в расхождении приватных снимков и одинаковом финальном рейтинге.
