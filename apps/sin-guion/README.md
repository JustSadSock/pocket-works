# Sin Guion — устный модуль испанского

Полноценное офлайн-приложение PocketWorks: **60** проверяемых вопросов по шести грамматическим разделам и **7** реальных тем устного модуля. Не требует AI, API, сервера или учётной записи.

## Основной цикл
- Стартовый экран показывает текущий день семидневного плана и предлагает начать грамматику, говорение или карточки.
- «Грамматика» → краткое объяснение → 8 упражнений с тремя вариантами → результат → повторение ошибок.
- «Говорение» → вопрос по одной из семи тем → 30 секунд на подготовку → 90 секунд ответа с записью микрофона (при доступности) → самопроверка по 5 критериям.
- «Пробный модуль» → три темы подряд с разными вопросами, отдельная самопроверка каждого ответа, итог.
- «Фразы» → карточки с активным воспоминанием перевода, интервальные повторения.
- «Прогресс» → реальные попытки и результаты, история устных ответов с локальными аудиозаписями и удалением.

## Надёжность
- Прогресс, оценки и история: localStorage с пространством имён pocket-works:sin-guion:v1.
- Записи: IndexedDB, база pocket-works:sin-guion:recordings, доступна только на текущем устройстве.
- Если пользователь не разрешает микрофон или браузер не поддерживает MediaRecorder, доступен полноценный сценарий с таймером и ручной оценкой.
- Вторая загрузка и работа без сети обслуживаются собственным Service Worker.
- Относительные ссылки ведут обратно к оболочке PocketWorks.
- Субъективная устная речь не получает придуманной автоматической оценки: процент — доля отмеченных пользователем пунктов.
- Никакого PocketNet, синхронизации между устройствами или генеративной модели нет.

## Технологии
Vanilla JS ESM + CSS, общий PocketWorks mobile-runtime, update-manager и workshop-mode. Никаких новых корневых зависимостей.

## Испытания
npm/Node: node --test apps/sin-guion/tests/engine.test.mjs.
Universal QA: apps/sin-guion/qa.plan.json, автоматический smoke на PR; visual suite для главного экрана, грамматики и задания.
