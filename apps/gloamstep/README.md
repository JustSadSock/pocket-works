# GLOAMSTEP

Компактный портретный пошаговый рогалик для Pocket Works.

## Игровой цикл

- Процедурный этаж из комнат и коридоров.
- Передвижение свайпом по полю, экранной крестовиной или WASD/стрелками.
- Столкновение с врагом автоматически превращается в ближнюю атаку.
- После каждого действия игрока противники получают один пошаговый ответ.
- Между этажами выбирается одна из трёх реликвий.
- Пятый этаж заканчивается боем со Стражем Пепла.
- Смерть окончательная; текущий живой забег сохраняется локально после каждого хода.

## Враги

- **Глодатель** — слабый преследователь, действует каждый ход.
- **Тень** — умеет атаковать по прямой через несколько клеток.
- **Каменный страж** — медленный, но живучий и бьёт сильнее.
- **Страж Пепла** — финальный босс пятого этажа.

## Мобильный UX

Приложение использует общий `mobile-runtime`, безопасные зоны iPhone, Pointer Events, scoped gesture surface, отключаемый Web Audio, progressive haptics и адаптивный canvas с ограничением DPR. Есть отдельные текстовые ссылки возврата в Pocket Works на стартовом, паузном и финальном экранах.

## Offline / PWA

`sw.js` кэширует собственный shell приложения и только явно необходимые shared-файлы Pocket Works: mobile runtime и update manager. Cache prefix и storage namespace изолированы от остальных приложений.
