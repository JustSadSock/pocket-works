# Пресс · Pocket Works

Автономная утилита сжатия и архивации. Страница: `/apps/press/`.

## Функции

- Фото: массовое уменьшение JPEG/PNG/WebP/HEIC/HEIF/AVIF (если браузер декодирует исходный формат), выбор WebP/JPEG и трёх профилей качества. Если получившийся файл не меньше исходного — отдаётся оригинал.
- Видео: локальное перекодирование с ограничением длины 15 минут и размера 512 МБ. Используются MediaRecorder и Canvas.captureStream; формат итогового файла (MP4/WebM) зависит от реальных кодеков браузера. Дополнительная аудиодорожка через Web Audio поддерживается там, где работает захват аудио. Если API отсутствуют, показывается реальная ошибка, никакого фальшивого результата.
- ZIP: создание обычных ZIP32 (STORE/DEFLATE), импорт файлов и папок с сохранением относительных путей, чтение центрального каталога, распаковка с проверкой CRC32. Отклоняются опасные пути, зашифрованные, многотомные, ZIP64 и экзотические методы сжатия.
- Весь код и преобразование выполняются локально. Файлы не отправляются в сеть. Настройки качества/формата сохраняются в localStorage; сами файлы не сохраняются и исчезают при обновлении страницы.
- Кнопка «Скачать всё ZIP» для результатов пакетного сжатия. В режиме распаковки индивидуальная загрузка распакованных файлов; кнопка «Сохранить всё ZIP» загружает исходный архив для сохранения всех файлов одной загрузкой на мобильном устройстве.

## Ограничения

ZIP32: максимум 1024 файлов, 256 МБ на один распакованный файл и 512 МБ суммарно, при распаковке — проверка CRC32. Потоковая обработка ZIP без чтения всего архива в RAM, но каждый файл/результат преобразования читается целиком; на устройствах с малым объёмом RAM большие операции могут не пройти.
Видео зависит от аппаратных/программных возможностей движка и обрабатывается в реальном времени, не быстрее исходной длительности. Браузер может запретить сохранение звука или перекодировку отдельных MOV/HEVC; есть понятная ошибка и возможность повторить без звука. Фотографии могут потерять метаданные EXIF и при JPEG — прозрачность. Сервис не обещает lossless для фото/видео.
После скачивания пользователю нужно сохранить файл через системное меню, в частности в Safari/iOS.

## Технологии и проверки

Quick PWA, mobile-runtime, app-scoped service worker, Web Canvas, MediaRecorder, Web Audio, CompressionStream/DecompressionStream, локальный ZIP32 writer/reader, `node --test apps/press/zip.test.mjs`. Автоматические Playwright сценарии: `apps/press/qa/flow.spec.ts`.
