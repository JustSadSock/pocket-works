# ЗАМАЗКА — интернет-сервер за один запуск (Windows)

## Самый быстрый способ

1. Скачай INSTALL-AND-START.bat из этой папки: https://raw.githubusercontent.com/JustSadSock/pocket-works/main/apps/zamazka/server/INSTALL-AND-START.bat . Сохрани на рабочем столе. Либо запусти START-ONLINE.bat, если у тебя уже скачан весь репозиторий.
2. Запусти двойным щелчком. Скрипт сам скачает исходники сервера ЗАМАЗКИ из main, установит локальные пакеты ws и esbuild, скачает переносимый Node.js 22 при необходимости и cloudflared из официального релиза.
3. В окне появится ссылка вида https://something.trycloudflare.com . Она автоматически скопирована в буфер обмена.
4. Открой Pocket Works → ЗАМАЗКА → Создать комнату → вставь эту HTTPS-ссылку в поле «Адрес PocketNet» → введи имя → создай комнату.
5. Нажми «Скопировать ссылку» в комнате и отправь её друзьям. Им ничего устанавливать не нужно. Они открывают ссылку, вводят имя и присоединяются. Для матча нужны минимум два человека.

**Не нужны домен, проброс портов, роутер, Cloudflare-аккаунт или VPS.** Node.js и cloudflared скачиваются без прав администратора в папку ZAMAZKA-SERVER рядом с BAT.

## Ограничения

- Это бесплатный тестовый сервер на личном компьютере, не 24/7 хостинг. Он работает, пока открыто окно BAT и включён ПК.
- Домен trycloudflare.com случайный, меняется после рестарта. Новый адрес требуется вставить в игру перед созданием новой комнаты.
- Комнаты и гостевые токены сохраняются локально. Активные соединения прерываются при перезапуске.
- Quick Tunnel официально предназначен для разработки, без гарантий uptime. При желании позже можно перейти на именованный Cloudflare Tunnel со своим доменом.
- Игра рассчитана на доверенную компанию. Не публикуй публичный адрес сервера открыто.

## Что делает скрипт

INSTALL-AND-START.bat получает файлы по HTTPS из GitHub, затем запускает local/start.ps1. Сервер HTTP/WebSocket слушает только 127.0.0.1:8788, cloudflared открывает наружу зашифрованное исходящее соединение; пробрасывать порты не нужно.

Локальный сервер использует исходный игровой модуль из server/module.ts без копирования логики. При запуске он компилируется с esbuild. Используются Guest sessions, PocketNet wireVersion 1, /health, /session, /ws, хранение состояния комнат, голосование, таймеры и серверный подсчёт очков.

- START-ONLINE.bat — запуск из полного репозитория.
- START-LOCAL-TEST.bat — диагностика только localhost, без внешнего HTTPS.
- npm test внутри папки local — smoke-тест HTTP, WebSocket и комнаты на двух или трёх игроков.
- Логи лежат в local/local-logs/, состояние в server/local-data/. Нельзя заливать данные игроков в GitHub.

Если порт 8788 занят, закрой прежний сервер. Если Cloudflare не выдал адрес, открой local/local-logs/tunnel-errors.log. Если случилась ошибка загрузки пакетов, проверь интернет и повтори запуск.

Постоянный домен пока не нужен. Позже можно настроить свой поддомен через Cloudflare Tunnel.

## Исправление подключения из двух вкладок (v1.4)

Один браузер может участвовать в разных игровых сессиях одновременно: каждая вкладка имеет отдельный гостевой токен и собственное имя, даже если обе открывают один домен Pocket Works. При клонировании вкладки приложение обнаруживает уже использованный токен и запрашивает новый. При смене ника приложение также создаёт новую личность при следующем подключении. При открытии ссылки приглашения поле комнаты и сервера заполняется автоматически.

После обновления клиента до версии 1.4 закрой старые вкладки, открой две новые и **создай новую комнату**: старые комнаты содержат ранее сохранённого общего гостя и не могут автоматически различить двух игроков. Сам сервер из прошлого запуска не обязательно перезапускать, если он продолжает работать. Если имя меняется во время текущей игры, оно начнёт действовать только после следующего подключения.

Проверка: в `server/local` выполнить `npm test` — тестируются локальные WebSocket-комнаты, два независимых PocketNet-клиента с разными именами, две вкладки с копированным sessionStorage и изменение имени.
