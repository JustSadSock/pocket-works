# ЗАМАЗКА

Самостоятельная installable Quick PWA-игра в Pocket Works: party-дедукция и рисование. Библиотека генерируется локально в artworks.js — 50 оригинальных векторных произведений десяти направлений, без CDN и сторонних изображений.

## Правила

1. Создатель приглашает от 2 до 7 друзей (всего 3–8 игроков).
2. 25 секунд все рассматривают пять оригиналов, которые можно увеличить.
3. 105 секунд каждый восстанавливает повреждённый участок одной назначенной картины.
4. Для каждого автора по очереди на 20 секунд показывают одинаковую пятёрку; только одна картина подменена его работой. Автор не голосует.
5. После завершения всех голосований девять секунд на каждого автора последовательно демонстрируются подделки и оригиналы.
6. После 1, 3 или 5 раундов победа по очкам за маскировку и зоркость. Счёт нормализуется под размер комнаты.

## Сеть

Серверные файлы server/module.json и server/module.ts реализуют PocketNet module contract, а клиент использует shared/capabilities/net.js. Необходимы реально работающий HTTPS-сервер, публикация модуля и ввод адреса игрового PocketNet origin в настройках. Клиент не имитирует создание комнаты, а показывает ошибку при отсутствии инфраструктуры.

Pocket Server на этапе присоединения передаёт целое состояние комнаты, поэтому данная версия рассчитана на доверенные дружеские комнаты. При исследовании WebSocket-трафика игрок может увидеть ответы; это не защищённый режим для турниров. Чтобы получить серьёзный рейтинг, платформе понадобится серверное приватное хранилище для игровых секретов.

Фазы ограничены абсолютными серверными deadline; при их достижении приходящий pulse продвигает фазу. Сервер проверяет полномочия, очередность голосования, допустимые полотна и структуру штрихов, а также ограничивает их количество.

## Автономная тренировка

Самостоятельный офлайн-режим: пять оригиналов, один повреждённый, восстановление, сравнение, сохранение в личный фонд. Без фальшивых ботов и без сервера. Черновики мазков восстанавливаются после перезагрузки.

## Интерфейс

Живописный музейный зал с отдельной светлой рабочей поверхностью, прикреплённый Canvas, кисть, сухой контур, фактура, пипетка, ластик, масштабирование и двухпальцевый жест. Переход к Pocket Works виден постоянно.

Установка через app.config.json и manifest.webmanifest, service worker кэширует собственные файлы, shared mobile runtime и net capability.

## Проверка

node --check apps/zamazka/artworks.js
node --check apps/zamazka/editor.js
node --check apps/zamazka/app.js
npm run registry:check
node scripts/validate-visual-direction.mjs --app=zamazka
node pocket-server/scripts/modules.mjs

Для полноценного online E2E необходимы сервер PocketNet и три независимых гостевых сессии.
