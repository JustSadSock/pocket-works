# РИКОШЕТ — лаборатория математического бильярда

Автономная Quick PWA в Pocket Works. Без внешних библиотек, сетевых запросов и общих изменений оболочки.

## Игра
- **Задачи:** 8 постепенно усложняющихся сцен. Столкновение с целевым датчиком засчитывается только после необходимого числа отражений; результат и лучший счёт сохраняются.
- **Лаборатория:** прямоугольник, круг, стадион и треугольник. Добавляй зеркала, бамперы, перемещай старт и датчик, стирай объекты, откатывай изменение, переключай физику и готовые установки.
- **Физика:** дискретная симуляция с шагом 1/120 с. Сплошные границы, отражение векторов по нормали, круговые препятствия, сопротивление, коэффициент сохранения скорости и опциональная гравитация.
- **Математика:** предварительный луч рассчитывается тем же интегратором, что реальный шар. Показываются угол, длина пути, время полёта и число отражений. В лаборатории есть «веер» соседних углов, показывающий чувствительность траекторий.
- **Управление:** потяни от шара в сторону желаемого полёта и отпусти для запуска; кнопка «Пуск» запускает по установленному углу; стрелки на клавиатуре меняют угол/мощность; пробел запускает, R возвращает шар.
- **Хранение:** локальные рекорды, настройки, набор лаборатории. Кнопка Workshop доступна через Ctrl/⌘ + Shift + W.
- **Навигация:** явный выход в Pocket Works в шапке и на экране завершения.

## Файлы
`physics.mjs` — независимая физика и предиктор; `app.js` — интерфейс/Canvas; `styles.css` — адаптивная композиция; `sw.js` — scoped offline cache; `tests/physics.test.mjs` — Node-тесты отражений.

Локальные проверки: `node --test apps/billiard-lab/tests/*.test.mjs`, `node --check apps/billiard-lab/app.js`, `npm run registry:check`, `npm run validate:mobile`.
