# ЧУШЬ! — игра нелепых коллажей

Онлайн party-игра PocketWorks для 2–8 игроков. Все участники получают один абсурдный сюжет и совершенно разные наборы из 18–22 SVG-объектов, составляют на собственных холстах изображения, затем анонимно голосуют и открывают авторство после подсчёта. Пять раундов.

* Каталог из 320 предметов: 64 авторских SVG-силуэта в восьми категориях, каждый с пятью узнаваемыми вариациями. Для честности каждому игроку в каждом раунде даются одинаковое число деталей и хотя бы две из каждой категории.
* Редактор позволяет добавить каждую из выданных деталей единожды, перетаскивать, вращать, зеркалить, масштабировать, менять уровень наложения, отменять действия и экспортировать SVG.
* PocketNet server module обеспечивает authoritative наборы, фильтрацию досок до голосования, таймеры, подсчёт очков, защиту от голосования за себя и 2-player альтернативу: поставить 1–5 баллов сопернику.
* Pocket ID nickname подтягивается при наличии аккаунта, гость также может играть.
* До публикации после сдачи собственная работа остаётся на экране. Сеть восстанавливает комнату; в личной палитре нет доступа к чужим наборам.

Серверные исходники: `server/module.ts`; Cloudflare snapshot должен быть зарегистрирован в `pocketnet/module-versions/chush/v1.ts` и `pocketnet/modules.lock.json` отдельным изменением платформы.
