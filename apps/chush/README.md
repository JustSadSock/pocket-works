# ЧУШЬ! — рисование нелепиц штампами

Онлайн игра для 2–8 игроков. Все получают одну абсурдную фразу, но персональные 18–22 кисти. Вместо готовых мини-сцен — **крупные залитые силуэты без декоративных наложений**, которыми можно рисовать прямо пальцем: нажать для одиночного отпечатка или провести для линии из отпечатков. Каждая кисть многоразовая.

- Каталог: 64 отдельных силуэта × 5 начальных цветов = 320 сочетаний, восемь тематических категорий. Выдача сбалансирована — одинаковое количество, по две кисти из каждой категории.
- Инструменты: смена цвета (8), размер, ластик, очистка с подтверждением, отмена целого мазка, экспорт SVG.
- Защита сетевой комнаты: PocketNet v2 проверяет, что используются только выданные символы, цвет и размеры валидны, и ограничивает рисунок 140 отпечатками. Вписываемся в лимит 16 KiB на сообщение.
- Голосование без показа авторов, раскрытие результатов и таблица очков. При двух игроках — выставление 1–5 баллов.
- Пять раундов по 2,5 минуты на рисунок, ник из Pocket ID и вход по коду/ссылке.

Новые комнаты работают на серверном модуле `pocketnet/module-versions/chush/v2.ts`, старые с v1 остаются закреплёнными на прежних правилах до завершения.
