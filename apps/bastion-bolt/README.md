# БАСТИОН: БАЛЛИСТА

Вертикальная мобильная 3D-мини-игра Pocket Works про осаду средневекового замка.

## Игровой цикл

1. Выбрать уязвимый узел замка касанием по сцене.
2. Настроить натяжение, угол и горизонтальную поправку.
3. Выбрать обычный, тяжёлый, зажигательный болт или каменный снаряд.
4. Наблюдать натяжение, выстрел, баллистический полёт и кинематографическое попадание.
5. Разрушать ворота, стены, башни и деревянные укрепления с разной прочностью.

## Технология

Небольшой самостоятельный WebGL-рендерер без внешних CDN и тяжёлых моделей. Геометрия, материалы, частицы, освещение и анимации создаются процедурно, поэтому приложение остаётся офлайн-доступным и пригодным для мобильного браузера.

## Управление

- Ползунки: сила, угол и горизонтальная поправка.
- Кнопки боеприпасов: тип урона и масса.
- Касание сцены: выбор цели; горизонтальный свайп: тонкая наводка.
- Камера: баллиста / общий вид; во время выстрела — сопровождение и акцент попадания.
- Сброс: возвращает параметры к базовым; восстановление замка доступно после выстрела.
