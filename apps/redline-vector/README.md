# REDLINE VECTOR

Первое лицо, три стилизованные трассы, аркадный дрифт, умные соперники, чемпионат и гонка с призраком.

This app is independently served from `/apps/redline-vector/`. Launcher and release metadata are owned by `app.config.json`; the app owns its manifest, service worker and local state.

Validate with `npm run validate` after building Enhanced apps, and exercise its main interaction in the Pocket Works mobile browser QA workflow.
