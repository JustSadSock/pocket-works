# Resident World Surface — qualification, not release

Origin: 463d7a4, artifact 15170782443. The two modes remain available; Copy is the default. Resident is accessible only through the localhost atlas-review API. It is not a published production renderer.

## Geometric proof
For a world point (x,y,z), fixed tilt t, c = sqrt(1-t²), camera center (X,Y), physical scale S and framebuffer viewport V:
- Px = Vx + Vw/2 + S(x-X)
- Py = Vy + Vh/2 - S((y-Y)c-(z-datum)t)
- clipZ = -((y-Y)t+(z-datum)c)/160

For identical scale/tilt/datum, a camera displacement shifts every projected point by a constant; the depth difference is constant and the depth order is unchanged if neither camera clips geometry. The source crop is (pad + SΔX, pad - ScΔY). Noninteger offsets, changed scale, region, LOD, knowledge or insufficient coverage cannot be cropped from the same raster. The isolated Node test verifies 3,600 projections, edge limits, fractional rejection, scale invalidation, and depth clipping guards. Floating-point shader arithmetic, antialiasing, derivatives, dithering, and depth quantization may still invalidate pixel equivalence. A geometric proof is not a raster proof.

## Prototype
RGBA8 texture plus depth buffer, 96 physical-pixel padding, nearest GPU framebuffer blit at unchanged raster phase. Bounded LRU: 48 MiB nominal attachment bytes, six entries maximum; actual driver memory overhead is not observable through WebGL. Region change disposes the GPU bank; adaptive motion LOD and restricted knowledge use fresh rendering. No readback or gl.finish in continuous motion loops. Separate diagnostic readback compares resident vs original raster with no pixel tolerance. If GPU evidence fails, do not enable the mode outside review.

## Architecture
WebKit integer translation does not always match fresh. Use a bounded exact-pose bank (32 MiB/eight entries, one current terrain identity) instead of translating raster output. It does not claim spatial translation reuse. Height queries memoize exact coordinate pairs for the current terrain and LOD (32,768 entries), without rounding; geometry and model assets remain unchanged. Canonical path commands or world-aligned tiles remain research alternatives, not claimed implemented. The legacy integer and fractional paths remain diagnostic controls.

## Immutable source identity and cooperative yield study
Material tiles may use exact identities of immutable `scaleTerrainSource` tile arrays when the complete shadow halo is covered by those source tiles. Identity tokens are monotonic per typed-array object and compared byte-for-byte; no hash authorizes a hit. If source coverage is incomplete, the cache falls back to compact native-byte snapshots only when the entire halo is present in the regional arrays; otherwise the tile is not cached. This permits halo sharing without pinning source arrays or duplicating them. The probe clears the upstream scale-tile cache before each Original Fresh and Incremental sequence, so cold, neighbor and return timings are paired fairly. Cooperative yields use a MessageChannel task when available, with a timeout fallback; timing and yield count remain recorded.


## Raster identity policy (2026-11-28)
The default Resident Surface uses a same-size framebuffer (`pad: 0`). Independent browser probes found same-size FBO build and blit pixel-identical to Fresh in Chromium and WebKit. Padded viewports change raster phase in WebKit; disabling dithering does not remove the differences. Padded experiments therefore remain diagnostic-only and use an explicit fresh fallback. Nonzero integer/fractional crops are never cache hits: the renderer builds a same-size FBO at the current camera pose instead. Exact same-pose reuse remains eligible. This policy trades spatial crop reuse for verified raster identity and reduces resident allocation size.


## Recovery: exact physical framebuffer and production baseline
The Copy baseline retains its drawing buffer again; the discard buffer is a review-only comparison. This preserves same-pose terrain reuse during simulation. The exact Resident candidate allocates the full physical drawing buffer and uses the original viewport origin and dimensions, not a viewport-sized FBO. The key includes physical origin, DPR and framebuffer size. Antialiased or invalid layouts fall back. Diagnostic padded targets retain a 96-pixel halo even when the candidate uses zero padding. Geography Review reports integration and historical/camera outcomes independently, and still fails when either fails. Camera admission requires both composition-delivery and independent RAF rates. No production Resident selection.
