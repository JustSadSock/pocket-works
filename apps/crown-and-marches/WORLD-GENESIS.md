# World Genesis: Geography v3 (experiment)
Frozen candidates: Erosion, Watersheds, Forge Relief, Patch and Structural Synthesis. Final scores: real Alpine 7, Patch relaxed 5, strict 4.5, Baked 4, Structural strict 3, relaxed 2.5. Original artifact 15057904225 contains seven DEM grids and provenance; acceptance-only canonical correction is retained but not selected by production or QA.
v1/v2 fingerprints recorded before generator edits in genesis-legacy-hashes.json, 42 size/version/shape combinations. Default newGame still uses v2. Explicit experimentalGeography:{approach:'structure'|'tectonic',detail:2|4|8} opts into v3. Saves record revision, method and resolution; no external DEM dependency in generation. Revision genesis-3.0.0 must remain immutable after a release. No automatic migration. Existing campaign systems remain unchanged.
The existing continental mask is retained; mountain heights are regenerated from either broad folding belts or branching ridge systems. Fine height, rainfall, incision and sediment redistribution precede priority-flood drainage. Coarse height and climate are aggregated from fine data; coarse routing is independently flood-resolved to preserve existing D8 contract. Coarse routing is not yet guaranteed to follow the fine valley at every boundary. Fine depressions are measured; lakes are not yet navigable or promoted to coarse water. Incision exports part of sediment, not a physically calibrated erosion simulation.
Research-only Baked Terrain adapter reads the same global fine field, not viewport reconstruction. Only fully revealed autonomous fixtures allowed; no production fog integration. Diagnostic tests compare overlapping source channels, not independent baked shadows. Existing Baked Terrain material/light shared across all rendered samples; v3 and v2 resolution 4/cell, real DEM resampled to 250m. Game cell=1km is an experiment assumption; vertical scaling differs between procedural and real elevation domains. No claim of geographic or artistic acceptance until original captures reviewed.
First phase: 3 regional fixtures and 2 methods; no 21-world gameplay expansion until art acceptance. Node regression measures 2/4/8 resolution and save reconstruction; browser captures 3 scales, 4 comparison types, maps and camera timings. Generation remains synchronous in this explicit experiment; profile before enabling interactive newGame. No new mechanisms or release.
