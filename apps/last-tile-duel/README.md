# ПОСЛЕДНЯЯ ПЛИТА

Самостоятельная простая тактическая дуэль Pocket Works. Сетка 7×7, два игрока, шаг, прыжок и толчок, матч до трёх выигранных раундов. Каждый тик разрушает клетку под игроком; третье пребывание превращает её в провал.

## Сценарий

Против бота — тренировка без сервера. Вызвать друга — создать комнату PocketNet и получить код/ссылку. Второй игрок входит по 8-символьному коду. Хозяин начинает при наличии двух игроков. Оба игрока выбирают направление до очередного тика; сервер одновременно разрешает действия, включая столкновения. При выходе из дуэли матч засчитывается оставшемуся.

Телефон: крестовина + кнопки Прыжок и Толчок. ПК: WASD или стрелки — направление, пробел — прыжок, E — толчок, Q/X — стоять. Перезарядка отображается рядом с действием. Звук можно отключить.

## Архитектура

- engine.js — чистые серверные/локальные правила, рендер не принимает решений.
- server/module.ts — PocketNet-обработчик команд и единственный источник сетевой победы.
- app.js — соединение, UI, тренировка с ботом и плавная визуальная интерполяция.
- В сети изменение направления сразу отображается локально, но отправляется вместе с одним клиентским pulse в секунду. Сервер учитывает обе команды и разрешает **не более одного тика в секунду** после краткого окна сбора команд; следующий срок nextAt=now+1000. После сна нет догоняющих тиков.
- Для новой игры есть неизменяемый PocketNet snapshot v1. Сервер не рендерит кадры.
- Локальный Service Worker сохраняет приложение и его shared runtime для повторного офлайн-запуска тренировки.
