# КАВИТАЦИЯ — лаборатория пузырька

Автономное приложение Pocket Works с замедленной визуализацией схлопывания кавитационного пузырька в воде при 20 °C.

## Основной опыт
1. Выберите «Свободная вода», «У стенки» либо «Мягкий импульс».
2. Изменяйте перепад давления (0.3–4 бар), радиус (0.25–2.5 мм) и расстояние до стенки (1.15–4.0 R0); стенку можно тянуть на изображении камеры.
3. Нажмите «Схлопнуть пузырёк»; используйте паузу, скорость и перемотку по графику. Кнопка импульса повторяет опыт после завершения.
4. Читайте рассчитанное время коллапса, минимальный радиус, график R(t). Выбор сохраняется локально.

## Научная область и честность визуализации
Радиус интегрируется методом RK4 с адаптивным временным шагом по сферическому уравнению Рэлея–Плессета. Заданы ρ=998.2 кг/м³, μ=0.001002 Па·с, σ=0.0728 Н/м, давление пара 2339 Па, небольшой неконденсируемый газовый остаток 5000 Па при R0, политропа κ=1.4. Давление окружающей жидкости растёт ступенью на Δp. По классификации модель не CFD: нет пространственного расчёта течения, сжимаемости, переноса тепла, разрушения пузыря, температуры в центре или давления на стенке.

Нарисованная волна после коллапса — иллюстративная. Форма пузырька и микроструя у стенки показываются качественно на основе геометрического отношения γ=d/R0; они **не являются** решением несимметричной задачи и не должны интерпретироваться как предсказание скорости или силы микроструи.

Для оценки используется классическая формула Рэлея t≈0.915 R0 sqrt(ρ/Δp). При газовом остатке время фактического минимума радиуса может отличаться.
