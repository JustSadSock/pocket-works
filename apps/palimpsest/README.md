# ПАЛИМПСЕСТ

Карманная лаборатория альтернативной истории для Pocket Works.

## Основной цикл

1. Коснуться державы на процедурной карте.
2. Использовать одно вмешательство: покровительство, смута, торговый путь или притязание.
3. Пропустить десятилетие и наблюдать автономные войны, союзы, торговлю, расколы и исчезновение государств.
4. Коснуться любого сохранённого года на ленте, стереть будущее и продолжить в новой ветви.
5. Каждые 120 лет получить итог эпохи и решить, продолжать ли летопись.

## Управление

- касание — выбрать державу;
- перетаскивание — панорамирование;
- щипок или кнопки `+` / `−` — масштабирование;
- `Вся карта` — вернуть исходный обзор;
- `Законы мира` — настроить частоту войн, смут и влияние торговли.

## Техническое

- Quick PWA без внешних зависимостей;
- Canvas 2D с адаптацией к DPR;
- сохранение через `pocket-works:palimpsest`;
- собственный Service Worker и кэш `palimpsest-v1.0.0`;
- общий mobile runtime, update manager и Workshop Mode;
- офлайн после первого успешного запуска.
