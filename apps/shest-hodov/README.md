# ШЕСТЬ ХОДОВ

Изолированное Quick PWA для PocketWorks. Шесть соревновательных мини-игр без случайных событий, с локальным ИИ и без сетевого сервера. В меню можно выбрать ИИ с тремя уровнями сложности или локальную игру на двоих. Два человека играют на одном устройстве; тайные приказы вводятся по очереди через экран передачи устройства.

## Включено

- Мост: Hex, шестиугольные связи на поле 7×7, первый путь между личными сторонами побеждает.
- Заражение: Reversi 8×8, полный захват по восьми направлениям, автоматический пропуск хода.
- Пропасть: движение на один шаг по ортогонали, покинутая клетка исчезает.
- Поворот: 6×6, поворот одного блока 2×2 плюс ход своей фишкой, гонка к противоположным краям.
- Влияние: 5 регионов, по 3 тайных жетона, 8 раундов, контроль большинства регионов.
- Протокол: 5×5, два тайных приказа роботу за раунд, одновременно разрешаемые столкновения, 8 раундов.

Все партии сохраняются в `pocket-works:shest-hodov:v1`; ненадёжное или несовместимое состояние игнорируется. Меню сохраняет незавершённую партию.

## Алгоритмы ИИ (v1.1.0)

- Мост: длины кратчайших связующих путей с проверкой ответов соперника.
- Заражение: позиционная оценка углов, мобильности и фишек; поиск minimax/альфа-бета.
- Пропасть: поиск на дереве ходов и оценка доступных областей, соседей и территорий.
- Поворот: перебор легальных пар «поворот + передвижение», на повышенных сложностях — расчёт опасного ответа.
- Влияние: анализ 35 законных распределений против 35 вероятных чужих; без чтения скрытого человеческого плана.
- Протокол: анализ 25 вариантов двух команд против 25 возможных программ человека, с точной симуляцией коллизий.

ИИ играет синими, человек — красными. Трудность регулирует глубину и тип оценки, но не использует случайные ходы. Прежние сохранения на двоих по умолчанию остаются локальными. Полная партия офлайн.

## Ограничения

Нет PocketNet, рейтинга, профилей и турниров. «На двоих» = передача одного устройства. Новая партия сбрасывает прежнюю; перед сбросом требуется повторное нажатие.

## Проверка

```sh
node --test apps/shest-hodov/core.test.mjs apps/shest-hodov/ai.test.mjs
node --check apps/shest-hodov/core.js
node --check apps/shest-hodov/ai.js
node --check apps/shest-hodov/app.js
node --check apps/shest-hodov/sw.js
npm run registry:check
```

Откройте `/apps/shest-hodov/`, проверьте все шесть режимов, перезагрузку в середине партии, выдачу устройства второму игроку, экран завершения и установку/offline reload.
