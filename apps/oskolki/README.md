# ОСКОЛКИ

Мобильная офлайн-игра на память внутри PocketWorks. Пользователь вставляет произвольный Unicode-текст или открывает UTF-8 TXT/MD-файл. Строки с нумерацией (1., 2), 3: и т. п.), маркированные строки и обычные непустые абзацы становятся заданиями. Перенесённые на следующую строку части нумерованного пункта объединяются.

После запуска исходные фразы не отображаются общим списком: одно предложение — один раунд, с перемешанными фрагментами и местами для сборки. Перенос можно выполнять касанием фрагмента либо менять порядок заполненных фрагментов. На проверке подсвечиваются правильно/неправильно стоящие части и показывается целая исходная фраза. Общий результат — доля фрагментов на правильных позициях, по всем заданиям; можно повторить только ошибочные.

Сессия (включая собранный черновик, задания и ответы) сохраняется в `localStorage` только на устройстве; отправки загруженного текста нет. Сброс требует подтверждения. Игровые тексты выводятся только через `textContent`.

Запуск: `apps/oskolki/index.html` через HTTP вместе с общим `shared/mobile-runtime.js`. Встроенный Service Worker кеширует собственные файлы и компоненты mobile/update runtime. Выход в PocketWorks — явная ссылка «PocketWorks» в любом состоянии.

Сценарии QA: UTF-8 кириллица/латиница/арабский/иероглифы; маркированные пункты; многословные и короткие строки; дублирующиеся слова; пустой ввод; сохранение после перезагрузки; повтор ошибок; длинная фраза и экран 320 × 568.
