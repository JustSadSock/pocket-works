# PIT LOOP

PIT LOOP — автономная наблюдательная мини-игра для Pocket Works. Игрок ничем не управляет: два минималистичных бойца постоянно проводят короткие поединки, сами выбирая дистанцию, атаки и защитные реакции.

## Основной цикл

- бойцы автоматически сближаются и удерживают рабочую дистанцию;
- доступны джеб, хук и удар ногой;
- ИИ может блокировать и отскакивать от входящей атаки;
- попадания дают урон, импульс и короткую реакцию;
- при нуле здоровья происходит нокаут;
- после короткой паузы автоматически начинается следующий раунд;
- счёт побед и выбранная скорость сохраняются локально.

## Управление наблюдением

- **Пауза / Продолжить** — останавливает и возобновляет симуляцию;
- **×1 / ×1.5 / ×2** — меняет скорость боя;
- **В Pocket Works** — возвращает в основной launcher.

## Технологии

Приложение использует Quick runtime Pocket Works, `shared/mobile-runtime`, shared versioned storage, Canvas 2D и общий update manager. Все файлы, PWA-манифест, иконка и service worker изолированы внутри `apps/pit-loop/`.
