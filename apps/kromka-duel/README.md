# КРОМКА: ДУЭЛЬ

Самостоятельная top-down дуэль для Pocket Works. Старую игру `apps/kromka` (гонку) не затрагивает.

## Игровой цикл
- Два сенсорных ввода: левый задаёт смещение за такт, правый — поворот клинка относительно текущего положения.
- За один такт клинок может повернуться максимум на 1.43 радиана, тело — пройти до 29 игровых единиц.
- 18 детерминированных шагов интегрируют движение и проверяют сегменты оружия, столкновения клинков и касание корпуса.
- Касание корпуса засчитывает очко. Одновременное касание не даёт очков; взаимная защита останавливает клинки.
- Первый до 3 очков выигрывает. 65 тактов — ограничение партии.
- В тренировке используется тот же движок и бот. В онлайне победу вычисляет PocketNet.
- Короткий повтор показывает серверную траекторию. Без постоянных потоков сетевых координат.

## Архитектура
- `engine.js`: чистая детерминированная физика и бот.
- `server/module.ts`: копия движка и отдельные авторитетные серверные правила для PocketNet.
- В `pocketnet/module-versions/kromka-duel/v1.ts` закреплён неизменяемый снимок серверного кода.
- Commit/reveal: обе стороны отправляют SHA-256 от такта, стороны, действия и nonce, а затем раскрывают команды. В состоянии комнаты до второй фиксации лежат только хэши.
- Если игрок не зафиксировал решение до дедлайна, ход нейтрален; отсутствие раскрытия после фиксации может стоить одного очка.
- Приложение поддерживает веб-комнаты, восстановление соединения, гостевые имена и локальную тренировку. PocketLAN не используется.

## Проверки
`node --check apps/kromka-duel/app.js`
`node --check apps/kromka-duel/engine.js`
`node scripts/build-pocketnet-modules.mjs`
`npm run registry:check`
`npm run prepare:site`

Ограничения: сетевой сервис требует опубликованного Cloudflare Durable Object. При большом пинге переход между тактами замедляется, но уже зафиксированные решения нельзя подменить.
