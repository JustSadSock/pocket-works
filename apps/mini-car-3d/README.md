# Mini Car 3D

Исходная площадка с GLB-моделью машины, Rapier 0.12, физическими ящиками, светом и джойстиком. По умолчанию одиночная езда работает без сети; создание/вход в комнату подключает общую серверную физику PocketNet до восьми водителей. WASD/стрелки либо джойстик.

Сборка: `npm ci --workspaces=false`, `npm run build --workspaces=false` из папки приложения. Браузер использует Rapier compat, сервер — ту же версию с предварительно собранным WASM. Vendor-папка неизменяема: опубликованные PocketNet-снимки ссылаются на её хешированный путь. Состояние мира сохраняется снимком Rapier между событиями; скрытая вкладка прекращает ввод.
