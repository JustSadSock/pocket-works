# Rivals Roulette

Мобильное offline-first колесо случайного персонажа Marvel Rivals для Pocket Works.

## Что умеет

- 53 уникальных героя актуального ростера Season 9.5 на 14 августа 2026 года.
- Фильтры: все, Vanguard/танки, Duelist, Strategist.
- Deadpool считается мультиролевым и попадает в каждый соответствующий фильтр.
- Режим без повторов до исчерпания текущего пула с автоматическим сбросом.
- Бан-лист с локальным сохранением.
- Серия из трёх последовательных выборов.
- История последних результатов.
- Полностью локальная работа без API и сетевых зависимостей.

## Данные и состояние

Пользовательские настройки сохраняются в `localStorage` под ключом `pocket-works:rivals-roulette:state:v1`. Приложение кэширует только собственные файлы и обязательный `shared/mobile-runtime` в `rivals-roulette-v1.0.0`.

## Запуск

Откройте `apps/rivals-roulette/index.html` через локальный HTTP-сервер или из оболочки Pocket Works. После первого успешного открытия приложение доступно офлайн через Service Worker.
