# СТАПЕЛЬ — Марсианское конструкторское бюро

Самостоятельная offline-first игра в библиотеке Pocket Works о разработке и запуске многоступенчатых ракет. **Построить → рассчитать → испытать → изучить орбиту → улучшить** — законченный игровой сценарий.

## Игровой процесс

- Три марсианских контракта: спутник 200 кг (110–260 км), ретранслятор 950 кг (140–330 км), тяжёлый зонд 1500 кг (170–410 км).
- От одной до трёх ступеней. На каждой выбираются число баков (1–6), один из трёх жидкостных двигателей и стабилизаторы.
- Технический рисунок меняется вместе с конфигурацией. Коснитесь нужной ступени на ракете либо её номера.
- Расчёт характеристической скорости по уравнению Циолковского, стартового TWR и сметной стоимости конструкции.
- Запуск разрешён, если стартовой тяги хватает для преодоления гравитации, а проект помещается в бюджет.
- В полёте работают настоящий двухмерный численный интегратор, отделение ступеней, ручной тангаж и дросселирование, автопилот, пауза, ускорение времени, орбитальная карта с вычисленными апогеем и перигеем.
- Миссия выполнена только после расчётного достижения устойчивой связанной орбиты внутри заданного диапазона высот.
- При неудаче отображаются параметры и рекомендации; конструкция остаётся доступна для исправления.
- Результаты миссий, текущая конфигурация и настройка звука сохраняются локально.

## Физическая модель

Марс: средний радиус **3389,5 км**, гравитационный параметр **4,282837 × 10¹³ м³/с²**, период осевого вращения **88 642,66 с**. Модель с упрощённой экспоненциальной атмосферой (0,020 кг/м³ у поверхности, масштабная высота 11,1 км), аэродинамическим сопротивлением, переменным атмосферным удельным импульсом и реальным истощением топлива. Пространственное движение ограничено одной 2D плоскостью. Гравитация меняется как 1/r², а орбитальные апсиды считаются из энергии и удельного момента импульса. Интегрирование полунеявным Эйлером до 0,15 с на подшаг.

Характеристики двигателей, цены и контракты — игровые, а не сертифицированное железо NASA. Первая версия не моделирует конструкционные разрушения, вращательную инерцию, тепловые перегрузки, многоточечные трубопроводы или реалистичное управление ориентацией через момент тяги. Видимые стабилизаторы добавляют массу и площадь сопротивления. Эти системы нельзя выдавать за полноценный аэрокосмический симулятор.

Численный автоматический пилот выполняет программу подъёма, ждёт апогея и делает касательное включение для выхода на орбиту; пользователь может в любой момент перейти на ручное управление. Программный расчёт автопилота не изменяет ускорение и не телепортирует корабль на заданную орбиту.

Данные планеты: [NASA Mars Fact Sheet](https://nssdc.gsfc.nasa.gov/planetary/factsheet/marsfact.html). Схема двигателя: [NASA Glenn](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/liquid-rocket-engine/).

## Тестирование

```bash
node --test apps/stapel/physics.test.mjs
npm run registry:check
npm run validate:configs
```

Тесты проверяют уравнение орбиты, запас топлива, реальное достижение первой орбиты стандартной ракетой и выполнимость тяжёлых контрактов после инженерного изменения прототипа.

## Структура и интеграция

Все файлы принадлежат `apps/stapel/`. Приложение регистрируется `app.config.json`, загружается из библиотеки Pocket Works как Quick runtime, использует `../../shared/mobile-runtime.js`, имеет собственные PWA-манифест, SVG-иконку и versioned Service Worker, возвращается в лаунчер через видимый текстовый переход.

Хранение изолировано под `pocket-works:stapel:v1`; автономный кэш — `stapel-v1.0.0`. Нет внешних скриптов, CDN и обязательных сетевых запросов после первой загрузки.
