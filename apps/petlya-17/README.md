# ПЕТЛЯ 17 · Coast Run 3.2

Офлайн 3D-гонка от первого лица для горизонтального телефона и компьютера. Три круга по прибрежному автодрому, пять соперников, физика сцепления, обгоны и контакты. Версия 3.2 сохраняет игровой цикл, полностью перестраивая 3D-сцену и презентацию.

## Как играть

1. В гараже видна сама трасса и гоночная машина. «На трассу» активирует руление наклоном телефона, «Руль / клавиши» включает ручное управление.
2. На телефоне газ справа, тормоз слева, руление наклоном или нижним сенсорным рулём. На ПК: W/↑ — газ, S/↓ — тормоз, A/D или стрелки — руль, Esc — пауза.
3. Мини-карта показывает шесть болидов; поворотные сигналы помогают планировать торможение. Используйте воздушный след, чтобы обгонять.
4. После трёх кругов получаете протокол и локальный рекорд. Можно повторить заезд.

## Художественная система

- Модуль `source/circuit-32.ts`: приоритетная геометрия дорожного полотна с двухсторонними поверхностями, асфальтовая фактура с резервом, контрастные линии и поребрики, стартовая шахматка, защитные ограждения, указатели.
- Окружение: портовые краны и терминалы, морская вода, дальний рельеф, береговая растительность. Декоративные элементы изолированы от строительства основной трассы.
- Новые машины: клиновидный кузов, колёсные ниши, подвеска, шлем, антикрылья, воздухозаборники, стоп-сигналы.
- Камера из низкого кокпита больше не перекрывает апекс; в меню используется отдельный панорамный ракурс.

## Надёжность и офлайн

Сцена показывает меню после фактически успешно отрисованных кадров, а не после потенциально бесконечного ожидания готовности зеркал. Ошибка рендера выводится пользователю с возможностью перезапуска. Материал асфальта работает и без 2D Canvas. Рекорды, звук, вибрация, чувствительность, качество сохраняются в `pocket-works:petlya-17`. Внешних 3D-моделей не требуется, Babylon.js собирается в приложение.

Проверка: `npm run --workspace=@pocket-works/petlya-17 typecheck`, `npm run --workspace=@pocket-works/petlya-17 test`, `npm run --workspace=@pocket-works/petlya-17 build`.
