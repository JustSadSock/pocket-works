# DEFIXIO — латинские проклятия

Отдельное офлайн-приложение Pocket Works в стиле римской мастерской табличек *defixiones*.

## Что работает

- Двенадцать последовательных латинских формул с тремя грамматическими выборами на каждой. Реальные латинские формы (jussive subjunctive, падежи, число).
- Выбор нажатием или перетаскиванием слова на свинец. Неверный ответ оставляет царапину. Три ошибки требуют переплавки таблички; правильные формы физически выгравировываются.
- После трёх верных формул надпись запечатывается. Заказы доступны повторно, архив сохраняет результат, свободный режим позволяет составлять собственные формулы.
- Звук можно отключать. Достижения и текущий заказ сохраняются локально; приложение устанавливаемое и работоспособно после первого посещения без интернета.
- Полностью доступный текстовый возврат в Pocket Works в верхней панели и архиве.

## Управление

Коснуться одного из трёх вариантов или перетащить его на табличку. Коснуться уже выцарапанного слова — увидеть грамматическое объяснение. `АРХИВ` показывает завершённые надписи. `СВОБОДНЫЙ РЕЗЕЦ` создаёт собственные короткие формулы. `Esc` закрывает архив.

Эпиграфическое письмо отображает U как V. Формулы являются художественной реконструкцией жанра, а не дословными археологическими надписями.

## Технически

Quick PWA. Только app-local DOM/CSS/JS/SVG, Web Audio, локальное сохранение `pocket-works:defixio:v1`, отдельный service worker cache `defixio-v1.0.0` с update-manager protocol v2. Никакого внешнего CDN.
