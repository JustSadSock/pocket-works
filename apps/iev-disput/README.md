# ДИСПУТ: ІЕВ

Offline-first застосунок Pocket Works для інтенсивної дводенної підготовки до комісії з історії економічних вчень.

## Що всередині

- **План на 2 дні** — 8 конкретних блоків по 35–55 хвилин із локальним прогресом.
- **Атлас** — хронологія, персоналії та перехресний перегляд за країнами.
- **Тренажер** — 55 питань у трьох рівнях складності з самоперевіркою «ні / частково / так».
- **Комісія** — три послідовні усні питання, де третє навмисно перехресне або каверзне.
- **Слабкі місця** — автоматично формуються з історії самооцінок.
- **Конспект** — повнотекстовий пошук по всіх абзацах завантаженого навчального матеріалу.
- **Контекст+** — окремо позначені зовнішні містки для питань, яких прямо немає у конспекті (правитель, дата, головний представник тощо).

## Дані й приватність

Прогрес зберігається лише локально в `localStorage` під простором `pocket-works:iev-disput`. Мережа для навчання не потрібна після першого успішного відкриття.

## Pocket Works

Застосунок використовує спільний mobile runtime, має власний manifest, service worker, cache namespace та PWA-іконку. Усі файли ізольовані в `apps/iev-disput/`.
