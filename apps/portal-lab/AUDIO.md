# ШОВ: звук исследовательского симулятора

Новая акустическая палитра — сдержанная научная установка, а не аркадная головоломка.

Материалы: сталь механизма излучателя, шлифованная керамика, воздух в резонаторе, оптическое стекло. Действия: запуск пучка — мягкий пневматический выброс с коротким металлическим щелчком; перемещение источника — миниатюрная защёлка; изменение параметров по умолчанию без шумов, чтобы не мешать наблюдению. Нет звуков победы или несуществующих ударов в центре норы.

Используется исходный синтез Web Audio: фильтрованный шум + короткие частотные огибающие и контролируемый разброс. Контекст активируется по жесту пользователя, доступно отключение через верхнюю панель и localStorage. Отсутствие звука никак не мешает проведению эксперимента.
