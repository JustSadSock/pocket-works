# ШОВ v0.3.0 — «Видеть пространство»

Сохраняет геометрию 3+1D `ds² = -N(l)²dt² + dl² + R(l)²dΩ²`, где `R²=l²+a²`, `N=exp(-ηa/R)`, с `c=G=1`. **При η=0 это модель Эллиса**; η>0 — отдельно маркированный статический анзац. Ни создание реальных порталов, ни решение задач о стабильности горловины не заявляются.

## Новое: оптический наблюдатель

Первая вкладка теперь содержит **вид с локальной статической камеры**. Каждый пиксель испускает назад направленный луч локальной ортонормированной системы. Из сферической симметрии выводится редукция его 3D световой геодезической к меридиональной плоскости, после чего по `E`, `L`, `p_l` и выбранной метрике интегрируется направление и конечная область выхода. Чтобы работа была интерактивной на телефоне, `optics.js` считает одномерную таблицу углов (640 выборок; 150 при полёте), а `observatory.js` интерполирует её в каждый пиксель и берёт цвет на одной из двух процедурно созданных бесконечно далёких небесных сфер. Переменная `region` определяет источник неба; `angle` определяет направление в соответствующей области. Физический эффект — отклонение лучей, многократные изображения и окно в другой регион. **Звёзды искусственные, не реальные наблюдения**; спектроскопическое изменение яркости и собственный вид аппаратов пока не рассчитываются.

**Пределы:** оптика статической сферической метрики, конечный радиус выхода `22a`, ограничение времени интегрирования, дискретная угловая сетка. Практически круговые орбиты могут не достичь границы к пределу времени; они помечаются как численно неразрешённые (тёмные), а не как физический горизонт. Это не произвольная покраска горловины и не полноценный динамический GR-рендеринг с обратной реакцией материи.

Камеру можно повернуть пальцем/мышью. Слайдер удаляет статическую камеру от горловины. Кнопка **Пройти горловину** запускает массивного пробного наблюдателя с физически интегрируемой мировой линией (`speed=.73c` в начальной локальной системе), при пересечении горловины ориентация камеры не сбрасывается; вид перестраивается через модуль световых геодезических. Ручная установка камеры не считается свободным падением; её статическое положение требует внешней поддержки при `η>0`.

Тап по кадру даёт экспериментальный параметр попадания `b=|L/E|`, число оборотов фотона и регион выхода, а не заранее заданные описания. Промежуточные вычисления отображают прогресс и могут быть отменены/перезапущены при изменении параметров. Результат сохраняется при следующем запуске вместе с положением и направлением камеры.

## Приливной зонд

Кнопка **Отправить зонд** создаёт пять близких времениподобных геодезических: центральную, ±`ε` радиально, ±`ε/R` по углу, одинаковая локальная начальная скорость. Непрерывно измеряются метрические расстояния между соседними траекториями в локальной пространственной системе:

```
δs² ≈ (δl)² + R(l)² (δφ)²;
F_ij ≈ (x_i(+ε)-x_i(-ε))/(2ε);
stretch_radial = ||F e_r||; stretch_lateral = ||F e_t||.
```

Это дискретная оценка геодезического отклонения (конгруэнция свободнопадающих пробных точек), а не полноценная механика конечного упругого тела. Диагностический контур помещён **в отдельную систему измерений**, не притворяется оптическим изображением самого зонда. Энергетический источник кротовой норы и влияние зонда на метрику не моделируются.

## Управление и проверки

- Вкладки **Наблюдатель**, **Топология**, **Профиль**; редкие параметры не конкурируют с основной сценой.
- Камера: drag — взгляд; tap — инспектор фотона; удаление/FOV — слайдеры; «Пройти горловину», «Исходный вид» — отдельные действия.
- Тесты: `node --test apps/portal-lab/relativity.test.mjs apps/portal-lab/observatory.test.mjs`.
- Экспорт JSON включает метрику, положение камеры и текущие измерения зонда. Всё локально и офлайн; `v0.3.0` использует отдельный cache namespace.

# Архив реализации v0.2.0

Отдельное портретное/десктопное приложение PocketWorks. Это **не игра**, не лабиринт с телепортами и не доказательство существования реальных порталов. Лаборатория исследует конкретно определённую геометрию проходимой кротовой норы в общей теории относительности.

## Математическая модель

Сферически-симметричная 3+1-мерная метрика (в приложении интегрируются геодезические экваториального 2+1-мерного среза, при θ=π/2):

```
ds² = -N(l)² dt² + dl² + R(l)²(dθ² + sin²θ dφ²)
R(l) = sqrt(l² + a²)
N(l) = exp(-η a / R(l))
```

Установлены c = G = 1 (безразмерные нормированные единицы). Геометрия содержит два асимптотически плоских региона, l>0 и l<0, и одну регулярную горловину l=0, радиуса a. **При η=0** получаем точную ультрастатическую метрику Эллиса (Einstein + фантомное скалярное поле). При этом пространственная кривизна ненулевая, линзирование есть, но N=1 и статические часы идут с равной скоростью. Обычной локальной гравитационной силы, тянущей неподвижный объект к горловине, **нет**.

**При η>0** N(l) задаётся как параметрический анзац для изучения влияния градиента lapse (красного смещения). Это допустимая заданная гладкая метрика, но неизвестный источник тензора энергии-импульса **не вычисляется**; не надо интерпретировать η как верифицированный параметр реальных объектов или продолжение исходного решения Эллиса с тем же полем.

Для Эллиса пространственная гауссова кривизна экваториального среза: `K = -a²/(l²+a²)²`. Для данной функции lapse градиент ускорения покоящегося наблюдателя `a_l = -d ln N / dl = -η a l / (l²+a²)^(3/2)` (фактически минус собственное ускорение, нужное для удержания статического положения). Статические часы: `dτ = N(l) dt`. Для Эллиса радиальная нулевая энергетическая комбинация, выраженная через тензор Эйнштейна, `8πG(ρ + p_r) = -2a²/(l²+a²)²`, т.е. нарушается NEC — экзотический источник энергии.

## Физический интегратор

Временная симметрия и осевая симметрия дают постоянные:

```
E = N² dt/dλ;   L = R² dφ/dλ
H = 1/2 [-E²/N² + p_l² + L²/R²] = -κ/2
κ=0 photon, κ=1 timelike test particle
```

В `relativity.js` используется Hamiltonian evolution с независимым временем t:

```
dl/dt = p_l N²/E
dφ/dt = L N²/(E R²)
dp_l/dt = -E (d ln N/dl) + N² L² l/(E R⁴)
dτ/dt = N²/E  (massive)
```

RK4 с шагом не более 0.018a/c по координатному времени. Свет всегда движется со скоростью c в локальной ортонормированной системе, но может сильно изгибаться в пространственной проекции, рассеиваться, оборачиваться вокруг горловины и переходить в другой регион. Массивные объекты испытывают изменение локальной скорости в метрике с η>0. Свет и материя — **пробные**, обратно на метрику не влияют. Топологический переход происходит непрерывно, без вручную назначенных импульсов и без телепортационной поверхности.

Энергия E и момент L сохраняются по построению (заданы константами); отдельный тест контролирует изменение нормировки Hamiltonian constraint. В численной проверке 400 случайных лучей и траекторий расхождение нормировки не превысило 1e-6.

## Интерфейс

- Два региона A/B показывают один и тот же связный многообразный объект в **двух проекциях**. Место источника выбирается нажатием на карту; направление настраивается протягиванием от источника. Рисуемые радиальные диаграммы — атлас координат, а не изометрическое изображение всей метрики.
- **Топология:** живые интегрированные геодезические фотоны/частицы и прохождение горловины.
- **Профиль:** аналитическое изометрическое вложение экваториальной пространственной геометрии Эллиса `R(l)=sqrt(l²+a²), z(l)=a asinh(l/a)`, показанное в облической перспективе.
- Переключение точной метрики/анзаца, радиус горловины, глубина потенциала, луч/частица, количество траекторий, раскрытие пучка, скорость массивного зонда, масштаб времени, пауза, очистка и экспорт JSON.
- Кнопка **Критический фотон** подбирает `b=|L/E|≈0.996·b_crit`, где `b_crit=a/N(0)=a exp(η)` (η≤0.85). Геодезическая долго вращается около неустойчивой световой сферы перед проходом.
- Наблюдения: пространственная кривизна горловины, градиент lapse при l=a, проходы между регионами, нарушение нормировки и относительные показания статических часов у горловины и далеко от неё.
- При смене метрики мир запускается заново, чтобы константы интегралов движения старой метрики не применялись к новой.
- Параметры эксперимента, координаты источника, начальные траектории и текущее состояние пробных объектов сохраняются в локальном хранилище.

## Границы научной модели

Это не динамическая симуляция решения уравнений Эйнштейна и не симуляция квантовых полей, гравитационной реакции массивного груза, устойчивости горловины, создания/разрушения кротовой норы или причинно-следственных парадоксов. Отсутствуют распределения реально реализуемых источников энергии, физические силы рук и стен, фотореалистическое обратное трассирование изображений далёкого мира и полная трёхмерная динамика. Визуальная карта — геометрическая проекция, **не фотография того, как выглядело бы пространство через нору**. Выводы модели ограничены её уравнениями.
