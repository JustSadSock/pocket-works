# ШОВ — лаборатория порталов

Отдельная офлайн-игра PocketWorks. Порталы представлены **ориентированными геометрическими швами** между двумя участками 2D пространства, а не телепортацией с произвольным вектором движения.

## Игровой цикл

Шесть опытов, включая свободный режим. Наведи пусковую установку кликом по камере либо проведением от ствола; запусти капсулу и попади в приёмник. При выборе входа/выхода канала А или Б тап по креплению на стене переставляет соответствующее устье; монтажные позиции достаточно велики для пальца. Эксперименты доступны с первого запуска. Победы и последний выбранный опыт сохраняются локально. В песочнице редактируются ускорение свободного падения и коэффициент восстановления.

Физические величины: позиция — пиксели, **72 px = 1 м**, скорость — м/с, масса — 1 кг, гравитация — 9.81 м/с², энергия — Дж. Полунеявное интегрирование с шагом 1/120 с и дополнительным адаптивным дроблением времени. Столкновения круглых тел с прямоугольниками и друг с другом; нормальный импульс, тангенциальное трение и вращение диска; воздушное сопротивление.

### Геометрия портала

У каждого устья есть центр P, выходная нормаль n и касательная t. Пересечение считается при переходе центра тела из полупространства с положительной нормалью через плоскость в разрешённом диапазоне апертуры. Для пары (A,B) при пересечении:

- (u = (x-P_A) \cdot t_A)
- (x' = P_B - u t_B + n_B (r+\varepsilon))
- (v' = -(v\cdot t_A)t_B -(v\cdot n_A)n_B)
- \$\\omega'=\\omega\$

Это собственное ортогональное преобразование (определитель +1), сохраняющее длину вектора скорости и кинетическую энергию на самом шве. Направление гравитации после выхода остаётся глобальным, а не «поворачивается магией». Внешние анкеры отвечают за обмен потенциальной энергией при изменении высоты: (W_{anchors}=-mg\Delta h), который отображается отдельно. Это энергетически **открытая** система для движущегося тела.

**Ограничения научной точности:** такое идеальное локальное соединение не является экспериментально подтверждённой физикой реальных порталов. Нет ОТО, кривизны пространства-времени, причинности/светового времени, аэродинамики на границе, полных связанных твёрдых тел, точной геометрии объекта, находящегося одновременно по обе стороны шва, и сохранения полного импульса портала с опорами. Столкновения рассчитаны численно, с конечной точностью. Нельзя обещать буквальную «идеальную» симуляцию невозможного в современной физике объекта.

## Запуск, тесты и интеграция

Открой `apps/portal-lab/index.html` через PocketWorks; UI отображается в портретной ориентации и масштабируется на ПК. Сборка не нужна (Quick Canvas). Node tests: `node --test apps/portal-lab/physics.test.mjs`. Проверки охватывают поворот скорости, сохранение кинетической энергии, работу внешних опор, независимые пары, стенки и все уровни. Состояние для автотестов: `window.__PORTAL_LAB__.snapshot()`.

Собственный манифест, SVG-иконка, service worker и offline cache `portal-lab-v0.1.0`; никаких изменений общего лаунчера. Звук отдельной палитры в AUDIO.md.
