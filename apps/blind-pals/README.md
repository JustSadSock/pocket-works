# СЛЕПАЯ СМЕНА

Сетевая кооперативная физическая головоломка для двух игроков. Каждый видит **только другого** персонажа. Собственный персонаж скрыт во всех игровых кадрах; поле фиксировано в общих мировых координатах. Действия полностью проверяются серверным модулем PocketNet и синхронизируются через облачную комнату.

## Игра

На главном экране доступны три действия: **создать комнату**, **позвать друга** через Pocket ID или **присоединиться по 8-символьному коду либо ссылке**. При создании комната появляется непосредственно после подключения PocketNet, без промежуточной формы. В лобби можно копировать только код, поделиться прямой ссылкой или отправить игровое приглашение выбранному другу Pocket ID. Для приглашений через друзей нужен настроенный Pocket ID; гостям доступна ссылка. При входе по ссылке приложение заполняет код автоматически.

Создайте комнату, скопируйте 8-символьный код, передайте его второму игроку. Ведущий начинает после входа двоих. В каждой из шести комнат необходимо одновременно занять две плиты (и при наличии установить груз на ромб), после чего обоим попасть на выход. Уровни последовательно вводят стены, конвейеры, толкание ящика и пульсирующие прессы. Переход автоматический. После финала ведущий может начать заново.

## Управление ПК

- WASD/стрелки — движение с управляемым ускорением.
- Space — короткий прыжок над работающим прессом.
- E (удержание) — толкать груз.
- F — сигнал, который видит напарник.
- Esc — локальная пауза, отпускание ввода.

В узком мобильном окне работают джойстик, кнопки прыжка и толкания.

## Сетевая модель

Только PocketNet Durable Object. Клиенты посылают ограниченный ввод 12.5 раз/с. Сервер рассчитывает движение, двери, конвейеры, толкание груза, опасности, подсчёт провалов и завершение уровней. Отправляемое состояние невелико; WebSocket переподключается через общий клиент. Отключившийся игрок сохраняет место в комнате, но без его ввода продвижение невозможно. Каждая открытая вкладка защищена от переиспользования скопированного из другой вкладки bearer-токена через согласование BroadcastChannel (см. `tab-session.js`); при перезагрузке обычной вкладки сохраняется её собственная сессия. Клиент явно обрабатывает неверные коды, заполненную комнату, совпадение аккаунтов и неподходящий gameId. Во время повторного подключения движение блокируется. Offline fallback — стартовое меню, не фиктивная локальная кооперация.

UI-файлы: `lobby-v2.css`, `app.js`. Для Social-приглашений используется платформенный диалог `PocketSocial.open(roomId,'blind-pals')`. Игровой сервер по-прежнему использует первоначальную неизменяемую версию правил.

Владелец приложения — `apps/blind-pals/**`. Сервер: `server/module.ts`; выпуск правил должен быть снапшотнут в `pocketnet/module-versions/blind-pals/v1.ts` и прописан в `pocketnet/modules.lock.json` до развёртывания. Это отдельный шаг платформенной регистрации, потому что сборщик запрещает неподтверждённые серверные версии.
