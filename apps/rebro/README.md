# РЕБРО

`РЕБРО` — изолированная offline-first игра Pocket Works о расстановке порталов. Порталы не лежат на клетках и не переносят персонажа: это вертикальные ворота, установленные на рёбрах изометрического поля. Через них проходит энергетический импульс.

## Игровой цикл

1. Игрок выбирает одни из парных ворот на нижней стойке.
2. Ворота ставятся касанием или перетаскиванием на свободное монтажное ребро.
3. Касание уже поставленных ворот либо кнопка `РАЗВЕРНУТЬ` меняет сторону выхода.
4. После `ПУСКА` импульс идёт по прямой, пересекает плоскость ворот и появляется у их пары.
5. Камера завершена, когда импульс собрал все кристаллы и дошёл до приёмника.

В первой половине кампании используется одна пара ворот. Во второй появляются две независимые пары и цепочки из нескольких телепортаций. Все 12 камер собраны вручную и имеют проверяемое эталонное решение.

## Управление

- касание ворот на стойке → выбор;
- касание монтажного ребра → установка выбранных ворот;
- перетаскивание ворот → перенос на другое ребро;
- касание поставленных ворот → разворот;
- `РАЗВЕРНУТЬ` → явный разворот выбранных ворот;
- `СНЯТЬ` → возврат выбранных ворот на стойку;
- `НАМЁК` → подсветка одного правильного ребра;
- `ПУСК` → симуляция маршрута.

## Архитектура

- `game-core.js` — чистая модель рёбер, направлений, портальных выходов и симуляции;
- `app.js` — состояние, сохранение, ввод, Canvas-рендер и анимация;
- `styles.css` — мобильная промышленная визуальная система;
- `tests/game.test.mjs` — проверки всех эталонных решений и базовых контрактов геометрии;
- `sw.js` — автономный app shell с изолированным кешем `rebro-*`.
