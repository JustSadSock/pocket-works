# FORMICA // COLONY

Живой 2D-симулятор муравьиной колонии для Pocket Works. Мир показан вертикальным срезом: поверхность, грунт, туннели и камеры существуют в одном непрерывном пространстве.

## Принцип

Игрок не управляет приоритетами и не назначает работы. Пища, грунт, расплод, вода, трупы и враги существуют как конкретные объекты мира; поведение возникает из локальных потребностей, физической доступности и феромонных сигналов.

Наблюдателю доступны камера, скорость времени, выбор и слежение за конкретной особью, журнал колонии и диагностические слои: феромоны, влажность и температура.

## Что исправлено в 1.1.0

- муравьи больше не «подплывают» сквозь грунт: подземное перемещение идёт только по реально существующим воздушным клеткам через навигацию по сети ходов;
- добыча переносится порциями, поэтому один рабочий не может унести целого крупного жука как единый абстрактный ресурс;
- темп кладки королевы зависит от численности рабочих, расплода и фактической еды;
- пища на поверхности и в гнезде стареет, а её появление и питательность пересобраны так, чтобы запасы не разрастались бесконтрольно;
- сохранение больше не сериализует несколько огромных Float32-массивов как JSON: грунт хранится в base64, влажность квантуется, феромоны восстанавливаются динамически; типичный save занимает менее 100 КБ;
- рендер больше не показывает клеточную сетку напрямую: физическая сетка сохранена для симуляции, но тоннели, слои почвы, камни, корни и поверхности визуально сглажены;
- добавлен специализированный Playwright mobile journey, который действительно запускает колонию и проходит ключевые сценарии, вместо простого «потыкивания» стартового экрана.

## Технологии

Quick PWA, Canvas 2D, ES-модули, общий mobile runtime Pocket Works, локальное сохранение, service worker и офлайн-кеш.
