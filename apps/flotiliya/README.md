# ФЛОТИЛИЯ — v0.1.0

Морская тактика малых эскадр внутри PocketWorks.

- 1 игрок против простой автономной эскадры.
- До трёх активных кораблей, движущихся с инерцией и ограниченной скоростью поворота.
- Луки, сближение и абордаж; каждая 9-секундная фаза исполняет приказы обеих сторон одновременно.
- Последствия столкновений, стрельбы, потеря экипажа, захват, потопление.
- Сохранение кораблей, их имён, опыта, повреждений, улучшений и добычи.
- Полностью локальный Canvas 2D; без дополнительных пакетов и серверных запросов.

Управление: выбери зелёный корабль, коснись воды для манёвра, при необходимости выбери вражеский корабль как цель. Нажми «Исполнить приказы». После боя возвращайся в гавань, ремонтируй и усиливай суда. Можно играть мышью или касаниями; рекомендуется горизонтальная ориентация.

Нельзя считать эту версию полноценной симуляцией исторического морского боя: скорость и физика намеренно упрощены ради проверки интересности тактики. Ветер, сложные галерные построения, сетевой PvP и глобальная кампания в первом прототипе отсутствуют.

Изоляция: все файлы только внутри apps/flotiliya/. Persistence key: pocket-works:flotiliya:v1.
