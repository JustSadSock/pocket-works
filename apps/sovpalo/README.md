# СОВПАЛО

Интерактивная лаборатория парадокса дней рождения для Pocket Works.

## Основной сценарий

1. Пользователь задаёт от 2 до 1000 человек числом, кнопками или нелинейным ползунком.
2. Приложение без симуляции рассчитывает вероятность хотя бы одного совпадения, тройки, четвёрки и двух независимых общих дат.
3. Блок точных раскладов ранжирует конкретные структуры вроде одной пары, двух пар или тройки с парой.
4. Сетка из 365 дней показывает один воспроизводимый случайный пример и может быть переброшена отдельно от точных расчётов.

## Математическая модель

- 365 равновероятных дней;
- дни рождения независимы;
- 29 февраля, сезонность и близнецы не моделируются;
- вероятности точных структур вычисляются через число размещений дат и разбиений людей по размерам групп;
- вероятности «хотя бы тройка» и «хотя бы четвёрка» получаются как дополнения к распределениям с максимумом 2 и 3 человека на дату.

## Проверка

```bash
node apps/sovpalo/math.test.mjs
```

Приложение хранит только выбранное количество людей, состояние раскрытия редких сценариев и seed наглядного примера в namespace `pocket-works:sovpalo`.
