# ПЯДЬ — Малое королевство

Оригинальная автономная пиксельная микро-стратегия для Pocket Works. Всё действие — в одной средневековой миниатюре, нарисованной на Canvas размером 240 × 352 логических пикселя без сглаживания.

## Игровой цикл

Переживите пять ночных набегов, сохранив здоровье крепости. Каждый день доступны три приказа: жатва (+5 зерна), лес (+4 дерева), копейщики (2 зерна +1 дерево), лучники (3 зерна +3 дерева), частокол (4 дерева) или ремонт замка (+2 здоровья, 3 дерева). Выбор дороги изменяет направление оборонительных приказов. Лимиты на дорогу: 4 копейщика, 3 лучника, 2 секции частокола. На ночь противники идут по трём дорогам, лучники стреляют издалека, копейщики останавливают врагов вблизи. Перенос королевского знамени усиливает выбранную дорогу с перезарядкой 1.2 с. Победа — продержаться пять ночей, поражение — потерять все 9 очков прочности ворот.

## Технически

- Vanilla HTML/CSS/JS, независимая Quick PWA с версионированным SW.
- Свой низкоразрешённый рендеринг без фильтров/браузерного сглаживания; пиксельные дома, ландшафт, замок, поля, воины, животные, тени и проектайлы.
- Автосохранение снапшота в `pocket-works:pyad:save`; возврат из меню/паузы; звук с отключением.
- `window.__PYAD_QA__` публикует тестовое состояние для локальных тестов.
- Контент и навигация на русском, адаптация к вертикальному телефону и safe areas.

Запускать как `apps/pyad/` из Pocket Works либо отдельной вкладкой с корнем репозитория на HTTP-сервере. Все ресурсы локальны.
