# Emergence Lab

A touch-first laboratory for producing complex collective behavior from a compact set of visible rules.

## Main loop

1. Choose a behavior cassette or tune attraction, repulsion, reach and spin directly.
2. Pull, push, seed or erase agents on the live field.
3. Mutate the current rules, observe the reorganization and undo when a mutation is weak.
4. Use Cause mode to inspect the strongest forces acting on a single specimen.

## Product details

- Spatial-hash particle engine with three species and a bounded population.
- Colony, Orbit, Territory, Cycle and Crystal behavior cassettes.
- Optional birth, mutation and death loop.
- Persistent world snapshot, rules, transport state and simulation time.
- Responsive portrait, landscape and desktop layouts.
- Offline PWA shell, managed updates and Workshop diagnostics.

## Controls

- **Pull / Push**: hold or drag in the field to create a local force.
- **Seed / Erase**: paint agents into or out of the dish.
- **Cause**: tap a specimen to inspect age, energy, neighborhood and current force trace.
- **Mutate rules**: makes a bounded random change to the active rule set.
- **New dish**: two-step destructive reset that preserves the active rules.
