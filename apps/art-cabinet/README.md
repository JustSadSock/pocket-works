# КАРТОТЕКА

Самостоятельное PocketWorks-приложение, не изменяющее «Замазку».

- 100 настоящих произведений с фиксированными номерами, категорией и ссылкой на исходную статью о картине.
- № 3 «Смерть Марата» отмечена при самом первом запуске по выбору пользователя; затем любое изменение сохраняется локально.
- Миниатюры получаются через официальное API MediaWiki с параметром CORS origin=* (плюс запасной REST endpoint при крупном просмотре); в UI есть прогресс, отсутствие миниатюры, повтор и прямая ссылка на оригинал. Никаких фиктивных изображений.
- В браузере самого PocketWorks запросы к Wikimedia выполняются вне ограничений встроенных чат-виджетов. Интернет необходим только для самих музейных изображений; интерфейс и список остаются доступными offline.
- Все фильтры, поиск, перемещение по 100 карточкам, выбор, экспорт TXT, буфер обмена и диалог увеличения работают локально. Список никуда не отправляется автоматически.

**Номер** — идентификатор внутри этой подборки, не совпадает с идентификатором полотна в «Замазке». Существующие игры/файлы не меняются.

Локальная проверка: node --check apps/art-cabinet/app.js; node apps/art-cabinet/qa/catalog.test.mjs.
