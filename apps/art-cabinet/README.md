# КАРТОТЕКА · Выпуск 02 / v1.1.0

Отдельное приложение PocketWorks. Файлы «Замазки» не импортируются и не изменяются.

Выпуск 02 — **100 новых** кандидатов №101–200, составленных по выбору 36 полотен первого выпуска. Акцент: драматургия, несколько читаемых фигур, выразительные жесты, узнаваемые силуэты, странные образы. Выбранные из выпуска 01 картины доступны под фильтром «Уже одобрены 36» с исходными номерами и статическими ссылками на Wikimedia Commons.

Функции: нативная вертикальная прокрутка на мобильном (не вложенный overflow), одна крупная картина в ряд на телефоне, две или три на ПК; страницы по 12 работ, фильтры, поиск по автору/названию/ID, просмотр без обрезания, стрелки и свайпы, отметка и сохранение нового отбора, копирование и TXT-экспорт. Старые одобренные работы нельзя случайно удалить. Старое хранилище выбора v1 не переписывается; новый отбор лежит отдельно в v2.

Картинки новых кандидатов запрашиваются из Wikipedia pageimages **только при просмотре страницы**. При отсутствии статьи или изображения включается Commons file-search с фильтрацией по названию и автору. Ошибки и таймауты отображаются явно; карточки не пересоздаются при асинхронных ответах и потому не сбрасывают прокрутку. Есть ручная коррекция: вставить прямой Wikimedia URL или ссылку на страницу File: с сохранением в localStorage.

**Оговорка:** автоматический поиск Commons не гарантирует, что найденный файл — нужное полотно. Перед добавлением выбранных работ в «Замазку» требуется сверка конкретных файлов и прав, как в первом выпуске. Нет сгенерированных изображений или фиктивных заглушек вместо оригиналов.

Проверки: node apps/art-cabinet/qa/catalog.test.mjs и node apps/art-cabinet/qa/mobile-smoke.mjs (Playwright Chromium 390×844, 360×640, 1440×900; мок Wikimedia; прокрутка, перелистывание, выбор, смена адреса, сохранение).

Отдельно требуется проверить реальную доступность CDN Wikimedia и соответствие каждой репродукции произведению на телефоне после Cloudflare deploy.
