# КАРТОТЕКА · Ревизия исходного фонда · v1.2.0

Самостоятельное приложение PocketWorks. Список исходных картин **в точности совпадает с игровым фондом до первого расширения**: игровые ID 0–71 (8 из первоначального мини-каталога + 46 музейных + 18 поздних). **Основной сценарий теперь обратный**: пользователь помечает только те старые картины, которые НЕ нужны. Отметки лишь создают список на удаление; **«Замазка» не изменяется автоматически**.

Подборки из второго выпуска с номерами 102, 103, 104, 106, 107, 108, 112, 116, 117, 124, 125, 126, 127, 133, 134, 135, 136, 137, 139, 142, 144, 145, 146, 147, 148, 176, 191, 192 (28 картин) занесены в постоянный архив одобрения. Сохранились и предыдущие 36 одобренных работ первого выпуска. Два архива используют собственные внутренние ID 1000+ и 2000+, но пользователю показываются их прежние номера. Игровые ID 0–71 не пересекаются с архивными ID. Подборка 28 пока только записана — не добавлена в игру без согласованной проверки оригинальных файлов.

В основном списке используются **те же Wikimedia Commons filename/path/source**, что и в «Замазке». Если точная миниатюра недоступна, запасной URL направлен на тот же файл через Commons Special:Redirect, не на сомнительный результат поиска. Ручная замена неверного источника остаётся доступной в полноэкранном просмотре. Отмеченные ID на удаление хранятся в отдельном localStorage key v3, не смешиваясь с выбором новых картин из выпуска 02.

Нативная вертикальная прокрутка на телефоне, одна большая работа в строке, фильтры по 54 старым и 18 дополнительным, избранным на удаление, архив двух отборов, поиск, полноэкранное перелистывание и скачивание TXT. Включены реальная кнопка закрытия в PocketWorks, состояния ошибок изображения, сохранение отметок.

Проверки: `node apps/art-cabinet/qa/catalog.test.mjs` и `node apps/art-cabinet/qa/mobile-smoke.mjs` (Chromium, смартфоны и ПК). Уточнение: автоматический браузерный тест мокирует внешние изображения; живую загрузку всех Commons файлов на iPhone нужно проверить после развёртывания.
