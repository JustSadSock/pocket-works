# НУЛЕВОЙ ЭТАЖ

Мобильный FPS о побеге из перестраивающегося бетонного комплекса: три энергоядра, охотящиеся дроны и один лифт наружу.

This app is independently served from `/apps/nulevoy-etazh/`. Launcher and release metadata are owned by `app.config.json`; the app owns its manifest, service worker and local state.

Validate with `npm run validate` after building Enhanced apps, and exercise its main interaction in the Pocket Works mobile browser QA workflow.
