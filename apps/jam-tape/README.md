# ЛЕНТА 2 — совместная музыкальная студия

ЛЕНТА — самостоятельное приложение Pocket Works с пятью синтезируемыми на устройстве инструментами: клавиши, бас, ударные, синт-лид и колокола. Звуки доступны без микрофона и внешнего CDN; WAV-сведение выполняется через OfflineAudioContext.

## Быстрый старт

- **Моя студия:** свободно играй клавишами A S D F G H J K, записывай ноты в личные фрагменты, редактируй и сохраняй эскиз офлайн.
- **Создать комнату:** PocketNet на Cloudflare Durable Objects выдаёт восьмизначный код и ссылку. До четырёх человек могут одновременно играть через интернет из любых сетей. Каждый управляет своей дорожкой; транспорт общий, а ведущий задаёт BPM и может начать новую композицию.
- **Войти по коду:** присоединись по коду или открой ссылку с `?room=CODE`. PocketNet автоматически пытается восстановить комнату после сетевого разрыва. Гостевой профиль допустим.
- **Ноты по шагам:** редактор 4 тактов по 16 шагов. Каждый такт показан двумя страницами по 8 шагов для комфортного управления на телефоне. Нажатие на ячейку добавляет или удаляет ноту. Доступны длина 1/2/4/8 шагов, динамика, обрезка, дублирование и удаление фрагментов.

У каждого музыканта максимум 6 фрагментов по 96 нот. Все нотные события проверяются сервером и принадлежат автору; клиенты не могут менять чужие записи. Передаются ноты и события синтезатора, но **не аудиофайлы**. Сервер хранит композицию, в том числе записи временно отключённых пользователей; при заполнении четырёх дорожек новое подключение вытесняет самую старую освободившуюся дорожку.

«В эфир» регулирует слышимость участника для остальных; «Слушать остальных» и «Только мои» работают локально. Текущий слышимый микс экспортируется в WAV. После выхода из комнаты композиция остаётся локальным эскизом. Покинуть музыкальную студию можно без потери своих записей.

## Архитектура

Клиент: `app.js`, `audio.js`, `shared/capabilities/net.js`. Серверный модуль: `server/module.ts`, immutable snapshot `pocketnet/module-versions/jam-tape/v1.ts`. Версия указана в `pocketnet/modules.lock.json`; для будущих серверных изменений создавать v2, v3 и так далее, не менять прошлые снимки. PocketLAN не загружается приложением.

## Проверки

`node --test apps/jam-tape/tests.mjs` — серверные проверки дорожек, прав автора и ведущего, синхронизации и доступа в комнату.

Обязательно проверить в браузерах: одиночный запуск без сети, создание и вход через PocketNet в двух вкладках/сетях, живые ноты и остановку, редактирование по шагам, WAV, изменение темпа, отключение/возврат и мобильную компоновку с безопасными зонами. Для публикации провести реальную Playwright-проверку и визуальный просмотр скриншотов.
