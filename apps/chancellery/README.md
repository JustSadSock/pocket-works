# КАНЦЕЛЯРИЯ 0.3

Локальный второй экран для Europa Universalis V в Pocket Works. Приложение не играет вместо пользователя: оно разбирает сохранения, сравнивает состояния страны и позволяет проверять собственные гипотезы перед действиями в игре.

## Основной сценарий

1. Импортировать plaintext/ZIP сохранение EU5.
2. Получить диагностику страны, карту и сравнение с предыдущими снимками.
3. Открыть **Сценарии** и задать прямые эффекты предполагаемого решения.
4. Сравнить сохранённые варианты по балансу, долгу, казне и простой окупаемости.
5. Перед войной открыть **Военную комнату**, задать силы противника и последовательность целей.
6. В **Сословиях** проверить, кто выигрывает и кто пересекает опасные пороги удовлетворённости/влияния.
7. В **Хронике** просмотреть ключевые изменения кампании по датам и графику.

## Точность сценариев

Лаборатория намеренно разделяет три типа вывода:

- **прямой расчёт** — арифметика из текущего снимка и введённых пользователем чисел;
- **оценка** — например простая окупаемость при неизменных прочих условиях;
- **неизвестно** — ИИ, события, рынки, миграция и скрытые модификаторы движка EU5.

Это предотвращает ложную точность: Канцелярия не обещает состояние страны через 25 лет, если для этого потребовалось бы воспроизвести движок игры.

## Военная комната

Проверяет:

- долю армии, отправленную в поход;
- наличие резерва;
- ручную оценку соотношения сил;
- финансовый запас войны;
- пищевой баланс выбранных целей;
- протяжённость последовательности целей при наличии координат;
- неизвестные данные, которые нельзя честно восстановить из снимка.

## Бинарные сейвы

Версия 0.3 добавляет **инспектор совместимости**, а не фальшивый binary parser. Для прямого `EU5bin` файла он может:

- распознать бинарный заголовок;
- извлечь безопасные текстовые подсказки версии/даты, если они присутствуют;
- построить fingerprint и диагностическую выборку 16-битных слов;
- экспортировать JSON-отчёт;
- валидировать и хранить resolver-пакеты token→name для будущего декодера.

Resolver-пакет сам по себе не включает декодирование. Полная поддержка Ironman остаётся отдельным техническим этапом и должна опираться на проверенный EU5 binary format, а не на эвристическое угадывание байтов.

## Файлы 0.3

- `app-v3.js` — интеграция стратегических экранов поверх стабильного v2.
- `scenario.js` — чистая модель сценариев.
- `warfare.js` — оценка военного плана.
- `politics.js` — перераспределение сословий.
- `chronicle.js` — временная линия и series.
- `binary-inspector.js` — безопасная диагностика бинарного файла и resolver registry.
- `strategic.css` — интерфейс v3.

```bash
node --check apps/chancellery/app-v3.js

node --check apps/chancellery/warfare.js
node --check apps/chancellery/politics.js
node --check apps/chancellery/chronicle.js
node --check apps/chancellery/binary-inspector.js
node --check apps/chancellery/sw.js
node --test apps/chancellery/tests/*.test.mjs
npm run registry:check
npm run validate:configs
```

Все пользовательские снимки, планы и resolver-пакеты остаются локальными в браузере.
