# КАНЦЕЛЯРИЯ 0.2

Локальный мобильный штаб для текстовых и ZIP-сохранений Europa Universalis V.

## Основной сценарий

1. Импортировать `.eu5` или ZIP-сохранение.
2. Получить нормализованный снимок державы и территорий.
3. Добавить следующий сейв той же кампании.
4. Сравнить показатели и изменения территорий.
5. Открыть пожар или возможность на картограмме.
6. Изучить конкретную территорию и доказательную цепочку.

## Что разбирается

- метаданные кампании и страна игрока;
- казна, доход, расходы, баланс, займы;
- территории, население, контроль, товары, культуры, религии, рынки, здания;
- сословия, армии, флоты, войны и отношения;
- координаты территорий, когда они действительно присутствуют в сохранении.

Имена полей EU5 могут меняться между патчами. Адаптер использует набор проверяемых алиасов, сохраняет диагностические предупреждения и не падает из-за неизвестных полей.

## Карта

Версия 0.2 показывает операционную картограмму. Если большинство территорий содержит координаты, используется их относительное расположение. В остальных случаях применяется стабильная табличная раскладка по владельцу и рынку. Приложение не рисует выдуманные границы.

Слои: контроль, население, товары, проблемы и владельцы. Поддерживаются перетаскивание, колесо мыши, pinch-to-zoom, поиск и фокусировка на территориях из диагностики.

## Ограничения

- бинарные и Ironman-сейвы отклоняются с кодом `BINARY_TOKEN_RESOLVER_REQUIRED`;
- точная географическая карта требует отдельного проверенного индекса игровых данных;
- причинные цепочки являются декомпозицией найденных показателей, а не симуляцией будущего EU5;
- старые снимки схемы 1 можно открыть, но для карты их нужно переразобрать из сохранённого исходного файла.

## Хранение

Снимки и исходные файлы сохраняются в IndexedDB `pocket-works-chancellery`. При недоступности IndexedDB сохраняются только паспорта в `localStorage`; исходный файл в fallback не помещается.
