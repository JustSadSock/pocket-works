# Сценограф

Тактильный теневой театр для телефона: двигайте бумажные фигуры и источник света, чтобы собрать живой силуэт. Решённые сцены открывают небольшую историю; свободная мастерская позволяет сохранить свою композицию.

Это приложение разрабатывается в отдельной папке `apps/scenograph/` и будет автономной Quick PWA.
