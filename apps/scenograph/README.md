# Сценограф

Бумажный театр теней с семью миниатюрами, которые складываются в одну маленькую историю. Расставляйте фигуры и меняйте положение лампы, пока тень не совпадёт с задуманным силуэтом. После финала можно сочинять собственные сцены в свободной мастерской.

## Как играть

1. Нажмите **«Открыть занавес»**. Перетащите бумажные фигуры по нижнему столу; для выбора фигуры можно коснуться её имени под сценой.
2. Поворачивайте выбранную фигуру кнопками **↶/↷** с шагом 15° и передвигайте лампу ползунком. Индикатор **«Совпадение»** показывает, насколько близка композиция к цели.
3. **«Показать намёк»** подсвечивает ориентир. **«Начать сцену заново»** возвращает исходную расстановку. В антракте сцена сохраняется, а после разгадки открывается следующая.
4. В **«Свободной мастерской»** добавьте до пяти фигур из палитры, поверните и расставьте их, настройте свет. **«Сохранить открытку»** скачивает композицию в PNG. Звук можно включить в верхней панели.

Есть текстовые пути обратно в Pocket Works из меню, антракта и экрана завершения. Управление рассчитано на касание и мышь; установка приложения не обязательна для игры.

## Устройство и офлайн

Приложение написано на обычных HTML, CSS и JavaScript с Canvas 2D. Сцены и фигуры лежат в локальном `levels.js`; сторонние сервисы и сетевые запросы для игры не нужны. Прогресс и состояние мастерской хранятся в локальном пространстве `pocket-works:scenograph`.

Установочный манифест и Service Worker находятся в этой папке. Кэш `scenograph-v0.1.0-p2` включает интерфейс, `levels.js`, значок и нужные файлы общей мобильной среды. После первого успешного открытия приложение перезагружается без сети; обновление использует механизм Pocket Works. Экспорт PNG создаётся в браузере и не отправляет сцену на сервер.

## Проверка

Из корня репозитория:

```bash
npm run registry:check
node --check apps/scenograph/app.js
node --check apps/scenograph/levels.js
node --check apps/scenograph/sw.js
npm run build:quality-site
npm run test:e2e
```

Для проверки офлайна откройте приложение из локального сервера после сборки, дождитесь установки Service Worker, затем отключите сеть и перезагрузите страницу. Для проверки экспорта сохраните открытку и откройте полученный PNG.
