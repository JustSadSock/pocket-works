# СТЫК

Отдельная мобильная Pocket Works Quick PWA: тактика пластичного фронта. Три сценария против локального ИИ. Нажмите на синий отряд, перетаскивайте центр для движения, конец линии для изменения ширины; режимы манёвр/строй/натиск/держать. Два приказа за ход, 8 секунд одновременной симуляции, потери и мораль сохраняются между раундами. Локальное автосохранение после каждого хода и восстановление при перезапуске.

Сеть в этом выпуске не используется, никаких зависимостей от PocketLAN нет. Установочная PWA, app-owned service worker и отдельный storage namespace.
