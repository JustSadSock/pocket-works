# FACET 2.0

FACET — локальное мобильное приложение для многовидового анализа геометрии внешности. Оно использует пять управляемых ракурсов, проверяет качество каждого кадра, объединяет ориентиры лица и показывает только те особенности, которые достаточно устойчиво повторились.

## Основной сценарий

1. Пользователь подтверждает право на использование фотографии.
2. FACET проводит через пять ракурсов: прямо, небольшой поворот влево, небольшой поворот вправо и два контрольных фронтальных кадра.
3. Плохие кадры отклоняются по резкости, свету, положению головы, выражению и перекрытиям.
4. Результат показывает устойчивые особенности, пограничные классификации, визуальный баланс и практическую интерпретацию.
5. Экспериментальная оценка восприятия доступна отдельно и не является главным результатом.

## Интерпретация 2.0

Для каждой измеренной черты рассчитывается отдельная опора из трёх компонентов:

- уверенность классификации и расстояние до границы категории;
- повторяемость между ракурсами;
- выраженность признака в общей композиции.

Главный экран разделяет:

- качество кадров;
- повторяемость ориентиров;
- уверенность отдельных классификаций;
- покрытие анализа устойчивыми признаками.

Слабые и пограничные выводы не удаляются, но показываются отдельно и не используются как точный факт. Итоговая шкала 1–5 сжимается к нейтральному значению и получает более широкий диапазон при недостаточной опоре.

## Ограничения

FACET анализирует видимую геометрию на конкретной серии кадров. Он не измеряет объективную красоту и не учитывает движение, голос, стиль, харизму, культурный контекст или индивидуальный вкус. 2.5D-профиль по обычной RGB-камере является приближением и не заменяет TrueDepth, фотограмметрию или медицинскую диагностику.

Приложение нельзя использовать для решений о здоровье, найме, доступе к услугам или ценности человека.

## Приватность и офлайн-режим

Фото обрабатываются локально и не сохраняются в истории. Первый запуск загружает модель; после успешного кэширования приложение может запускаться офлайн. Service Worker использует собственный префикс `facet-face-lab-` и не удаляет данные других приложений Pocket Works.

## Проверка

```bash
node apps/facet-face-lab/test.mjs
```

Тест проверяет калибровку итоговой оценки, выделение устойчивых и пограничных признаков, расширение диапазона при слабых данных и генерацию практических рекомендаций.
