# ПЕРЕЛИСТ

Двухлистовый редактор Pocket Works для текста и чисел.

- Лист 01 — свободный текст до 5000 знаков с выбором шрифта, размера 18–56 px, жирности, курсива, выравнивания и цвета.
- Лист 02 — несколько чисел с цифровой клавиатурой на мобильных устройствах.
- Переключение свайпом влево/вправо, кнопками 01/02 или стрелками клавиатуры вне поля ввода.
- Текст, оформление, числа и последний открытый лист автоматически сохраняются в `pocket-works:perelist`.
- Пока приложение активно, Screen Wake Lock удерживает экран включённым; после возврата из фона блокировка запрашивается заново.
- Если браузер не поддерживает Wake Lock или отклоняет запрос, приложение явно показывает это состояние и позволяет повторить запрос нажатием.
- Workshop умеет сбросить состояние приложения.
- Приложение работает офлайн после первого открытия.
