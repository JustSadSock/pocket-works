# Toy Lens

Toy Lens — отдельное Pocket Works приложение для локальной tilt-shift обработки фото и видео.

## Что умеет

- принимает фото и видео любого соотношения сторон;
- работает с любым входным разрешением, автоматически уменьшая только рабочий предпросмотр;
- даёт перетаскивать резкую полосу прямо по кадру;
- настраивает blur, ширину резкой зоны, растушёвку, наклон, насыщенность, контраст, яркость и виньетку;
- показывает оригинал удержанием одной кнопки;
- экспортирует фото в JPEG/PNG;
- экспортирует видео через `MediaRecorder` в лучший доступный MP4/WebM;
- пытается сохранить исходный звук через Web Audio;
- не загружает пользовательские файлы в сеть;
- сохраняет только настройки эффекта в локальном хранилище;
- после первого успешного запуска оболочка приложения доступна офлайн.

## Совместимость форматов

Приложение не содержит отдельный многомегабайтный кодек-пакет: декодирование входного медиа выполняет сам браузер. Поэтому JPEG/PNG/WebP/AVIF, MP4/MOV/WebM и другие обычные форматы работают там, где их декодирует установленный Safari/Chrome/Edge/Firefox. HEIC/HEIF обычно доступен на Apple-устройствах. Если контейнер известен, но конкретный видеокодек не поддерживается системой, приложение показывает понятную ошибку вместо пустого экрана.

## Разрешение экспорта

- **Авто:** до 4096 px по длинной стороне для фото, до 1920 px для видео.
- **1080p:** до 1920 px по длинной стороне.
- **4K:** до 3840 px по длинной стороне.
- **Оригинал:** без апскейла, с защитным лимитом 8192 px по длинной стороне, чтобы не упереться в аппаратный лимит canvas на телефоне.

Видео рендерится локально по ходу воспроизведения. Это сознательно сохраняет совместимость без серверной обработки и внешних зависимостей.
