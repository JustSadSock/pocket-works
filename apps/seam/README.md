# ОСЬ

Абстрактная тактическая дуэль: двигайте формации, толкайте линии, возвращайте резерв и победите удержанием центра или выбиванием Корня.

This app is independently served from `/apps/seam/`. Launcher and release metadata are owned by `app.config.json`; the app owns its manifest, service worker and local state.

Validate with `npm run validate` after building Enhanced apps, and exercise its main interaction in the Pocket Works mobile browser QA workflow.
