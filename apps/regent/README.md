# РЕГЕНТ

Тактильная стратегическая лаборатория для Pocket Works. Игрок управляет вымышленной федерацией из девяти провинций и переживает двенадцать кризисных ходов.

## Главная механика

Указы не выбираются из абстрактного меню: печать перетаскивается на конкретную провинцию. Эффект проходит по карте каскадом — часть решения достаётся соседям, иногда как польза, иногда как побочный ущерб.

## Сценарии

- **Голодный год** — дефицит продовольствия и дорогой хлеб.
- **Пограничная искра** — напряжённые окраины и милитаризация.
- **Тихий раскол** — богатые провинции требуют больше самостоятельности.

## Управление

Нажмите или перетащите печать указа на провинцию, проверьте прогноз и подтвердите решение. Состояние кампании сохраняется локально после каждого хода.

## Технически

Plain HTML/CSS/JavaScript, SVG-карта, Web Audio без внешних ассетов, собственный service worker и изолированное хранилище `pocket-works:regent`.
