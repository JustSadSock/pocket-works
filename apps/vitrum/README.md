# VITRUM 2 — мастерская витражиста

Мобильный тактильный симулятор средневекового витражного ремесла. Не 3D-макет и не редактор кнопок: взаимодействие происходит пальцем непосредственно на стекле, свинце и олове.

## Игровой цикл

1. Подберите листы кобальтового, рубинового, янтарного, зелёного или молочного стекла и раскрасьте картон северной розы.
2. Для каждой из 7 деталей проведите железным резцом замкнутый надрез. Когда линия замкнётся, 5 раз вручную отколите лишнее стекло клещами в отмеченных местах; сколы дают осколки, звуки и тактильный отклик.
3. Зажмите деталь пальцем в нижнем лотке и **перетащите** на соответствующий силуэт на световом столе. Перемещение и магнитная подгонка визуальны, простое нажатие не засчитывается.
4. Протяните свинцовый профиль пальцем по периметру каждого куска. Сеть возникает только на пройденных участках, а не появляется целиком нажатием на кнопку.
5. На 7 соединениях удерживайте наконечник железа около 0.7 секунды. Припой накапливается, меняет цвет и получает блик, пока узел не спаян.
6. Поднимите изделие в каменное окно. Перемещайте солнце и наблюдайте цветные отсветы.

## Техническое устройство

- Quick Canvas 2D + DOM, mobile-first, portrait, без CDN и зависимостей.
- Детали: стабильная геометрия, процедурная неоднородность выдутого стекла, пузырьки, волнистые прожилки, гризайль, профили с бликом.
- Pointer Events + захват указателя, приложение работает с мышью и пальцем; звуки по Web Audio включаются только после пользовательского действия.
- Автосохранение: `pocket-works:vitrum:state`, прежний формат совместим; старый прогресс пайки автоматически переносится в новую стадию свинца.
- `window.__AI_TEST_STATE__`: stage / cut / chip / assembled / lead / soldered / heat / finished.
- Офлайн Service Worker с версионным кэшем `vitrum-v2.0.0`; интеграция с обновлениями и оболочкой Pocket Works.

## Ограничения

Сколы и олово моделируются художественно, а не физическим solver стекла. Макет содержит семь деталей: цель — качественный законченный процесс, не процедурная генерация произвольных картонов.
