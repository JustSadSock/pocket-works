# VITRUM

VITRUM — портретный Pocket Works vertical slice о ремесле средневекового витражиста. Он сознательно не симулирует целую мастерскую в 3D: вся сложность вложена в сам материал, свет и четыре хорошо читаемые операции.

## Основной сценарий

1. На световом столе выбрать стекло и раскрасить шесть лепестков розы и центральный медальон.
2. По очереди провести резцом по контуру каждого из семи элементов. Трасса допускает небольшую неточность, но требует пройти реальный контур.
3. Выбрать вырезанные элементы в лотке и установить их в соответствующие ячейки.
4. Пропаять семь узлов свинцовой сети касанием.
5. Открыть готовое окно в каменной нише и менять угол солнца, наблюдая цветной свет.

## Технически

- Quick Canvas/DOM приложение без внешних зависимостей.
- Стекло полностью процедурное: градиенты, неоднородность, прожилки, пузырьки и световые блики.
- Состояние хранится в `pocket-works:vitrum:state` и автоматически восстанавливается.
- `window.__AI_TEST_STATE__` публикует текущую стадию, прогресс раскроя, сборки и пайки для QA.
- Web Audio используется только после пользовательского жеста; звук можно отключить.
- PWA и Service Worker кэшируют только файлы приложения и обязательный общий mobile runtime.
