# VITRUM 3 · свободная мастерская витражиста

Полностью свободное создание витражей, без шаблонов, медальонов и обязательной семичастной розы. Фрагменты — замкнутые произвольные многоугольники, обведённые пальцем на отдельном листе цветного стекла.

## Пользовательский сценарий

1. Выберите цвет листа. Нажмите **Новый фрагмент**.
2. Нарисуйте любую замкнутую границу пальцем (свободный жест без сетки). Контур при отпускании замыкается; самопересечение недопустимо, минимальный размер — чтобы стекло реально можно было вырезать. Если форма не удалась, перерисуйте.
3. Захватите четыре отмеченные точки клещами, вытягивая их **наружу от детали**. Кромка откалывается, появляются осколки. Только после этого создаётся свободная деталь.
4. Готовый фрагмент возникает в световом окне. Перетащите его в любое место. При выделении доступны поворот вправо/влево, увеличение, уменьшение, перекрашивание, удаление.
5. При желании выделите стекло и нажмите **Свинец**. Рукой обведите **его собственную границу**, постепенно прокладывая тяжёлый профиль. На трёх точках удерживайте раскалённое железо, плавя припой.
6. Добавляйте новые фрагменты сколько угодно (до 70 для стабильности мобильного устройства), комбинируйте их и завершайте рисунок по своему усмотрению.
7. Кнопка **На свет** показывает работу в каменной нише. Сдвигайте солнце и сохраняйте PNG.

## Визуальная технология

- Рендер на Canvas 2D с имитацией 2.5D глубины, не полноценно моделируемая физика или real-time raytracing.
- Каждая панель имеет боковые грани с разной освещённостью, отдельную тень, градиент толщины, прожилки, пузырьки, блики, приподнятый свинцовый кант и выпуклые узлы пайки.
- Свободная композиция строится из локальных координат каждой детали; все пользовательские вершины сохраняются.
- Стадии и жесты восстанавливаются после перезагрузки, включая незавершённую прокладку свинца.
- Пальцевое управление через Pointer Events; рендер масштабируется по DPR; безопасные области и портретная ориентация.
- Звук можно отключить. Обновление/offline через стандартный Pocket Works runtime и свой SW.

## Хранение и миграция

Данные v3 хранятся в новом ключе `pocket-works:vitrum:freeform:v3`. Исходное состояние v2 `pocket-works:vitrum:state` не удаляется и не перезаписывается: старый фиксированный картон нельзя правдиво представить как свободно нарисованное пользователем изделие.

`window.__AI_TEST_STATE__` публикует состояние создания: количество самодельных контуров, количество фрагментов со свинцом и пайкой.

## Ограничения

Это выразительный 2.5D симулятор, а не физически точная 3D-модель стеклорезного станка. Кромки, металлы, пузырьки и преломления стилизованы. Рисунки могут накладываться друг на друга (слои); автоматической оптимизации под раскладку без пересечений пока нет.
