# ГЛЯДЬ — мастерская второго взгляда

Эксперимент Wildcard №01: локальный редактор рельефа и однокартинных стереограмм (SIRDS).

## Как пользоваться
1. Рисуйте по матрице глубины (кисть / ластик), регулируйте высоту и диаметр.
2. Посмотрите справа на стереограмму (на телефоне — вкладка «Секрет»).
3. Расслабьте фокус за экраном, совместите две верхние точки в три.
4. Поменяйте шум и цвет, сохраните изображение в PNG. Изменения хранятся локально.

### Что реализовано
- Плавная кисть и ластик по 180×120 глубинной карте;
- Сердце, кольцо и волна, отдельная отмена до 24 изменений;
- Детерминированный row-link алгоритм SIRDS, унаследованные случайные пиксели для пар изображений;
- Сохранение состояния в localStorage, export PNG 1200×800 без серверов;
- Адаптивный двухоконный / однооконный режимы, офлайн Service Worker, PWA, выход в Pocket Works.

На плоской глубинной карте выдаётся повторяющаяся текстура. При разном профиле глубины смещается расстояние связанных пикселей — так возникает стереоскопическая иллюзия. Генератор намеренно упрощён по сравнению с алгоритмом Thimbleby–Inglis–Witten: скрытые поверхности и предотвращение «эха» не полностью реализованы. Некоторым людям сложно или невозможно различить объём.
