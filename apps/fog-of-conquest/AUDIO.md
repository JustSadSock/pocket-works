# Туман завоеваний — звуковая палитра
- Материалы: пергамент полевого штаба, кожи папок, дерево стола, кольчуга, знаменная ткань.
- Выделение: тихий матовый щелчок деревянной фишки, короткий полосовой шум.
- Перемещение: мягкое трение фишки по вощённому пергаменту, низкочастотный фильтр.
- Атака: пара сдержанных ударов металла по дереву, без голливудских взрывов.
- Захват/набор: более длинный бумажный шорох и приглушённая древесная фактура.
- Ошибка: короткий сухой звук без электронного тона; действия остаются видимыми и при отключённом звуке.
- Характер: сухой, тёплый, тактильный, негромкий, непрерывности музыки нет.
- Используется синтез шумового буфера с bandpass/lowpass и огибающими. Звуки отключаемы в меню; запуск только по жесту.
