# INKFALL

A portrait-first Canvas arcade game for Pocket Works.

## Loop
Drag horizontally to steer the falling shard. Avoid tears, collect embers, fill Impulse and use **ПРОБИВ** for a short invulnerable burst. Depth is the score; the best score is stored locally.

## Visual thesis
A living cobalt woodcut: layered flowing bands, etched contour lines, bone-white player silhouette, oxidized teal secondary motion and a single burnt-orange gameplay accent. UI is sparse and angular so the playfield remains dominant.

## Controls
- Drag anywhere on the playfield: steer.
- ПРОБИВ: spend full impulse.
- Ⅱ: pause.
- Menu/pause/game-over all include a text route back to Pocket Works.

## Offline
The app precaches its shell and the shared mobile runtime through its app-owned Service Worker.
