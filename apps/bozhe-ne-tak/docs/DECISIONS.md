# Журнал решений (2026-10-17)

| ID | Решение | Причина / проверка |
|---|---|---|
| D01 | Название «БОЖЕ, НЕ ТАК!»; комедийная религия из ошибок | Ключевая уникальная механика, последствия не scripted skit |
| D02 | 2–5 игроков, проектируем прежде всего под троих | Выразительные асимметричные роли, поддержка типичной компании |
| D03 | 5 обрядов за 12–18 минут | Быстрые партии, реиграбельность |
| D04 | PocketNet, не PocketLAN | Актуальная политика проекта |
| D05 | Без встроенного голосового чата в MVP | Транспорт не реализует media-слой; внешние приложения необязательны |

| D07 | Сервер определяет результат, клиенты проигрывают анимацию по seed | Одинаковый результат при небольшом числе событий |

| D10 | Локальный вертикальный срез до сервера | Ускоряет проверку механики, не перегружает Cloudflare |
| D11 | Живой деревянный алтарь вместо паперкрафта и 3D | Узнаваемый визуал с бюджетной реализацией |
| D12 | Догмат изменяет правила, не только текст | Главный источник системного юмора |
| D13 | В первой версии P0 — честное проектное досье | Не публиковать неготовые комнаты/кнопки как игру |

## Открытые вопросы (не блокируют P0)
1. Минимальная глубина подсказок для прохождения без голоса: проверяется P3 на трёх телефонах.
2. Сколько догматов можно поддерживать без перегрузки: стартовый предел 3, оценка после P4.
3. Материалы/слои лицевой анимации бога: выбор по визуальным сравнительным тестам P5.
4. Улучшать общий PocketNetHub ради dirty-state экономии только после измерений; отдельный platform PR.
5. Конкретное число сообщений за матч откалибровать тестами P2–P6.

## Не делаем в MVP
Встроенный voice, LLM-генерацию требований, физику всех предметов на сервере, P2P transport, переназначение архитектуры PocketWorks, 3D по умолчанию, многочасовые метапрогрессии и cosmetic store без функциональных кастомизаций.

## Новые решения P2 (17.10.2026)
- D14: `module.ts` и immutable v1 со встроенными pure правилами, чтобы сохранённые комнаты не зависели от будущих правок движка.
- D15: Каждая из 2–5 ячеек подношений управляется самим игроком; общий результат — округлённая средняя оценка всех. Ошибка одного влияет на команду.
- D16: Vote через все подтверждённые голоса и разрешение ничьей в пользу первого предложения, без произвольной случайности.
- D17: Публичный snapshot сознательно не содержит секретов; P3 запускается только после server-private views.
- D18: 6-секундный heartbeat, серверные дедлайны (125/16/28 с), тайм-аут без сервера на 60fps.
- D19: Не выбравший дар до дедлайна даёт дефолтный `bread/wash/1/low` — хуже оптимального решения, но команда не зависает.
- D20: Чистый локальный v0.2 остаётся доступным и сохраняется независимо от сетевых комнат.
