# ПРИЛИВ · v1.0.0

Офлайн-головоломка Pocket Works. Объедините все 49 островов: выбор цвета перекрашивает связанную область в левом верхнем углу и присоединяет соседние острова. Палитра показывает ожидаемый прирост. Доступны остров дня, случайные поля, отмена, рестарт и локальные рекорды.

- `core.mjs` — детерминированное поле, связная область, заливка, прирост и проверка победы.
- `app.js` — поле, палитра, клавиши 1–5 и локальное сохранение.
- `manifest.webmanifest`, `sw.js` — автономная PWA.
- Хранилище: `pocket-works:tidepool:state`. Ежедневное поле меняется по дате UTC.

В корне Pocket Works запустите `npm run prepare:site` и откройте `/apps/tidepool/` через сервер проекта. Проверьте смену цвета, отмену, рестарт и восстановление после перезагрузки.

Автоматические тесты: `node --test apps/tidepool/core.test.mjs`.
