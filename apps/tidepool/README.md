# ПРИЛИВ

Quick Pocket Works color puzzle, version 1.0.0. Start in the north-west island, select a color to absorb adjacent islands of that color, and capture the full archipelago in as few moves as possible. Daily and random maps, move counter, territory size, undo, restart, and new map controls are available. Keys 1–5 also select colors. The app stores local progress/records and has its own manifest, icon and service worker.

## Run

Open `/apps/tidepool/` through Pocket Works, using the standard repository development or production build workflow.

## Validation

Use the existing registry, health and browser checks; this documentation-only change does not change the app implementation or validation rules.
