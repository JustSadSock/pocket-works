# ПИКТО — язык без слов

Браузерная party-игра (2–8 игроков) внутри PocketWorks, интернет-комнаты через PocketNet на Cloudflare Durable Objects. Каждый участник по очереди становится автором сообщения из векторных пиктограмм; остальные разбирают отношения между объектами, а не угадывают предметы по отдельным значкам. Победа общая, без рейтинга против друзей.

## Сценарий
1. Открыть приложение, при необходимости войти в Pocket ID в оболочке. Ник и цвет аватара берутся из GET /pocket-id/me. PocketNet пока выдаёт отдельную гостевую транспортную сессию; она не является подтверждённой авторизацией аккаунта.
2. Создать комнату, скопировать восьмизначный код / ссылку. Участники входят через другие устройства или вкладки.
3. Создатель запускает игру, каждый участник один раз становится автором. Автор видит фразу и может открыть все четыре близкие версии смысла, добавляет символы в композицию, меняет их размер и поворот, перетаскивает по доске и публикует работу.
4. Остальные выбирают вариант ответа, через 38 секунд или после всех ответов открывается правильная фраза.
5. Раунды переходят автоматически после 11 секунд или по кнопке ведущего. В конце показываются совместные результаты и галерея, можно начать новую партию.

Состояние и действия проверяются серверным модулем apps/picto/server/module.ts. Сеть использует общую библиотеку shared/capabilities/net.js. Guest-сессия отдельно на вкладку. В комнате хранится не более 26 фигур на доске, 8 игроков; сервер проверяет форму и размеры данных.

## Смысловые испытания v1.1
Сервер генерирует **127 наборов × 4 разных варианта = 508 заданий**. Все ответы в одном раунде используют одинаковые сущности, но различают действие, положение, направление отношения, превращение, путь или обмен. Порядок ответов и правильная версия случайны, шесть типов перемешиваются равномерно; один набор не повторяется в одной партии. Автор видит варианты только по нажатию «4 смысла», а разгадывающие получают их после публикации композиции. Шесть новых условных знаков позволяют показывать отрицание, обмен, повтор, путь, маску и перемену; птица перерисована.

Прежние комнаты продолжают использовать неизменяемую серверную версию v1, новые — v2. Полный серверный ответ скрывается в персональном игровом событии до раскрытия; PocketNet core при переподключении всё ещё отправляет сырой снимок состояния комнаты, поэтому без серверного изменения core это не является защитой от намеренного просмотра WebSocket-трафика.

## Сборка и тестирование
`node --check apps/picto/app.js`
`node --check apps/picto/symbols.js`
`node --check apps/picto/sw.js`
`node --experimental-strip-types apps/picto/qa/rules.mjs` — 25 завершённых матчей на восьмерых, проверка 6 типов, отсутствия повтора и адресного ответа
`npm run registry:check`
`node scripts/build-pocketnet-modules.mjs --snapshot` (при релизе новой версии правил; сохранить immutable snapshot и lock)

Проверить два браузера: код комнаты, живое редактирование, таймеры, приватную фразу автора, однократные ответы, общий результат, выход ведущего, переподключение после reload и профильный ник. Настоящую защиту Pocket ID внутри PocketNet сервер пока не обеспечивает; ник передаётся как отображаемое имя.

Дизайн — плакатная типография и линогравюра: бумага, кобальт, охра, терракота, крупные гравированные знаки. Никаких внешних ассетов.
