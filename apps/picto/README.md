# ПИКТО — язык без слов

Браузерная party-игра (2–8 игроков) внутри PocketWorks, интернет-комнаты через PocketNet на Cloudflare Durable Objects. Каждый участник по очереди становится автором сообщения из векторных пиктограмм; остальные выбирают его смысл. Победа общая, без рейтинга против друзей.

## Сценарий
1. Открыть приложение, при необходимости войти в Pocket ID в оболочке. Ник и цвет аватара берутся из GET /pocket-id/me. PocketNet пока выдаёт отдельную гостевую транспортную сессию; она не является подтверждённой авторизацией аккаунта.
2. Создать комнату, скопировать восьмизначный код / ссылку. Участники входят через другие устройства или вкладки.
3. Создатель запускает игру, каждый участник один раз становится автором. Автор видит фразу, добавляет символы в композицию, меняет их размер и поворот, перетаскивает по доске и публикует работу.
4. Остальные выбирают вариант ответа, через 38 секунд или после всех ответов открывается правильная фраза.
5. Раунды переходят автоматически после 11 секунд или по кнопке ведущего. В конце показываются совместные результаты и галерея, можно начать новую партию.

Состояние и действия проверяются серверным модулем apps/picto/server/module.ts. Сеть использует общую библиотеку shared/capabilities/net.js. Guest-сессия отдельно на вкладку. В комнате хранится не более 26 фигур на доске, 8 игроков; сервер проверяет форму и размеры данных.

## Сборка и тестирование
`node --check apps/picto/app.js`
`node --check apps/picto/symbols.js`
`node --check apps/picto/sw.js`
`npm run registry:check`
`node scripts/build-pocketnet-modules.mjs --snapshot` (при релизе новой версии правил; сохранить immutable snapshot и lock)

Проверить два браузера: код комнаты, живое редактирование, таймеры, приватную фразу автора, однократные ответы, общий результат, выход ведущего, переподключение после reload и профильный ник. Настоящую защиту Pocket ID внутри PocketNet сервер пока не обеспечивает; ник передаётся как отображаемое имя.

Дизайн — плакатная типография и линогравюра: бумага, кобальт, охра, терракота, крупные гравированные знаки. Никаких внешних ассетов.
