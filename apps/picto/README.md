# ПИКТО — язык без слов

Браузерная party-игра (2–8 игроков) внутри PocketWorks, интернет-комнаты через PocketNet на Cloudflare Durable Objects. Каждый участник по очереди становится автором сообщения из векторных пиктограмм; остальные разбирают отношения между объектами, а не угадывают предметы по отдельным значкам. Победа общая, без рейтинга против друзей.

## Сценарий v1.2
1. Открой игру, создай комнату и пригласи 1–7 друзей по коду или ссылке.
2. Автор получает уникальную фразу из **пяти смысловых частей**: субъект, действие, объект, предлог и место. В каждом раунде из 34 нарисованных знаков доступны **18**, а 1–2 предметных знака целенаправленно запрещены. При этом остаётся хотя бы один буквальный знак из основных существительных.
3. Автор помещает доступные символы на поле, поворачивает и масштабирует их, затем публикует композицию. Запрещённый символ нельзя отправить даже напрямую через сетевой пакет.
4. Угадывающие независимо заполняют пять выпадающих полей. Для каждого поля доступны 8–10 вариантов; можно **оставить любое поле пустым**. Требуется хотя бы одна заполненная ячейка. При смене предлога последнее существительное в списке автоматически склоняется; ответ сравнивается по смысловому индексу, независимо от окончания.
5. После окончания таймера или всех ответов появляется исходная фраза, разбор по каждому слову и результаты других игроков. За точный ответ начисляется +2, за ошибку −1, за пропуск 0 (не менее нуля за всю отправленную версию). Прогресс считается по числу точных слов, а не по угадыванию одной целой фразы.
6. В конце — общая галерея сообщений и возможность повторить матч. Автор меняется каждый раунд, шесть тематик заданий перемешиваются и не повторяют один сюжет в пределах партии.

## Генерация и честность
127 тематических сюжетов × десять вариантов действий × восемь пространственных отношений × вариативные наборы существительных. Точные комбинации создаются сервером при старте раунда. Подбор вариантов не раскрывает ответ: любая ячейка содержит правдоподобные альтернативы, и вариант ответа не определяется простым исключением готовых предложений.

Состояние и действия проверяются серверным модулем `apps/picto/server/module.ts`. Сеть использует общую библиотеку `shared/capabilities/net.js`. Гостевая сессия отдельна на вкладку. На доске максимум 26 фигур; в комнате 2–8 участников. Автор получает фразу персональным событием только во время композиции. PocketNet core всё ещё может отправлять внутренний снимок комнаты в транспортной синхронизации: абсолютная секретность от намеренного анализа сетевых пакетов требует отдельного исправления core.

**Версии:** v1 и v2 остаются неизменяемыми для уже созданных комнат; новые комнаты запускают v3. Браузерный клиент v1.2 не рассчитан на подключение к старой комнате после reload — для полной обратной совместимости потребуется клиент с версиями протокола раунда.

## Сборка и тестирование
`node --check apps/picto/app.js`
`node --check apps/picto/symbols.js`
`node --check apps/picto/sw.js`
`node --experimental-strip-types apps/picto/qa/rules.mjs` — 25 полных матчей на восьмерых, пять ячеек, отказ от пустого ответа, запрет знаков, частичные очки, адресная приватность
`npm run registry:check`
`node scripts/build-pocketnet-modules.mjs --snapshot` (при релизе новой версии правил; сохранить immutable snapshot и lock)

Проверить два браузера: код комнаты, живое редактирование, таймеры, приватную фразу автора, однократные ответы, общий результат, выход ведущего, переподключение после reload и профильный ник. Настоящую защиту Pocket ID внутри PocketNet сервер пока не обеспечивает; ник передаётся как отображаемое имя.

Дизайн — плакатная типография и линогравюра: бумага, кобальт, охра, терракота, крупные гравированные знаки. Никаких внешних ассетов.
