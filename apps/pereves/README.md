# ПЕРЕВЕС

Четыре головоломки на баланс подвесных скульптур. Выберите груз на столе, затем место на соответствующей перекладине. Момент силы равен массе × плечо; в двойном подвесе нижняя перекладина учитывается как груз массы уже размещённых на ней грузов. Для победы нужно разместить все грузы и обнулить моменты обеих перекладин. Отмена восстанавливает предыдущую расстановку. Прогресс каждого уровня сохраняется локально.

Проверка: `node --test apps/pereves/core.test.mjs`.
