# СВИДЕТЕЛЬ

Wildcard: шесть логических дел от пяти до семи событий. Улики описывают порядок, соседство, точное расстояние или отсутствие соседства. Две записи меняются местами последовательными касаниями. Противоречия видны; проверка закрывает дело только при соблюдении всех ограничений. Подсказка указывает одну неверную позицию. Состояние сохраняется локально. Нет сети, звука и внешних зависимостей.

## Проверки

`node --test apps/svidetel-interval/core.test.mjs` — полный перебор решений для каждого дела, стартовая позиция и инварианты перестановки. Browser QA должна проверить два касания, проверку, отмену, подсказку, сброс, сохранение, мобильный и настольный режимы. Visual sign-off и production deployment ещё не подтверждены.
