# МОРОК

Портретный offline-first roguelike-декбилдер для Pocket Works. Визуально это тёмный пиксельный 2.5D каменный зал: низкое внутреннее разрешение Canvas, арки, плиты, знамёна, свечи, жёсткие силуэты и процедурные карточные иллюстрации без внешних ассетов.

## Основной цикл

1. На каждой глубине выбрать один из следов: бой, добыча, знак, костёр или алтарь.
2. В бою разыгрывать существ и ритуалы на четыре линии, читая заранее показанный вражеский вход.
3. Один раз за ход можно принести своего зверя в жертву: получить Останки и сохранить выбранную метку как Наследие следующему существу.
4. После боя добавить карту или отказаться, а между боями переносить метки навсегда, улучшать существ и собирать глобальные Знаки.
5. На девятой глубине победить хозяина зала. Новый seed заново собирает маршрут, награды, противников и порядок колоды.

## Хранение

- текущий забег: `pocket-works:morok:run:v1`;
- профиль: `pocket-works:morok:profile:v1`;
- звук/вибрация: `pocket-works:morok:prefs:v1`.

## Проверка

```bash
node --check apps/morok/app.js
node --check apps/morok/game-core.js
node --test apps/morok/tests/game.test.mjs
npm run registry:check
```

Приложение не использует сетевые ассеты и после первого успешного визита полностью работает офлайн.
