# Trace Mosaic — этап 1: устойчивость мультиплеера

Реализация: 2026-10-19. Клиент **v0.2.1**, PocketNet immutable rules **v5**.

## Что изменено

**Соединение и комнаты**
- При повторном подключении PocketNet использует сохранённые сессионные токен и комнату. URL-приглашение в другую комнату имеет приоритет над ранее сохранённым номером.
- Убрана повторная команда join_room из события boot: ранее PocketNet мог присоединиться автоматически, а приложение отправляло вторую команду.
- При временном обрыве серверная копия комнаты и клиентская картина не удаляются. UI показывает восстановление; действия на поле блокируются до возвращения связи.
- После rejoin клиент получает новый персональный state и отправляет heartbeat. Серверные изменения приходят через `game_event.state`; события presence вызывают sync heartbeat.
- Неподходящая комната другой игры и закрытая комната возвращают пользователя в меню с объяснением.

**Presence и владение фрагментами**
- Сервер принимает heartbeat от аутентифицированного участника каждые ~2,5 секунды при работающих таймерах вкладки.
- Двадцатисекундное окно предотвращает потерю хода из-за краткого разрыва.
- По истечении окна при следующем сообщении живого участника система помечает пропавшего неактивным, удаляет его активный drag, выбирает нового хоста и перераспределяет неоконченные фрагменты между активными игроками.
- Завершённые корректно размещённые фрагменты остаются на поле; все некорректно размещённые и находящиеся в лотке получают доступного владельца.
- Вернувшийся игрок может получить новый фрагмент, **если у товарищей есть запас в инвентаре**; готовые фрагменты не отбираются.
- Отдельный `onLeave` немедленно передаёт управление и фрагменты на основе серверного исключения участника, не дожидаясь истечения окна.

**Время, офлайн, UX**
- Серверная абсолютная отметка времени `endAt` и `serverNow` используются для корректной индикации таймера на телефонах с отличающимся системным временем.
- Результат фиксируется в момент завершения. Если все клиенты закрыли вкладки, сервер завершает раунд на первом следующем авторизованном сообщении. **Независимый серверный alarm точно в момент дедлайна без активных соединений не реализован**.
- Практика хранится в localStorage, доступно возобновление. Кнопка «Новая тренировка» очищает прогресс после подтверждения. Возврат из соло обновляет страницу, восстанавливая онлайн-клиент.
- Оба входа в практику перенесены внутрь прокручиваемого стартового экрана; добавлено состояние восстановления сети и кнопка повторного подключения.

## Порядок проверок и критерии

`npm run test:trace-mosaic` запускает две группы тестов:
- `simulation.test.mjs`: 16 сценариев, включая начало/финал матчей 3/5, траектории, отмену, счёт, время, reconnect grace, уход хоста, сброс владения и серверную метку времени;
- `network.test.mjs`: 4 mock-теста на ссылки-приглашения, отсутствие двойного join, потерю и восстановление транспорта, чужую игру.

Перед выпуском на живой Cloudflare/PocketNet необходимо отдельно провести:
1. Реальный полный раунд в трёх и пяти отдельных WebSocket-сессиях.
2. Разрыв сети меньше 20 с и больше 20 с, возвращение хоста, уход игрока с незавершённой плиткой.
3. WebKit/iPhone портрет и landscape, Android 360px, множественные касания и фоновые вкладки.
4. Сохранение соло, сброс, возврат в онлайн и обновление Service Worker с `0.2.0` до `0.2.1`.
5. `npm run build:pocketnet`, `npm run test:trace-mosaic`, `npm run health` и проверки деплоя.

В данной итерации проведены **встроенные тесты модели/транспорта**, но живой Edge E2E, WebKit и полный pipeline не запускались из подключённого GitHub-контекста. Старые опубликованные снимки PocketNet v1–v4 оставлены неизменными.
