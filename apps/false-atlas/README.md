# ЛОЖНЫЙ АТЛАС

Мобильная тактическая игра для Pocket Works о принятии решений по противоречивым сведениям.

## Игровой цикл

1. Три источника рисуют на карте предполагаемые маршруты вражеского отряда.
2. Игрок может скрывать и сопоставлять слои источников.
3. Ограниченная линза проверяет выбранный город и показывает, есть ли там настоящая угроза.
4. Защитная восковая печать ставится на один город.
5. После скрепления приказа истинный маршрут проявляется на карте, а печати источников получают насечку достоверности или трещину.
6. Кампания заканчивается после шести ночей либо после потери трёх знамён.

## Управление

- Перетащите линзу или защитную печать на город. Короткое нажатие на инструмент также включает режим выбора города.
- Нажимайте на печати источников, чтобы скрывать или показывать их следы.
- Большая красная печать с галочкой завершает ночь.
- Круглая латунная кнопка в правом верхнем углу включает и выключает звук.

## Технические детали

- Runtime: quick, без внешних зависимостей.
- Рендер карты: Canvas 2D с DOM-слоем доступных сенсорных целей.
- Сохранение: `localStorage` в пространстве `pocket-works:false-atlas`.
- PWA: собственный manifest, install icon и versioned service-worker cache.
- Поддержаны safe-area, portrait mobile layout, pointer events, keyboard focus, reduced motion, Web Audio и vibration fallback.
