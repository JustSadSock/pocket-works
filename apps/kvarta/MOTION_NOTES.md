# КВАРТА — motion pass 1.1

- Поворот квартета теперь следует четверти окружности вокруг общей заклёпки вместо линейной перестановки.
- Фрагменты приподнимаются над листом через масштаб и динамическую тень, затем мягко осаживаются.
- Рама получает короткий механический recoil, направленный по ходу вращения.
- Заклёпка отвечает на нажатие глубиной и пружинным доворотом после отпускания.
- Сбросы и крупные перестройки используют отдельную короткую анимацию усадки, а не ложную дугу.
- Экран успешного оттиска получил отдельный вход и штамп-пружину.
- При `prefers-reduced-motion` остаётся только короткое изменение прозрачности без пространственного движения.
