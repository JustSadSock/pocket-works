# КВАРТА 1.0.0

Мобильная головоломка для Pocket Works про вращение перекрывающихся блоков 2×2.

## Механика

Поле 4×4 собрано из шестнадцати фрагментов одного печатного оттиска. Между клетками находятся девять заклёпок. Каждая заклёпка управляет окружающим её квартетом 2×2:

- обычное нажатие поворачивает четыре фрагмента по часовой стрелке;
- свайп вправо или вниз поворачивает по часовой;
- свайп влево или вверх — против часовой;
- сами фрагменты остаются ориентированы одинаково, меняются только их позиции.

Цель — восстановить изображение из образца над полем.

## Содержание

- 20 уровней в четырёх главах с нарастающей длиной гарантированного решения;
- каждый стартовый расклад генерируется из собранного состояния только допустимыми ходами, поэтому всегда решаем;
- процедурные ризографические изображения, уникальные для каждого листа;
- отмена, безопасный подтверждаемый перезапуск, пауза и выбор уровней;
- сохранение открытых листов, лучших результатов и незавершённой партии;
- синтезированный звук и мягкая вибрация с отключаемым звуком;
- Pointer Events, мобильный shared runtime и полноценная офлайн-PWA.

## Хранение

Профиль хранится в `localStorage` под ключом `pocket-works:kvarta:state:v1`. Кэш приложения — `kvarta-v1.0.0`; очистка service worker ограничена префиксом `kvarta-`.

## Проверка

`app.js` при инициализации валидирует все 20 уровней: применяет сохранённую обратную последовательность к сгенерированной раскладке и проверяет возврат к состоянию `0…15`.
