# ТАКТ

Тактильный тактический roguelite о спасательных дронах внутри рушащейся орбитальной станции.

## Главная идея

Игрок не двигает отряд в реальном времени. Он собирает четырёхтактную программу: выбирает дрон, команду и направление, а затем запускает исполнение. Все дроны, охранные турели, охотники и аварийные поля действуют на каждом такте одновременно. Вражеские намерения видны заранее, поэтому каждый раунд — маленькая задача на причинность, а не угадайка.

## Игровой цикл

1. На ветвящейся карте выбрать сектор: бой, лом, мастерская или аномалия.
2. В миссии собрать команды `MOVE`, `PULSE`, `GUARD`, `REPAIR`, `HACK` на четыре такта.
3. Забрать сигнальные ядра, пережить угрозы и вывести хотя бы один дрон через шлюз.
4. Выбрать модуль, который меняет правила следующего раунда.
5. Дойти до девятого узла, накопить лом и открыть новые корпуса для следующих забегов.

При первом открытии игра запускает готовую короткую миссию и показывает обучение поверх настоящего поля; его можно пропустить, не теряя сектор. Состояние забега, разблокировки и настройки сохраняются локально. Игра работает офлайн после первого открытия.

## Управление

- Тап по дрону — выбрать исполнителя.
- Тап по слоту — выбрать такт.
- `MOVE`, затем соседняя клетка на поле — записать перемещение.
- Остальные команды записываются одним тапом.
- `ИСПОЛНИТЬ` запускает четыре такта.
- Ссылка `Pocket Works` возвращает в оболочку из любого экрана.

## Визуальная доктрина

Холодный аварийный терминал, в котором ярко-лаймовая лента команд режет тёмную станционную сетку. Скругления минимальны, все цифры и линии что-то обозначают, а цвет угрозы читается без звука.
