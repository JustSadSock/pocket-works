# ЭХОЛОТ

Пошаговая игра о подводной разведке. Три рейса, 3 образца на каждом. Стрелки/WASD или экранные кнопки — движение; пробел/PING — сонар. Кислород расходуется на движение и сканирование. После сбора вернитесь к базе. Стрелка на карте указывает на ближайший оставшийся образец или базу.

Тесты: `node --test apps/echolot/core.test.mjs`.
