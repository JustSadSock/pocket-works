# КАЛИБР: запуск пока не работает

По разрешению пользователя оставляем проект в каталоге как экспериментальный и передаём восстановление следующему агенту.

- Пакеты `game-pack-0.txt`…`game-pack-3.txt` содержат повреждённый gzip: `zlib.gunzipSync` сообщает `unexpected end of file`; распаковка с Z_SYNC_FLUSH даёт испорченный JavaScript, а не пригодный исходник.
- `game-part-1.js`, HTML и метаданные относятся к v2, а `game-part-2.js`…`game-part-6.js` — к несовместимой ранней версии. Простая загрузка шести файлов вызывает `MAGAZINE_SIZE is not defined` и обращение к отсутствующим UI-полям. Этот неработающий способ исправления отменён.
- Нужно восстановить один согласованный runtime v2 либо осознанно восстановить целиком согласованную раннюю версию. Не объявлять рабочими три операции, комплекты, гранаты и дрон до реального прохождения.
- Коммит, добавивший повреждённый v2: `8bf2e4dc94c50bbed385fb8aadaba403b2e99694` (Expand КАЛИБР into full mobile FPS). Историю удобнее исследовать GitHub commits API с `path=apps/kalibr`: локальная история изначально неглубокая.
