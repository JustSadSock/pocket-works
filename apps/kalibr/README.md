# КАЛИБР 1.0

Мобильный одиночный 3D-шутер для горизонтального телефона. Игра использует собственный быстрый raycasting-рендерер без внешних библиотек и сетевых ассетов.

## Основной сценарий

1. Выбрать одну из трёх карт.
2. Зачистить арену от вражеских стрелков.
3. Подобрать боеприпасы и аптечки при необходимости.
4. После зачистки добраться до активированного эвакуационного маяка.
5. Получить оценку по времени, точности и оставшемуся здоровью.

## Управление

- левая половина экрана: большой плавающий стик движения;
- правая половина: свободный обзор свайпом;
- большая кнопка под правым пальцем: огонь;
- короткое автодоведение помогает удерживать видимую цель, но не стреляет за игрока;
- перезарядка доступна отдельной кнопкой и запускается автоматически при пустом магазине;
- поддерживаются WASD, мышь и R для проверки на компьютере.

## Карты

- **Терраса** — открытый бетонный комплекс с внутренним двором и длинными прострелами.
- **Сухой док** — тесные служебные коридоры, контейнерные секции и обходные пути.
- **Архив** — керамические галереи с центральным хранилищем и симметричными флангами.

Настройки, рекорды и последняя выбранная карта сохраняются локально в `pocket-works:kalibr`.
