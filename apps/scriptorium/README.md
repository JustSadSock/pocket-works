# Скрипторий

**Скрипторий** — автономный редактор средневековых миниатюр для Pocket Works. Он собирает иллюстрацию не из готовой картинки, а из процедурно отрисованных фигур, предметов, существ, архитектуры и орнамента. За счёт этого сцены остаются редактируемыми и могут сильно отличаться друг от друга.

## Основной сценарий

1. Выбрать формат листа, фон и рамку.
2. Добавить до трёх фигур и любые декорации из каталога.
3. Выбирать элементы прямо на миниатюре и перетаскивать пальцем; для выбранного элемента доступны размер, отражение и удаление.
4. Настроить головные уборы, предметы в руках, цвета, орнамент, надпись, палитру и толщину контура.
5. Использовать готовый сюжет или «Бросить кости» для новой связной композиции.
6. Сохранить результат в PNG. Служебное выделение в экспорт не попадает.

## Технически

- Quick canvas app без внешних зависимостей.
- Состояние автоматически хранится в `localStorage` под `pocket-works:scriptorium:state`.
- История отмены/повтора хранится в памяти текущей сессии.
- PWA и service worker кешируют только файлы приложения и общий mobile runtime.
- Все рисунки строятся Canvas 2D на устройстве и полностью работают офлайн.
