# ПАЛОМНИК

Пиксельная одиночная экспедиция по трём мёртвым небосводам: 21 переход на шагающей готической крепости.

## Правила

Касайтесь одного из трёх подвешенных каменных уступов справа. Недоступна опора, отстоящая от текущего положения более чем на один вертикальный ряд. Каждое движение стоит 1 жара. Янтарная искра даёт +3 жара, нейтральный камень безопасен, трещины повреждают корпус на 1, лиловая пустота отнимает ещё 3 жара. На шагах 7 и 14 привал восстанавливает 2 жара и 1 корпус. Дойдите до шага 21, прежде чем жар или корпус упадут до нуля.

После каждого шага прогресс автоматически записывается локально и предлагается для продолжения после возвращения. Доступны пауза, подтверждаемый сброс, отключаемый процедурный звук, выход в Pocket Works. На клавиатуре клавиши 1/2/3 выбирают верхний/средний/нижний уступ, Escape — пауза.

## Art direction

Готическая подвижная цитадель с коленными суставами, каменными фасетами и горящими окнами; процедурные суровые руины, ущелья, дым и цветной вихревой шторм. Небо предварительно рендерится в низком разрешении и дезерится упорядоченной матрицей Bayer 4×4. Источники изображений пользователя использованы как стилистический референс, не включены в игру.

## Integration

Quick app; изолированное содержимое внутри apps/palomnik/. app.config.json регистрирует игру; свои PWA-манифест, иконка, service worker и ключи сохранений. Все основные файлы кэшируются для повторного офлайн-запуска. Никакого сетевого мультиплеера: PocketNet следует использовать для возможной будущей сетевой версии; PocketLAN неактивен.

## QA

1. Старт → касание одной из доступных опор → посадка, запись прогресса.
2. Недостижимая опора показывает ограничение и не тратит ресурс.
3. Янтарные, красные и фиолетовые уступы меняют жар/корпус по правилам.
4. Пауза, продолжение, сброс через отдельное подтверждение.
5. Перезагрузка сохраняет позицию; на 7-м и 14-м шагах меняется биом.
6. Истощение любого ресурса ведёт к поражению; 21 шаг — к победе.
7. После первого онлайн-посещения перезапуск игры не зависит от сети.

Проверки в корне Pocket Works: npm run registry:check; node scripts/validate-visual-direction.mjs --app=palomnik; npm run prepare:site; npm run validate:site. Для полной проверки необходим реальный браузер Playwright (Chromium и WebKit).
