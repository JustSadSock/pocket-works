# КОМНАТКА — миниатюрная мастерская

Первый вертикальный срез уютного редактора диорамы, отдельное Enhanced-приложение Pocket Works.

## Что работает

- Фиксированная ортографическая камера Babylon.js, пол и две задние стены, мягкая авторская геометрия мебели.
- Каталог: диван, кресло, стол, комод, кровать, табурет, торшер, настольная лампа, фикус, ковёр, книги, чашка, картина, окно.
- Установка и перемещение предметов по сетке 0.25, поворот, окраска, копирование, удаление, проверка пересечений; мелкие предметы ставятся на столы и комоды.
- Два вида обоев плюс покраска, шесть цветов стен, четыре пола.
- День/вечер; управляемый звук; undo/redo; PNG-снимок; автоматическое локальное сохранение, восстановление сцены.
- Адаптивный полноэкранный редактор для мыши и телефона, PWA/offline.

Пока нет комнат с другими игроками, заказов жильцов или игры по памяти: это следующий этап, на одной и той же модели комнаты.

## Команды

`npm install` (из корня), `npm test --workspace @pocket-works/komnatka`, `npm run build --workspace @pocket-works/komnatka`.

## Визуальная модель

Все предметы процедурно создаются вручную из закруглённых скруглённых объёмов, сфер, цилиндров и авторских 2D Canvas-текстур. Никаких сторонних моделей, картинок, генераторов или CDN. Игровой результат хранится в `pocket-works:komnatka:scene-v1`, изменение каждой операции добавляется в историю действий.

## Обновление 0.1.1

Правильный winding скруглённых 3D-граней предотвращает видимость внутренних поверхностей. Текстуры ткани/дерева целиком непрозрачны. Мебель отбрасывает направленные тени на пол и стены, а не полупрозрачные круги. Новые кресло, диван, кровать, комод, листья фикуса, окно, чашка и опоры столика. Во время примерки доступна палитра и поворот до постановки, для существующей комнаты сохраняются прежний формат данных, undo/redo и декор на опорной мебели.

## Обновление 0.1.2

Сцена сохраняет Babylon-меши неизменённых объектов при перемещении/вращении соседей и не пересоздаёт точечные источники света при обновлении. День приглушён; ночь по-настоящему тёмная, каждый торшер и настольная лампа создают локальный тёплый свет. У ковра низкий ворс и авторский тканый рисунок; ножки мебели не тонут в высокой геометрии. Почва горшка оформлена ниже рельефного бортика, на шторах нет ложных точек. Каталог использует автоматически сгенерированные в браузере снимки собственных 3D-моделей, с запасным SVG при отсутствии WebGL. Настольные лампы корректно помещаются в углах, предметы можно унести вправо в зону удаления с Undo. Звуки создаются в исходном коде с отдельными акустическими профилями для разных действий; см. AUDIO.md.

## Обновление 0.1.3 — тактильная диорама

- `source/motion.js`: прерываемые анимации на существующих TransformNode и дочерних мешах; ни материалы, ни геометрия при движении не пересоздаются, сохранённые координаты не меняются. Масса, упругость и время затухания задаются отдельно для 14 типов предметов.
- При захвате предмет чуть поднимается; при отпускании оседает с небольшой деформацией; поворот проходит примерно за 215 мс; неправильное размещение отвечает мягким сопротивлением; удаление и Undo имеют визуальный отклик.
- Анимации мягких подушек, листьев, книг, чашки и первого раскладывания ковра; без бесконечных циклов и случайного движения соседних предметов.
- `room.tickLighting`: плавный переход освещения, оттенка оконного пейзажа и реальных источников света; состояние по-прежнему сохраняется как boolean.
- Сетка подтверждает шаги коротким ненавязчивым кольцом у указателя; полка и корзина имеют обратную связь. `prefers-reduced-motion` отключает декоративное движение.
- `motion.test.ts` проверяет отсутствие изменений игровой модели, детерминированность, прерывание, удаление и reduced motion.

## 0.2.0 — совместная онлайн-игра (PocketNet)

В правой части шапки кнопка «Друзья». Можно создать общую комнату, пригласить по 8-символьному коду или ссылке, подключиться с 2–5 устройств. Два законченных игровых цикла:

* **Новые жильцы.** Каждый раунд начинается с тематических пожеланий нового жильца (4 цели). Игроки совместно размещают мебель и декор. Цели и выполнение считаются на PocketNet-сервере. Организатор завершает раунд; при таймауте сервер подводит итог.
* **Собери по памяти.** Сервер показывает эталонный интерьер на 18 секунд. Затем эталон скрывается, друзья собирают комнату по памяти 155 секунд. После завершения сервер вычисляет совпадения по расположению, цвету, повороту и отсутствующим предметам, выдаёт процент и эталон. Ответ никогда не отправляется клиенту во время реконструкции.

Перестановка, установка, покраска, поворот, удаление и смена отделки синхронизируются. Цветные бейджи над выбранными предметами показывают действия других игроков. На сервере работают проверки координат, коллизий, опор и типа объектов, блокировка чужого активного предмета. Обрыв связи запускает переподключение.

Личный редактор хранит состояние в прежнем localStorage; при входе в онлайн он не перезаписывается. Для серверного запуска нужны `apps/komnatka/server/module.ts`, неизменяемая версия `pocketnet/module-versions/komnatka/v1.ts` и запись в `pocketnet/modules.lock.json` (отдельный platform PR).

## 0.2.1 — кукольный домик как отправная точка

На запуске всегда открывается полноценное главное меню с тремя реальными входами. «Свободная сборка» ведёт к сохранённому редактору. «Новые жильцы» и «Собери по памяти» выбирают соответствующий режим и сразу открывают создание/вход в онлайн-комнату PocketNet; закрытие формы из меню возвращает на стартовый экран. Кнопка «Меню» в редакторе возвращает к выбору, не теряя личную комнату; во время живой онлайн-сессии она открывает список участников и выход из комнаты вместо разрыва связи.

Панель справа на стартовом экране показывает захваченное изображение **реальной** 3D-комнаты с текущим сохранением. При возврате снимок обновляется. Если WebGL недоступен, вступает в силу существующий экран ошибки и кнопка повторной загрузки.

Ковёр переработан как овальная низкая ткань с процедурной пряжей, тремя отдельными объёмными плетёными кантами, малой вышивкой и рассыпающейся по форме короткой бахромой. Лампы освещают только компактную область вокруг себя, а мягкий тёплый «softbox» и боковая подсветка показывают объём маленьких игрушечных моделей. Внешние деревянные срезы стен и подставка подчёркивают, что это именно открытый кукольный домик, а не жилое помещение натуральной величины.

## 0.2.2 — свет настоящий, домик игрушечный

Прежний переключатель запускал `refresh()`, хотя менял исключительно атмосферу. Теперь `switchDollhouseLighting()` изменяет только `state.evening`, световую цель и UI-индикатор. 3D-объекты, указатель и выделение не пересоздаются и не сбрасываются; прежние комнаты и PocketNet-совместимость сохраняются. Изменение сохраняется в прежнем формате.

У студии остаётся только два световых источника, освобождая четырёхслотовый бюджет под действующие лампы; у всех материалов поддерживаются 6 совместных источников. Светильники имеют эмиссивные абажуры, собственные реальные тёплые `PointLight`, процедурные полупрозрачные пятна на стенах и полу. Пятна `isPickable=false`, не крадут жесты и не изменяют игровые столкновения. День остаётся кремовым, ночь — лавандовой, а не чёрной. `lighting-presets.js` содержит тестируемые диапазоны затухания и верхние границы числа ламп.

## КОМНАТКА 1.0 — первая полная коллекция

- 30 авторских моделей, все можно размещать, красить, поворачивать и сохранять; настенные декорации занимают стены, миниатюрные вещицы требуют настоящих свободных подставок.
- Девять обоев, шесть полов и независимое оформление задней/левой стен. Три настоящих плана пола с физическими границами: классическая квадратная, узкая прямоугольная и Г-образный уголок. При переключении формы редактор не удаляет мебель: он просит сначала освободить мешающие ячейки.
- До пяти личных комнат с названиями и обложками, сохранением в localStorage и автоматической миграцией исходного одиночного сохранения; новая комната создаётся пустой для выбранного плана. Удаление требует подтверждения.
- Фото комнаты PNG со сменой трёх ракурсов, без элементов управления в кадре.
- PocketNet v2: 12 пожеланий новых жильцов, в том числе условия соседства, и 15 разных заданий на воспроизведение. Для новых онлайн-сессий сервер v2, ранее созданные v1 не меняются.
- Файлы: `source/layout.js`, `source/rooms.js`, `source/studio-ui.js`, `source/v1.test.ts`; серверный модуль `server/module.ts` и pinned `pocketnet/module-versions/komnatka/v2.ts` доставляются через отдельный platform PR.

## Перетаскивание и проверка в браузере (2026-10-15)

Каталог теперь поддерживает единый жест: нажать и отпустить для выбора места или
перетащить предмет непосредственно на сцену. Перетаскивание ранее установленной
мебели использует ту же сетку 0.25. Сетка/контур появляются при захвате,
зелёный контур разрешает размещение, красный предупреждает о пересечении или
неподходящей опоре. При отпускании на запрещённой клетке изменение не применяется.
При горизонтальном жесте внутри каталога список прокручивается, а не устанавливает
мебель. Для клавиатуры остаётся выбор предмета кнопкой и последующее размещение.

3D-миниатюры центрируются по геометрии каждого предмета, снимки пустых кадров
отбрасываются, а SVG-иконки остаются резервным вариантом. Декор на столах и
комодах разделяет вертикальную анимацию мебели без изменения координат сохранения.

Playwright-сценарии: `tests/e2e/komnatka-placement.spec.ts`. Они проверяют
перетаскивание из каталога, сетку и запрещённое место, синхронный подъём
стола с чашкой/книгами, наличие и масштаб иконок на мобильном экране,
сохраняют снимки ключевых состояний.

После сборки preview-сайта команда:
```sh
npm run build:quality-site
npx playwright test tests/e2e/komnatka-placement.spec.ts --project=chromium-mobile-portrait
```

Проверки также подключены к `AI Mobile Gameplay QA` в GitHub Actions при
изменениях `apps/komnatka/**`.


## 1.1 — резкая мобильная графика и честное сравнение

- На стандартных Retina-экранах по умолчанию сохраняется физическое разрешение
  сцены; на больших поверхностях применяется только детерминированный предел
  пикселей. Динамического понижения качества во время перетаскивания нет.
- Ковёр получает 512×512 прорисовку волокон вместо 256×256.
- Главный экран больше не использует декоративный SVG-домик: показывается
  настоящий снимок 3D-сцены, а при сбое захвата — ранее сохранённый
  фотографический снимок этой же комнаты.
- Итог раунда «Собери по памяти» включает два кадра в общем ракурсе, статистику
  совпавших/частичных/пропущенных/лишних объектов и причины по каждому предмету.
  Серверный балл остаётся авторитетным.
- Для «Новых жильцов» видны название/смысл задания, прогресс каждой цели
  и итоговый протокол; более глубокая пространственная игровая логика
  запланирована в версии 1.2.
- QA: source/experience.test.ts и браузерные кадры домашнего экрана и ковра.
