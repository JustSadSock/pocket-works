# МЕХАНИКА

Офлайн мастерская кинематических передач для Pocket Works.

Шесть механических задач на зацепление, передаточное отношение и направление вращения. Чтобы собрать машину, выбери малую, среднюю или большую шестерню и коснись пустого посадочного гнезда. Можно перетаскивать установленную деталь в другое место или снять её касанием. После сборки заведи пружину и запусти испытание: выходной вал должен вращаться с требуемой скоростью и направлением. Победа открывает следующую схему.

Свободная мастерская доступна через меню «СХЕМЫ», с неограниченным запасом деталей; разомкнутые передачи можно изучать без требования конкретной цели.

Сохранение: локальный progress, размещение для каждого задания, свободная композиция и состояние звука. PWA ограничена префиксом /apps/mechanica/ и не вмешивается в чужие приложения.

Модель — кинематическая, без симуляции упругих деформаций: два колеса сцепляются, если расстояние между центрами совпадает с суммой делительных радиусов; соседнее колесо получает RPM × (-r1/r2), а замкнутые противоречивые связи заклинивают.

Smoke-тест: уровень 1 -> три средних колеса -> запуск -> победа -> переход в уровень 2 -> перезагрузка страницы -> сохранённый прогресс. Отдельно проверить отмену, перетаскивание, очистку с подтверждением, свободную мастерскую, поворот/узкий экран, паузу вкладки и офлайн-запуск.
