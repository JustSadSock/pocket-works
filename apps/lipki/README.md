# ЛИПКИ

Кооперативный 2D-платформер внутри Pocket Works. Маленькие плюшевые герои перепрыгивают обрывы, соединяются липучками, толкают катушки и активируют тканевые кнопки.

## Игровой цикл

- В меню выберите тренировку или PocketNet.
- В тренировке управляйте одним героем; уровень считается пройденным, когда он коснётся тканевой двери. Доступно 12 этапов, последнее открытое испытание сохраняется в namespaced localStorage.
- В PocketNet ведущий создаёт комнату и делится 8-символьным кодом/ссылкой. Комната рассчитана на 2–4 игроков. Сервер принимает ввод от каждого, проверяет действия, запускает физическую симуляцию и раскрывает дверь только когда **все** дойдут до выхода.
- Полные уровни имеют кнопку рестарта ведущего. После прохождения ведущий переводит группу дальше.

## Управление

Телефон: слева две кнопки ходьбы, справа прыжок и липкость. Последняя переключает схватку; прыжок освобождает захват. Клавиатура: A/D или стрелки, W/↑/пробел, E/Shift; Esc для паузы.

## Архитектура

- `game-core.js`: одна модель мира в клиенте, шариковая физика, коллизии, сцепки, пружины, кнопки, двери, 12 уровней.
- `render.js`: авторский Canvas 2D с фетровыми текстурами, мягкой камерой, тканевыми швами и персонажами.
- `app.js`: управление, прогресс, интерфейс, Pocket ID, сетевая игра.
- `server/module.ts`: серверная копия проверенной физики, команды ввода, право ведущего, лимиты игроков.
- `pocketnet/module-versions/lipki/v1.ts`: опубликованная неизменяемая копия серверного модуля. Lock обновляется одновременно.
- `sw.js`: scoped offline-first PWA, с предварительным сохранением общих библиотек только в собственном кэше.

**PocketNet на Cloudflare Durable Objects — единственный интернет-транспорт игры. PocketLAN неактивен, приложение его не импортирует и не использует.** Клиенты передают только входные команды. Симуляция на стороне PocketNet; серверное время продвигается по сообщениям игроков без фоновых таймеров внутри Durable Object. Короткие снапшоты сглаживаются клиентом.

## Проверки

```sh
node --test apps/lipki/tests/engine.test.mjs
npm run registry:check
node scripts/build-pocketnet-modules.mjs
npm run health
npm run build:quality-site
npm run test:e2e
```

Иконка `icons/icon.svg`, описание визуальной системы `visual-direction.json` и арт-библия `art-bible.json` принадлежат приложению. Сетка меню не скроллится на телефоне; ссылка возврата в библиотеку расположена в доступной верхней safe-area.
