# Munchkin Level Forge

Offline-first общий счётчик уровней Munchkin для Pocket Works.

## Основной сценарий

1. На первом запуске выбрать 2–8 игроков, имена, жетоны и режим 10/20 уровней.
2. Выбрать игрока касанием его жетона или карточки.
3. Менять уровень одним нажатием `+` / `−` либо нажать нужный уровень прямо на круге.
4. При ошибке использовать Undo. На десктопе работают `1–8`, стрелки и `Ctrl/⌘ Z`.
5. На целевом уровне запускается короткая победная сцена.

## Детали

- Один общий механический круг вместо отдельных счётчиков.
- Жетоны различаются и цветом, и символом; совпавшие уровни автоматически разводятся веером.
- Локальное сохранение партии и настроек без аккаунта или сети.
- Синтезированные Web Audio эффекты, отключаемые одной кнопкой.
- Столовый/полноэкранный режим, адаптивный layout для телефона, планшета и desktop.
- Уважает `prefers-reduced-motion` и сохраняет текстовые подписи для ключевых действий.
- Собственный service worker кэширует только файлы приложения и обязательный mobile runtime.

## Файлы

Всё приложение изолировано в `apps/munchkin-level-forge/` и не требует новых зависимостей.
