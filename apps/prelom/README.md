# ПРЕЛОМ

«ПРЕЛОМ» — изолированное Enhanced PWA-приложение Pocket Works для интерактивных экспериментов с геометрической оптикой на вертикальном телефоне.

## Основной сценарий

1. Приложение открывает сцену с белым лучом и призмой.
2. Любой объект можно двигать напрямую на поле.
3. Каталог добавляет источники, зеркала, линзы, среды, экраны и измерители.
4. Инспектор меняет численные параметры выбранного объекта.
5. Сцены сохраняются локально и экспортируются в JSON.
6. Библиотека содержит эксперименты и задачи с автоматической проверкой.

## Управление

- Один палец: выбор и перемещение объекта.
- Два пальца на пустом поле: масштабирование и перемещение камеры.
- Два пальца рядом с выбранным объектом: вращение объекта.
- Долгое нажатие: контекстное меню.
- Двойное касание пустого поля: вписать сцену в экран.

## Разработка

```bash
npm run typecheck --workspace=@pocket-works/prelom
npm run test --workspace=@pocket-works/prelom
npm run build --workspace=@pocket-works/prelom
```

## Хранение

Namespace: `pocket-works:prelom`.

Сцены, настройки, автосохранение и последняя сессия хранятся только локально. Импортируемые данные валидируются и мигрируются до текущей схемы.

## Структура исходников

Крупный интерактивный runtime хранится в детерминированном gzip-архиве `source/runtime-archive/*.gzpart`. Скрипт `assemble-source.mjs` объединяет архивные части и восстанавливает `source/runtime-generated.ts` перед build, test и typecheck. Архив существует только для атомарной доставки крупного автономного runtime через репозиторный коннектор; он не содержит сторонних бинарных зависимостей и не требует сети.
