# ТЯГА / Gravity Duel

Самостоятельная аркада PocketWorks по мотивам [JustSadSock/Gravity-duel](https://github.com/JustSadSock/Gravity-duel).

## Как играть
Один шар, два соперника. Верхний игрок направляет шар вверх, нижний — вниз. Побеждает первый, кто забьёт пять голов. Любое касание вашей зоны — **перехват гравитации**, а не необходимость удерживать палец. Текущий игрок сохраняет контроль до ответного перехвата соперника.

- **Перегрузка:** во время владения ускорение постепенно растёт от 340 до 930 единиц/с² за 1,4 секунды. Вместе с ним растёт уязвимость: при следующем перехвате соперник получает контримпульс от 115 до 570 единиц/с. Поэтому слишком долгая тяга опасна.
- **Кинетические комбинации:** в «Рикошете» и «Маятнике» две узкие золотистые дорожки усиливают скорость шара и придают боковую составляющую. Шар должен входить в дорожку с достаточной вертикальной скоростью. После рикошета можно снова попасть в ускоритель — альтернативные контакты в течение 1,45 с создают связку, дающую небольшой дополнительный разгон.
- **Арены:** «Пустота» — честная дуэль без препятствий; «Рикошет» — три штыря и две скоростные дорожки; «Маятник» — движущаяся преграда, боковые отражатели и ускорители.
- **Против ИИ:** касание где угодно, W / ↑ / пробел — верхний игрок. ИИ оценивает направление движения, положение шара и перегрузку и реагирует с задержкой.
- **Вдвоём:** верхняя/нижняя половины сенсорного экрана либо W / ↑ и S / ↓ на одной клавиатуре. Поддерживается одновременное касание.
- **Esc:** пауза. Звук и вибрация — реакция на физические события, звук можно выключить.
- Предпочтения и победы против ИИ сохраняются в localStorage; offline-first PWA.

## Проверка
```sh
node --test apps/tyaga-duel/tests/physics.test.mjs
node apps/tyaga-duel/qa/real-flow.mjs
```

Запуск из PocketWorks: `/apps/tyaga-duel/`. Физика рассчитана на фиксированный шаг 120 Гц. Сети для локальной дуэли не требуется. Все исходники, PWA-кэш и данные изолированы внутри приложения.
