# ТЯГА / Gravity Duel

Самостоятельная аркада PocketWorks по мотивам [JustSadSock/Gravity-duel](https://github.com/JustSadSock/Gravity-duel).

## Правила
Два игрока борются за направление ускорения единственного шара. Верхний игрок тянет шар наверх, нижний — вниз; гол в своей части поля приносит очко. Победа — пять голов. Перехват немедленно меняет ускорение и даёт небольшой импульс, поэтому момент касания важен.

- **Против ИИ:** касание в любом месте поля, W / ↑ / пробел — верхний игрок.
- **Вдвоём:** касание верхней/нижней половины, W / ↑ и S / ↓ соответственно. На смартфоне поддерживается multi-touch.
- **Эскейп:** пауза. Звук включается после первого пользовательского жеста и может быть отключён.
- **Арены:** Пустота, Рикошет, Маятник.
- Настройки арены, режима, звука и локальных побед сохраняются в localStorage.
- Рендер Canvas с физикой фиксированных шагов 120 Гц и процедурными WebAudio-сигналами.

## Проверка
node --test apps/tyaga-duel/tests/physics.test.mjs

Запуск в PocketWorks: /apps/tyaga-duel/. Ресурсы и настройки изолированы от других приложений; WebSocket/PocketNet не требуется для локальных матчей.
