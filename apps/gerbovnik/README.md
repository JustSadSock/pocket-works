# ГЕРБОВНИК — Право на знамя

Самостоятельная, ориентированная на телефон офлайн-игра для Pocket Works. Игрок — королевский герольд 1287 года, чьи решения меняют владения и геральдику Эллара.

## Игровой цикл
1. Изучить два документа по наследственному спору.
2. Выбрать одного из трёх претендентов и утвердить вердикт печатью.
3. Увидеть изменение отношений родов, законности и мира; проверить карту и хронику.
4. Между делами самостоятельно перерисовывать гербы десяти родов, соблюдая базовое правило тинктур.
5. Пройти 12 дел до одной из концовок или проиграть из-за распада королевства.

Данные кампании и гербов сохраняются в `localStorage` в собственном namespace. Для новой партии есть действие с подтверждением. Игра работает без серверов, библиотек и внешних изображений.

## Проверка
```sh
node --check apps/gerbovnik/app.js
node --check apps/gerbovnik/sw.js
npm run registry:check
npm run deploy:site
npm run test:e2e
```

## Управление
Большие кнопки рассчитаны на вертикальный мобильный экран. Выбор дел, свидетельств, гербов и владений доступен касанием. Пять разделов остаются в нижней навигации. Внешняя кнопка WORKS возвращает в оболочку.
