# ВЕНЕЦ — исследовательская основа

Статус: **проектное досье, не игровая демоверсия**. Пользователь попросил на этом этапе только зафиксировать исследование и решения, без реализации мира, механик и игрового визуала.

## Короткая навигация
- **[ROADMAP.md](./ROADMAP.md): последовательность обновлений v0.2–v1.0, задачи, зависимости и критерии выпуска.**
- [DESIGN.md](./DESIGN.md): продуктовая цель, механическая основа и технические границы.
- [RESEARCH.md](./RESEARCH.md): проверенные научные источники, выводы и ограничения доказательств.
- [TEST_PLAN.md](./TEST_PLAN.md): симуляционные инварианты, A/B, исследовательские метрики.
- [VISUAL_RESEARCH.md](./VISUAL_RESEARCH.md): сравнение направлений, анимации, материалы, производственные ограничения PocketWorks.

## Следующее обновление
**v0.2.0 «Мир»** — headless 12-провинциальная симуляция с детерминированным временем, журналом последствий и автоматическими тестами. Полная последовательность и условия переходов — в [ROADMAP.md](./ROADMAP.md). Игровую графику и декоративный UI на этом этапе не создаём.

## Первое правило следующего этапа
Сначала автономная модель персонажей и воспроизводимая симуляция, затем управление игрока, потом графика. Не добавлять числа и системы ради масштабности. Взаимодействие **характер → семья → феодальная иерархия → владения → история** важнее числа провинций.

Досье в приложении доступно через лаконичный встроенный просмотрщик: опубликованная сжатая сводка в dossier.json; полные Markdown-документы остаются исходными проектными материалами и не включаются в опубликованный пакет. Приложение помечено как экспериментальное; ни один экран не выдаётся за готовую игру.
