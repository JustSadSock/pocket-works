## Проверенные результаты

- GitHub Actions [Universal QA #39058631996](https://github.com/JustSadSock/pocket-works/actions/runs/39058631996): **40 из 40 модульных сценариев прошли**, ошибок нет. Сюда входят все предыдущие симуляционные инварианты и восемь новых кампанийных сценариев.
- **100 различных миров по 100 лет** прошли годовую симуляцию с династиями, финансами, политическими решениями, фракциями и сохранением. Проверяются прежние инварианты.
- Кампанийные тесты подтверждают: три начальных графа и двусторонняя юридическая претензия; минимум два доступных варианта решения первого политического спора (прошение или коалиция); одно действие игрока в год; контролируемый персонаж исключён из автономных решений в тот же год.
- Имеются проверенные сценарии отказа по претензии, рождения/смерти, переключения персонажа после смерти основателя на живущего представителя его династии, полной детерминированности saved/resumed истории, окончания первой 90-летней главы/продления на 50 лет, проверки некорректных действий и сохранений.
- Дополнительный прогон **16 кампаний по 70 лет** с чередующимися решениями не нарушил законность титулов, родство, финансы и непрерывность династической хроники.
- GitHub Actions [Universal QA #39058465913](https://github.com/JustSadSock/pocket-works/actions/runs/39058465913): реальные экраны первого запуска, Совета, условного атласа и календарного хода проверены в **Chromium/WebKit на 390×844 и 1366×768**; все четыре браузерные комбинации прошли без HTTP/JS ошибок, видимого горизонтального переполнения и пустых экранов.
- Скриншоты браузера из соответствующего CI-артефакта `qa-venets-campaign-mobile-first-year` просмотрены визуально: мобильное решение и кнопка следующего года помещаются на экране; на ПК одновременно читаются Совет, карта титулов и Летопись.
- **Подтверждение решения в реальном браузере проверено:** после открытия кампании нажимается одна из актуальных допустимых политических команд, открывается системный диалог подтверждения, действие исполняется, затем нажатие «Следующий год» приводит к 1067 году. На скриншотах Chromium/WebKit видны последствия отказа правителя и обновление набора допустимых действий.
- Полный прогон [#39058952584](https://github.com/JustSadSock/pocket-works/actions/runs/39058952584) завершился без ошибок по **всем smoke suite**: Node регрессии, 50/100-летний стресс и два браузерных теста (игра/досье). Артефакты прикреплены в GitHub Actions.

## Что сознательно не заявляется

- **20–30 минут осмысленного человеческого игрового теста НЕ проведены.** Времени одного только автоматического тестирования недостаточно, чтобы доказать интересность. Это блокер для дорогого масштаба v0.6, не для ознакомительной версии v0.5.
- Изображение «Земли» — **условная информативная схема провинций**, не итоговый художественный атлас. Финальный визуальный срез с реками/рельефом/генеалогией — v0.6.
- Отсутствуют войны, реальные феодальные военные союзы, самостоятельная смена сюзерена и придворные интриги. Военной победы/анимаций битвы в v0.5 нет.
- Династическая демография и политические коэффициенты остаются модельными гипотезами; стресс-тесты проверяют корректность, а не научную историческую достоверность.
