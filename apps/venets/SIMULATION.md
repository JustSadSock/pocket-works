# ВЕНЕЦ v0.2.0 — исторический каркас мира «Междуречье»

**Состояние:** документ описывает каркас v0.2. Начиная с v0.3 рождение, смерть, браки и наследование уже добавлены в [DYNASTY.md](./DYNASTY.md). Политический ИИ добавлен в v0.4 (см. [WILL.md](./WILL.md)); военная система и законченная художественная карта пока отсутствуют, но играбельная кампания добавлена в v0.5 (см. [FIRST_STORY.md](./FIRST_STORY.md)).

## Модули
- sim/random.js — хранимый xorshift32 PRNG, seed uint32; никаких Math.random и wall-clock.
- sim/world.js — 12 провинций, годовой шаг, наследуемая модель титулов, сериализация, API.
- sim/transactions.js — бухгалтерские переводы и причинный журнал событий.
- sim/validate.js — инварианты графа, владельцев, владений, ресурсов, журнала и времени.
- qa/stress.mjs — CLI с JSON-отчётом, используется и в CI.
- tests/world.test.mjs — регрессионные тесты, включая обязательные 100 seed × 50 лет.
- qa.plan.json — smoke node-test и стресс-прогон, а также deep 100×100 лет.

## Устройство мира
Начальный год **1066**, 12 соседствующих провинций в абстрактной топологии 4×3. Одна провинция — одно графство; выше 4 герцогства и 1 королевство, всего **17 титулов, 17 людей, 5 династий**. Люди существуют с основания мира; **смертность и наследование не симулируются до v0.3**. Координаты показывают смежность, а не готовую карту.

Каждый год возникают погода, урожай и потребление, внешняя торговля и расходы, ограниченные зерновые/денежные налоги графу, часть герцогу и часть короне. Нехватка еды отражается отдельным событием и статистикой, но **не приводит к смерти** в этой версии. Экономика является воспроизводимым учётным каркасом, **не исторической калибровкой**; монеты и зерно не объединяются в одну сумму.

Каждая запись содержит kind, year, cause, effect и возрастающий id. Изменение держателя титула через changeTitleHolder создаёт причинное событие; политическая законность пожалования появится позднее.

## Пример API

    import { createWorld, advanceYears, stepYear, assertWorld,
      changeTitleHolder, serializeWorld, loadWorld, summary } from './sim/world.js';

    const world = createWorld(413);
    stepYear(world);
    advanceYears(world, 49);
    console.log(summary(world)); // 1116 год, 12 провинций и проверенные счета
    const save = serializeWorld(world);
    const resumed = loadWorld(save);
    changeTitleHolder(resumed, {
      titleId: 'co-01', newHolderId: 'pe-02', cause: 'lawful-transfer'
    });
    assertWorld(resumed);

stepYear и advanceYears мутируют **переданный мир** в определённом порядке. Save сверяется со схемой и ключевыми инвариантами; повреждение вызывает исключение. Описываемая здесь версия состояния schemaVersion = 2; в текущем v0.4 действует schemaVersion = 4 с миграциями старых миров. Версия состояния **не равна версии PWA**.

## Инварианты
1. Иерархия строго графство → герцогство → королевство, без циклов и отсутствующих владельцев.
2. Один графский титул на провинцию; смежность симметрична, мир связен.
3. Династии и персонажи существуют; ID глобально уникальны внутри типа.
4. Для каждого ресурса: сумма запасов = исходный запас + внешние поступления − потери/потребление.
5. Год, число ходов, порядковый номер событий и порядок обработки согласованы.
6. Ошибочные переводы отвергаются до изменения счетов, валидные имеют причинную запись.
7. Save/load восстанавливает RNG и журнал, последующая история детерминированна.

## Запуск
Из корня репозитория:

    node --test apps/venets/tests/world.test.mjs
    node apps/venets/qa/stress.mjs --seeds=100 --years=50
    node apps/venets/qa/stress.mjs --seeds=100 --years=100 --output=/tmp/venets-century.json
    npm run registry:check

100×50 лет — **стресс-тест технической целостности**; он не доказывает историческую реалистичность или интересность. Обсуждать субъективный интерес можно только после полноценного цикла v0.5. Миграции сохранений потребуются до смены схемы, а не после.

Игровая визуализация здесь отсутствует; первая полноценная визуальная проверка задуманного атласа — v0.6.

**Фактические результаты v0.2:** [QA_V02.md](./QA_V02.md) — 10/10 тестов, 100×50 лет и проверенные снимки досье.
