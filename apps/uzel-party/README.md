# УЗЕЛ

Самостоятельная Quick PWA для Pocket Works. Кооперативная аркада на 2–6 игроков: участники тянут одну связанную команду, проводят канат через светящиеся цели и собираются у выхода. Четыре готовых испытания, управление касанием и клавиатурой, рывок, пауза и повтор уровня.

## Запуск
Откройте `/apps/uzel-party/`. Кнопка «Начать тренировку» запускает одиночную практику с двумя ведомыми героями; «Создать LAN» и «Присоединиться» связывают устройства через общий `shared/capabilities/lan.js`. На телефоне двигайте джойстик и нажимайте «Рывок»; на клавиатуре — WASD/стрелки, Space для рывка, Tab для переключения героя в тренировке.

## PocketLAN
Ведущий держит симуляцию: положение игроков, столкновения, сбор огней, переход между испытаниями. Другие устройства передают ввод, получают частые снимки состояния и плавно интерполируют аватары. Локальная сеть/точка доступа; в браузере без native bridge используется офлайн обмен приглашением и ответом PWL1, затем WebRTC напрямую. Гостевые/изолированные Wi-Fi сети могут блокировать прямое соединение.

## Правила
Проведите натянутой верёвкой через все огни. После этого соберитесь у открытых ворот. Верёвка натягивается между последовательными участниками, ограничивает расстояние и огибает круглые препятствия визуально. Прогресс соло хранится отдельно в `pocket-works:uzel-party`; чужие приложения не затрагиваются.

## Проверка
1. Начать тренировку; подвигать героя, сделать рывок и сменить героя; задеть все огни натянутой верёвкой; привести группу к воротам; продолжить.
2. Пауза → продолжение / повтор / меню; включить и выключить звук; обновить страницу, проверить сохранение открытых испытаний.
3. Два устройства в одной сети: создать комнату, получить PWL1 приглашение, вернуть PWL1 ответ, присоединиться, начать вместе, двигаться одновременно; отключение клиента не должно ломать ведущего.
4. Проверить мобильную безопасную область, горизонтальные и вертикальные размеры, офлайн перезапуск PWA после первой загрузки.

Никакие данные сессии и ключи авторизации по LAN не пересылаются.
