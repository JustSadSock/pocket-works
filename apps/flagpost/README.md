# ФЛАГПОСТ — тестовая сетевая мини-стратегия

Игра в Pocket Works для двух настоящих игроков. Создатель получает восьмизначный код и ссылку; второй вводит код. Браузеры используют `shared/capabilities/net.js`; **все правила и результаты проверяются сервером** в `server/module.ts`, исполняемом в Cloudflare Durable Objects.

## Правила

- Поле 5 × 7, три бойца на каждой стороне. Север начинает; за ход можно выполнить два приказа.
- Нажать своего бойца, затем соседнюю свободную клетку — шаг, соседнего противника — атака и захват клетки.
- Подкрепление: один солдат появляется на своей пустой крепости, максимум пять солдат одновременно, затрачивает один приказ.
- Если отряд занимает центральную башню при завершении **своего** хода, игрок получает знамя.
- Побеждает первый, кто соберёт три знамени или займёт крепость противника. Сдача и выход соперника также завершают матч.
- Матч сохраняется в SQLite Durable Object. После сетевого разрыва повторный вход с тем же токеном восстанавливает комнату.

## Проверить PocketNet

1. Зайди в **ФЛАГПОСТ → Создать комнату**. Должен появиться восьмизначный код.
2. Второй человек на другом устройстве открывает ту же игру, вводит код (или переходит по ссылке приглашения).
3. Нажмите «Начать сражение», по очереди перемещайте бойцов; попробуйте намеренно сделать приказ не в свой ход.
4. Обновите вкладку у одного игрока, восстановите комнату, убедитесь, что состояние не потеряно.
5. Захватите центр / дойдите до крепости / сдайте матч и проверьте результат у обеих сторон.

Поддерживаются короткий код и прежний UUID; код создаётся только сервером. Платные сервисы, локальный Node.js и тестовые боты не используются. Если при загрузке видна ошибка доступности сервера, проверьте `/pocketnet/health` и актуальный Cloudflare Worker deployment.

## Developer

Сборка модулей: `npm run build:pocketnet`; тест Cloudflare Worker — `PocketNet Edge` workflow. Снимок `pocketnet/module-versions/flagpost/v1.ts` должен в точности соответствовать исходному `apps/flagpost/server/module.ts`. После будущего изменения исходника создайте v2 через `npm run snapshot:pocketnet`.
