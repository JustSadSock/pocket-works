# v0.2 — Anatomy, Surface & Artistic Identity
Research only; no production approval. Preserve v1 spec adapter. v2 independently declares style (low-poly / historical-miniature / anatomical-realism) and lod (low / medium / high). Native surfaces: transported cross-sections, legacy frames, local implicit smooth union of torso/neck/sleeves under identical triangle ceiling; no automatic whole-body welding or subdivision/retopo claim. The SDF patch has an independently measured topology/weight test and cost. Style alters proportions, palette response, shading and export roughness/metal response; realism remains a target, not an achieved art grade. Neutral comparisons use common bounds. Historical miniature is the first candidate.
Species templates: horse elongated skull, elevated neck, mane, scapula, carpus, hock, fetlock, hooves; dog distinct barrel/head/tail and limb dimensions; elephant heavier broad barrel/feet, trunk chain, ears and tusks; avian sternum, shoulder/elbow/wrist, feather groups and toes. Composition supports standalone horse, rider, standalone or crew elephant; seat hierarchy and coordinated torso compensation are not physical rein/saddle constraints.
Anatomical research references: https://veteriankey.com/the-horse/ ; https://pubmed.ncbi.nlm.nih.gov/16985198/ ; https://pubmed.ncbi.nlm.nih.gov/18723530/ ; https://pmc.ncbi.nlm.nih.gov/articles/PMC2872429/ ; https://horses.extension.org/horse-walk/ ; https://doi.org/10.1016/j.cub.2022.06.079 . These inform separate limb roles, footfall sequence and wing structure, not copied geometry or calibrated captured gait.
MakeHuman source adapter: pinned CC0 OBJ, four target deltas, original default rig markers and default weights; remove helper faces before compacting body indices, scale decimetres to metres, keep source marker geometry for joint fitting, normalize top 4 influences and report discarded weight. Source roll and expression correction still open; not full MPFB clothing workflow. https://github.com/makehumancommunity/makehuman/blob/master/LICENSE.md ; https://static.makehumancommunity.org/about/concepts/basemesh.html . Native is independent.
Animation: separate procedural gait profiles, semantic frame retarget helper, clip sampling, normalized blending and opt-in bounded support-landmark correction. Measured actual mesh sole height separate; no horizontal foot lock or proven natural motion. Native clip/BVH import still open. Equipment components have type, binding, slots and optional removals; no cloth-body intersection solver. Joint face/finger source geometry is preserved, authored native hands remain primitive. 
Studio: node tools/character-forge/studio.mjs (localhost:4178), no app registration. Browser generation, orbit, compare, skeleton, spec/GLB downloads. CI desktop Chromium/WebKit controls. 
Benchmark: v0.1 100 models 226.87/310.47/628.24 ms. v0.1 SVG per-agent drawImage rasterization and overflow were confounders, not confirmed exclusive cause. v2 240 identical animated citizen instances at 24/48/96 px, same 2048x1280 buffer and per-agent frame sequence, decoded PNG vs atlas vs instanced mesh vs batched geometry vs animated GLB; WebGPU only if requestAdapter succeeds. Different shading paths; synthetic, not Banners FPS. No game renderer changes. 
Artifacts: 4 focused species x 3 styles x 3 LODs; old/new neutral comparisons, 3 citizen variants, 5 short movement probes, separate source morph and Blender v2 roundtrip evidence. No mass atlas generation (8-frame benchmark tile only). No new game dependency or spending.
