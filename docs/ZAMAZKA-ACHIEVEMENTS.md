# ЗАМАЗКА: первая серия достижений и наград

 > Статус: **реализовано**. Семь достижений начисляются через авторитетный PocketNet, награды хранятся в Pocket Social.
> Цель: семь серверно проверяемых задач, от первого матча до редких достижений,
> каждое с отдельной косметической наградой в Pocket ID.

## Каталог

| ID | Название / сложность | Проверяемое условие | Уникальная косметическая награда |
| --- | --- | --- | --- |
| `zamazka.first-stroke` | **Первый мазок** / простое | В онлайн-раунде подтвердить серверную сдачу картины с ≥ 4 мазками и завершить этот раунд | Титул **«Подмастерье»** |
| `zamazka.sharp-eye` | **Верный глаз** / простое | За одну голосуемую работу поставить все 3 фишки на правильную картину | Лицо: **круглый монокль** |
| `zamazka.shared-canvas` | **Общее дело** / среднее | За матч оставить ≥ 10 подтверждённых сегментов общего холста, причём ≥ 1 другой участник тоже оставил сегмент | Головной аксессуар **«Кисть за ухом»** |
| `zamazka.three-rounds` | **Трижды прозорливый** / среднее | На протяжении всех 3 раундов одного матча правильно поставить хотя бы одну фишку в каждом раунде | Титул **«Знаток подделок»** |
| `zamazka.five-works` | **Большая выставка** / среднее | Полностью пройти матч из 5 раундов, сдать непустую реставрацию в каждом раунде и досмотреть результаты | Фон профиля **«Галерея при свечах»** |
| `zamazka.perfect-forgery` | **Ни следа оригинала** / сложное | На твою реставрацию в одном онлайн-раунде не поставлено ни одной фишки на верную картину; голосовали ≥ 3 других игрока | Рамка портрета **«Потёртая позолота»** |
| `zamazka.maestro` | **Маэстро Замазки** / легендарное | Занять 1-е место без ничьей в полноценном онлайн-матче из 5 раундов при ≥ 4 игроках; лично участвовать во всех пяти раундах | Одежда **«Мантия великого реставратора»** |

## Правила качества и антинакрутки

- Счётчики только из подтверждённого состояния серверного модуля `zamazka`; данные из localStorage, одиночной практики и обычного POST клиента не могут разблокировать награду.
- Для открытия достижения требуется Pocket ID, проверенная привязка сетевой сессии к account ID и серверный финальный результат; гости играют, но не получают привязанные к аккаунту награды.
- PocketNet извлекает серверные факты по завершении раунда и матча, хранит краткую сводку в SQLite и доставляет награды в Pocket Social через внутренний Durable Object канал. Outbox сохраняется до успешной доставки, дубли не создают повторных наград.
- Замазка подсчитывает прогресс во время авторитетных `submit`, `vote`, `board_delta`, `continue/results`; при финализации результаты неизменяемы. Несколько вкладок или повторное событие не удваивают прогресс.
- Награды хранятся в SQLite `achievements` у Pocket Social, входят в `unlocked` только после server grant и проверяются при сохранении профиля. Косметика синхронизируется между устройствами.
- Соло-тренировка не выдаёт ценные сетевые достижения: нет независимого сервера, проверяющего её результат.
- Модуль игровой комнаты не изменён: оценка достижений находится в PocketNet coordinator и не меняет версию протокола. Уже идущие матчи продолжаются без пересоздания комнаты; статистика по раундам до обновления автоматически не пересчитывается.
- Сервер отправляет только целевые уведомления `achievement_awarded` после подтверждения записи; игра показывает короткий тост, основная коллекция доступна отдельным экраном. Анимацию подарочной коробки оставляем механикой выдачи кодовой косметики.
- UI достижений сначала показывает 7 лаконичных целей; скрытые средневековые коды остаются отдельной механикой и в этой коллекции не отображаются.

## События данных

```
accepted drawing: authenticated playerId + roomId + matchId + round + strokes.length
accepted ballot:  voterId + targetId + ballot[5] + selected + targetArtwork
accepted board segment: roomId + matchId + playerId
finalized round: roomId + matchId + round + scores + all accepted votes + authors
finalized match: roomId + matchId + rounds + players + per-round participation + total scores
```

Не выдавать достижения на клиентской стороне и не использовать клиентскую кнопку «получить награду» для этого каталога.

## Техническая реализация

- `pocketnet/zamazka-awards.mjs` — чистая функция расчёта семи целей по фактам PocketNet.
- `pocketnet/hub.mjs` — SQLite sidecar для прогресса комнаты, очередь подтверждённых наград, повтор доставки.
- `pocket-social/hub.mjs` — доверенный серверный endpoint `/pocket-social/award` внутри Durable Object, таблица `achievements`, права на косметику.
- `shared/capabilities/zamazka-achievements.js` — общий каталог с ID и слотами наград.
- `apps/zamazka/app.js` — мобильная галерея и уведомления.
- `scripts/test-zamazka-achievements.mjs`, `scripts/test-pocket-social.mjs` — автоматические тесты.
