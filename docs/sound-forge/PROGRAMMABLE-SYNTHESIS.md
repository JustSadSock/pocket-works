# Programmable synthesis v1 (research-only)
Use existing manifest v2 jobs: {name,type:"recipe",output:"generated/contact.wav",recipe:{version:1,intent:"creative brief",duration:1,seed:42,materials:{...},layers:[...]}}. Existing CLI run_manifest.mjs --manifest ... --base ... validates output paths and source catalog. Core renderRecipe also returns PCM16 integer master, per-layer integer stems, Float32 samples, metrics and exact reconstruction. No auto-eval of recipe strings. Trusted host extension functions are optional, not serialized executable source, and are not sandboxed. Pin extension implementation/version and external source bytes yourself. Samples are mono decoded 48kHz arrays from the existing catalog; CLI checks identity and rights; direct host calls must ensure the same admission before resolving.
Material names arbitrary: hardness .05–1, mass .05–20 (relative), roughness 0–1, size .25–4, damping .1–3, modes [Hz, decay seconds, gain]. Contact normal/tangential excitation, grit and microimpacts drive both independently damped modal banks; geometric scaling approximate, no literal physical units or fully coupled physical simulation. Layers: contact(a,b,force,angle,slip), noise(band), impulse(width), oscillator(frequency,endFrequency,jitter,harmonics), sample(source,offset). All have id, at, duration, gain, pan, envelope time/value points; optional modes, filter, soft saturation drive and short cross-channel reflection delay. Layer sum is routing, no arbitrary recursive graph or sidechain compressor yet. Version 1 bounds duration .08–12 seconds, <=32 layers/modes and numeric ranges; deterministic per-layer RNG seed; no silent or clipping output. Independent stems saved in audition; CLI exports postprocessed asset, not the exact stem bundle. Runtime contexts from audition manifest directly consumable by existing sound-family player. Demonstrations not closed presets: fictional crystal latch combines same primitives and novel material, no core changes. Optional group exertions/hoof-gear/reed are experimental, not admitted authentic living sounds. No new universal runtime. Future parameter bindings/continuous excitation, calibrated contact data, formant trajectories and interval studies; no arbitrary code from JSON.

## Acoustic identification and resynthesis (research host tool)
Existing v1 recipes remain unchanged. acoustic_resynthesis.py exposes analyze(x) and render(model,seed,gain,size,duration,noiseMix,modalMix) for 48kHz mono short events. Portable JSON model stores trajectories in [frame,Hz,amplitude], measured 1ms RMS, noise band powers, FFT/hop and length, not source samples or phase. Independent seeded oscillators and stochastic spectral overlap-add render tonal/residual stems; editable time/size transforms and raw gain are acoustic controls, not calibrated physical force. Audio exported to the existing catalog/runtime after rights and review. Not a live generator or new graph engine; a host can use resulting PCM via existing trusted extension/sample interfaces with source receipts. Model fitting uses local spectral peak linking and time-band residual approximation; no causal material deformation inference or true coupled mode identification. Tests compare separate holdout Foley records, not train fit only; no claim physical realism or real exhalation from descriptors. Source corpus documents unknown conditions. Documentary acquisition uses bounded public Wikimedia request, exact identity checks and explicit blocker receipts. No automatic label of inhale/exhale. No change to runtime or old recipes.


## Acoustic Models & Open Authoring — initial engineering slice
Manifest v2 accepts optional `acousticModels` entries `{id,path,sha256}`; each points to a nested JSON package. In v1 recipe layers use `{type:"acoustic",id,model,component:"mix"|"tonal"|"noise",controls,acousticSeed}` with ordinary timing, gain, pan, envelope, modes, filter and delay. The trusted offline Python backend checks exact engine hashes, pinned NumPy/SciPy versions, source dependency SHA-256 and rights metadata. Model package v1 includes original model, controls, seed, applicability/limitations and dependencies; retain source/license files. `tracks` maps track indices to normalized-time frequency and amplitude multiplier curves; `noiseBands` maps indices to amplitude curves (squared into power); `excitation` scales 1ms RMS; `tonalEnvelope` and `noiseEnvelope` act independently after reconstruction. Curves span [0,1], strict ordering, up to 64 points. Existing gain/size/duration/modalMix/noiseMix remain acoustic controls, not calibrated physical parameters. Layer length pads/truncates, not implicit stretching. Default acoustic seed derives from recipe seed and layer index; explicit acousticSeed permits matching separated tonal/noise renders. Package restoration requires identical backend and Python dependency versions; no runtime Python dependency for pre-rendered assets. Max eight acoustic layers/job; each subprocess bounded by 45s. No serialized executable extension. Lab uses existing Foley friction model for an unforeseen stylized observatory shutter with oscillator/modal/noise/recorded layers; no object-specific core. Breath event direction unverified. Technical CI pending; no artistic claim or new required audition.
