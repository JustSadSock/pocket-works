# Shared spatial scale contract
Research-only; existing createVirtualAudioWorld/createBudgetedAudioScene, no game integration. Logical inputs use stable id, region, family, detailAsset, regionalAsset, x/y, activity [0,1], density >=0, priority [0,10], optional occlusion [0,1]. Caller owns immutable AudioBuffers and supplies named assets; zoom [0,1] is abstract detail, not camera FOV, listener coordinates in game units. Smoothstep over [.22,.78], exponential smoothing by elapsed seconds, local and regional equal-power weights; density logarithmically compressed. Regional grouping stable independent of pan/zoom; weighted centroid and capped RMS-like volume. Deterministic ranking by spatial salience and priority, stable IDs, maximum 64 planned emitters; world handles actual retirement and voice limits. Strategic adapter uses settlements/regions/weather/economic activity; tactical adapter uses formations/activity/combat intensity (never a node per soldier); personal adapter uses nearby emitters, zoom near 1. No preset lock-in. Not guaranteed loudness conservation at cap or region aggregation; overlap can be truncated by voice rank, smooth world fade is bounded. Caller-side predecoded asset residency not globally owned; scene limits unique supplied snapshot+active ambience bytes, counts event cache/active union and music separately, observed transient decode peak excludes browser internal allocations. Test 1000 logical sites, four regions and eight selected local sources, real browser short tactical probe with actual existing representative layers (not exact offline master), cleanup, context receipts, no game changes. Future: region-specific production beds, event activity scheduling, global asset residency budget/streaming and actual consumer profiling. Archive SHA-256 local write-once objects and exact restoration, no remote provision without owner authorization.
