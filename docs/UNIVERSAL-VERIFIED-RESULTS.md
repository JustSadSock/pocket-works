# Universal Verified Results — cross-commit proof pilot

This first expansion is deliberately non-authorizing. Banners production delivery stays unchanged. The pilot runs Axis Pals rules and FLICKYARD engine in network-disabled read-only containers from two immutable historical commits. Scope is the whole app, shared, scripts, package manifests, not a guessed import graph. Every mounted byte and executable bit is checked against Git, metadata normalized, and mount digests compared before/inside/after. No Git metadata or commit-specific CI environment is exposed to tests. The actual runtime image, configuration, Node binary, kernel and CPU are recorded. Both sides execute; successful complete TAP assertions are compared without timing. This is empirical evidence, not a general determinism guarantee. Browser, performance, install-dependent, external service and unknown tasks remain fresh. The existing Banners signed catalog is not retroactively broadened.

The positive real historical pair changes only an unrelated app; the negative pair changes scoped infrastructure. A subsequent phase must independently authenticate signed receipts, bind exact source and target mount/runtime proofs, rotate fresh canaries, and integrate the original mandatory plan gate before any reuse is enabled. No production admission is granted by this workflow.
