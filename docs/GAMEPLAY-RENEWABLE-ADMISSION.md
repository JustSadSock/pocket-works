# Renewable production admission integration (shadow)

The optional Universal QA sidecar is enabled with PW_QA_RENEWABLE_ADMISSION_SHADOW=1, only for same-repository Banners PR #1355. It evaluates the actual merge checkout, not the source HEAD from a catalog. The dedicated live test instead freezes the actual current app HEAD and executes all eight shards plus a missing-catalog control. The discovery result is independently authenticated again for each consumed receipt. Exact source commit/tree, issuer commit/tree, mounted source/controller fingerprints, audited plan and complete environment must match. Unknown or missing evidence requires fresh gameplay; fresh performance is mandatory in both routes. A revoked admission after performance triggers fresh gameplay, while a real execution or semantic failure fails the experiment. Historical gameplay timings are never included in fresh measurements. The mandatory rotating canary cannot reuse. No ordinary task is skipped and no delivery gate accepts these shadow artifacts. This is deliberate until the real matrix and actual checkout eligibility are verified. The optional sidecar uses a separate lookup; deduplicating the existing discovery job and supporting equivalent merge trees are future work.
