# Production Verified Results delivery

The mandatory Universal QA legacy route now supports a narrow mixed delivery contract. Default enabled only for the approved same-repository Banners PR #1355; set repository variable PW_QA_PRODUCTION_VERIFIED=0 to disable. Sharded, fork, manual and unrelated tasks retain their existing route. Each planned eligible completion task attempts reuse only after the independent discovery job provides a signed catalog. The task checks its actual checkout, producer hashes, full tree, source/controller mounts, signed receipt, exact environment and rotating canary. A missing artifact, controller, inadmissible receipt or revoked admission exits 75 before publishing a hit; the ordinary app-owned task then runs fresh. Real execution errors remain failures.

A hit publishes a separate verified-delivery envelope and original raw evidence, never a fake result.json. The mandatory summary reconstructs the original task plan, accepts exactly one evidence type per task, reauthenticates and independently audits every hit, checks the actual checkout, complete task identity and fresh performance, and verifies the complete original plan digest. A corrupted or missing verified artifact fails closed. The ordinary stable Pocket Works CI Gate requires the summary and CPU/browser job successes, so a verified result cannot pass via an optional sidecar. No impact skipping. A repository variable can immediately restore full fresh behavior. Historical timing remains distinct. The first scope is legacy only. New catalogs use `pinned-runtime-gameplay-v1`: source and audit mounts, full source/tree identity, Docker image, config, Node/toolchain, architecture and container UID/GID must match exactly. Host kernel and CPU fingerprints remain recorded for audit but do not block semantic gameplay reuse, because all performance cases and measurements are always executed fresh on the target runner. Historical catalogs marked `exact-environment-only` retain their stricter full-environment equality rule. The gate rejects missing/duplicate tasks and tampered raw projections; no impact skipping or broader sharded reuse is enabled.
